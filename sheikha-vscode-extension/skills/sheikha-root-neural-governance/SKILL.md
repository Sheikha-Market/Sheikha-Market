# Sheikha Root Neural Governance

Use this skill when a task touches Sheikha runtime authority, VS Code integration, Sheikha-Core, Ollama, MCP, GitHub, GitLab, API routes, server deployment, publish planning, or enterprise/commercial system integration.

## Workflow

1. Identify the active workspace, branch, runtime entrance, and affected files.
2. Read the existing implementation before proposing edits.
3. Keep changes canonical: use registered runtime paths and avoid duplicate source trees.
4. Route local AI requests through Sheikha-Core or the governed fallback when the model is unavailable.
5. Preserve human authority for Git publish, server restart, destructive actions, and external integrations.
6. Validate with the narrowest reliable checks: syntax, manifest JSON, lint, endpoint smoke tests, and PR checks.
7. Summarize the result with the files changed, checks run, and any remaining risk.
