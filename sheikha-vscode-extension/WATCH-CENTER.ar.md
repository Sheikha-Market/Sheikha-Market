# مركز Sheikha Watch للرصد والتقارير

## الغرض

يرصد المركز بيانات عامة من مصادر ثابتة، ويحوّلها إلى سجل خاص قابل للمراجعة، ثم يجهز تقارير محلية بحسب المستفيد. الرصد لا يثبت صحة كل ادعاء، ولا يثبت انطباق تحذير على أصل، ولا يمنح تفويض تنفيذ أو نشر.

## المعمارية

```text
مصادر عامة ثابتة
  -> جامع محدود الحجم والوقت
  -> تطبيع + بصمة + منع التكرار
  -> سجل إدارة خاص
  -> تحقق المصدر والتصنيف
  -> جرد الأصول والانطباق
  -> الحقوق والجدوى واختبار القبول
  -> ملف المستفيد
  -> مسودة تقرير
  -> عرض محلي أو إعداد قناة خارجية مستقلة
  -> قياس الفائدة الصريح
```

## المصادر المفعلة

- إصدارات عامة مثبتة من GitHub لمشروعات PyTorch وTransformers وDiffusers وllama.cpp وvLLM وMCP.
- بيانات بطاقات نموذجين من Hugging Face، بلا تنزيل أوزان.
- تنبيهات NCA / Saudi CERT من واجهة الهيئة العامة.
- ملخص حالة خدمات GitHub العام.

كل اتصال هو `HTTPS GET` إلى عنوان مسجل في الشيفرة، بمهلة وحد أقصى للحجم، ومن دون تحويلات أو بيانات اعتماد أو محتوى خاص.

## الحوكمة النشطة

1. المصدر ليس إثبات انطباق.
2. اسم المورد ليس إثبات أن المنتج أو الإصدار متأثر.
3. المقترح والتقييم ليسا تفويض تنفيذ.
4. تغير المصدر أو الجرد يبطل قرار الانطباق المرتبط به.
5. التقرير الموجه للمستخدم لا يحتوي إلا نصًا اعتمدته الإدارة صراحة.
6. القنوات الخارجية تحتاج مزودًا ومستلمًا وموافقة واشتراكًا وعزل مستأجرين.
7. التغذية الراجعة المحلية ليست تدريب نموذج.
8. تحديثات النظام والحزم والأصول ليست ضمن صلاحية Watch.

طبقة الحوكمة الهندسية تفعل بوابات: مصدر ودليل، حقوق وجدوى، ربط التحذير بالأصل، توقيع وبصمة artifact، انتهاء الاستثناء الأمني، نطاق MCP لحظة التنفيذ، حدود الطلبات، عزل النص غير الموثوق، ربط موضع نشر الوكيل، وقابلية إعادة بناء toolchain.

## حالات انطباق التحذير

- `AFFECTED`: يتطلب جردًا حديثًا، وأصلًا مطابقًا للمورد، ونتيجة مرتبطة باسم المنتج والإصدار المثبت ورابط الدليل.
- `NOT_APPLICABLE`: يتطلب جردًا معلن الاكتمال ومراجعة كل الأصول المرشحة.
- `INVESTIGATE`: الحالة الافتراضية عند نقص الجرد أو الدليل أو قدمه.

لا تسمح أي حالة بتثبيت تحديث أو تعديل Firmware أو Secure Boot أو TPM.

## صيغة جرد الأصول

```json
{
  "schema": "SHEIKHA_ASSET_INVENTORY_V1",
  "scope": "نطاق الجرد",
  "observedAt": "2026-09-28T18:00:00.000Z",
  "declaredComplete": false,
  "assets": [
    {
      "id": "asset-1",
      "vendor": "Vendor",
      "product": "Product",
      "version": "1.2.3",
      "kind": "SOFTWARE",
      "exposure": "INTERNAL"
    }
  ]
}
```

الأنواع: `SOFTWARE`, `HARDWARE`, `FIRMWARE`, `GPU`, `SERVICE`.

التعرض: `INTERNET`, `INTERNAL`, `OFFLINE`, `UNKNOWN`.

## ملفات المستفيدين والقنوات

تدعم الملفات: فرد، عميل، شريك، باحث، معلم، وجهة خيرية. يحدد كل ملف هدفه ومجالات اهتمامه وقنواته. القنوات المحلية الفعلية هي الشات، الأدابتر، والتقرير المحلي. البريد والـwebhook واللوحة البعيدة تسجل كاحتياج إعداد فقط حتى توفير المزود والمستلم والموافقة والعزل.

## أدوات الشات

- `مركز Watch`: يعرض المعمارية والسياسات والحالة.
- `جرد الأصول`: يعاين ملف جرد محليًا ثم يطلب اعتماد حفظه الخاص.
- `انطباق التحذير`: يسجل نتيجة موثقة مرتبطة ببصمة التحذير والجرد.
- `ملف مستفيد`: يضيف اهتمامات وقنوات لمستفيد.
- `تقرير موجّه`: ينشئ مسودة محلية أو يوضح متطلبات القناة الخارجية.
- أدوات الرصد والتقييم والاعتماد والسحب والتفضيلات والتغذية الراجعة السابقة باقية.

## حدود النسخة الحالية

- التشغيل مالك محلي واحد، وليس خدمة مستأجرين متعددة.
- الرصد الدوري يعمل ما دامت جلسة الإضافة قائمة؛ لا توجد خدمة نظام دائمة.
- لا بريد أو webhook أو إرسال عميل فعلي.
- لا ادعاء حصر كل فرصة أو كل تحذير في العالم.
- لا تحليل تلقائي لنسخ المنتجات المتأثرة من نصوص المورد؛ قرار الانطباق يحتاج دليلًا بشريًا وجردًا.
- لا شراء أو تنزيل نماذج أو تدريب أو ترقية أو تغيير أمني عالي الأثر.
