# Sheikha OS — Kernel, Bootloader, and Mini OS

**جميع الحقوق محفوظة © 2026 سلمان أحمد بن سلمان الراجح**

## المكونات:
- **sheikha-kernel.js**: النواة البرمجية الأساسية (Kernel)
- **sheikha-bootloader.js**: بوت تشغيل (Bootloader)
- **sheikha-os.js**: نظام تشغيل مصغر (Mini OS)

## طريقة التشغيل:
- تشغيل الكيرنل:
  ```bash
  npm run os:kernel
  ```
- تشغيل البوت:
  ```bash
  npm run os:boot
  ```
- تشغيل النظام:
  ```bash
  npm run os:start
  ```
- اختبار النظام:
  ```bash
  npm run os:test
  ```
