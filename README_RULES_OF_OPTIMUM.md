# منظومة قواعد الأفضل (Rules of Optimum)

## الهدف
توحيد وتفعيل القواعد الكونية المستمدة من القرآن والسنة في جميع المشاريع التقنية والإدارية.

## الملفات
- `rules_of_optimum.json`: قاعدة بيانات القواعد (اسم، مصدر، ملخص، تطبيق كوني، مجالات، مثال، مقياس).
- `optimum_rules_checker.py`: سكربت بايثون لفحص أي مشروع أو وصف ضد القواعد.

## الاستخدام
1. عدّل أو أضف قواعد في `rules_of_optimum.json` حسب الحاجة.
2. لتشغيل الفحص:
   ```bash
   python3 optimum_rules_checker.py "وصف المشروع أو النظام هنا"
   ```
   أو بدون argument:
   ```bash
   python3 optimum_rules_checker.py
   # ثم أدخل الوصف عند الطلب
   ```
3. ستظهر نتيجة الفحص لكل قاعدة: هل الوصف يراعيها أم لا.

## مثال
```
python3 optimum_rules_checker.py "نظام إدارة مشاريع برمجية يعتمد على الشورى والإتقان والتكامل بين الفرق."
```

## التوسعة
- أضف قواعد جديدة للملف JSON.
- يمكن ربط السكربت بأنظمة أكبر (CI/CD, VS Code, إلخ).
