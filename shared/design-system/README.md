# SHEIKHA Unified Design System

نظام الهوية الموحد لمنصة شيخة — تُدار جميع عناصر الهوية البصرية من هذا المكان.

## العناصر
- **الألوان** — tokens.json → colors
- **الخطوط** — tokens.json → typography
- **التنقل** — tokens.json → navigation
- **النطاقات** — tokens.json → domains
- **البطاقات / الجداول** — مكونات قابلة لإعادة الاستخدام
