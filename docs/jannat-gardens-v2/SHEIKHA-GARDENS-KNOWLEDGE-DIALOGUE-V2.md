# منظومة جنات وأشجار شيخة والحوار المعرفي V2

## الغرض

تربط هذه المنظومة بين تسعة نماذج حدائق دنيوية، وسبع وعشرين شجرة
تشغيلية، وكتالوج المنتجات والقطاعات والأسواق، ومسار حوار معرفي
يحلل الأفكار والدعاوى والأهداف والوسائل والأدلة. ويضم سجلًا تعليميًا
منتقى من 19 إطارًا معاصرًا و18 إطارًا تاريخيًا، وفحص نزاهة بعشرة
أبعاد، ومولد مسودات لسبعة برامج منفعة مجتمعية، ومولد أطر فكرية هادفة
طوعية وقابلة للنقد والتوقف والتعافي.

## الحدود الحاكمة

- «الجنة» هنا استعارة دنيوية للمعرفة والعمل النافع، وليست وصفًا أو
  تمثيلًا للجنة الغيبية.
- المخطط النباتي مفهوم أولي، وليس خطة تنفيذ موقع. يلزم تحليل تربة وماء
  ومهندس زراعي محلي قبل الغرس.
- لا تُحدد كمية ري أو وصفة غذائية أو علاجية دون بيانات موقع ومختص.
- مرجعية الكتاب والسنة هنا قيم معلنة للصدق والعدل والأمانة والتثبت
  ومنع الضرر، ولا تتحول إلى فتوى أو حكم عقدي آلي.
- الأحكام الشرعية والاجتهادية تتطلب مراجعة بشرية مؤهلة.
- لا يصنف المحرك الأشخاص حسب الدين أو المذهب أو التوجه السياسي، ولا
  ينتج درجة إيمان أو درجة أيديولوجية.
- لا يولد «أيديولوجيا صحيحة» ملزمة، ولا يجيز قمع فكرة أو جماعة. ينتج
  مسودة برنامج سلمي تطوعي تحفظ الحقوق وقابلة للتوقف والتظلم.
- يمكنه توليد مسودة أيديولوجية هادفة جديدة، لكنه يصرح دائمًا بأنها
  اقتراح طوعي غير ملزم، لا حقيقة نهائية ولا عقيدة دينية ولا تفويضًا
  سياسيًا، ويُلزمها بالدليل المضاد والمراجعة والانقضاء أو التعديل.
- «صحة المجتمع» مؤشرات تجميعية اختيارية وليست تشخيصًا طبيًا أو نفسيًا،
  ولا تسمح بعلاج قسري أو جزاء جماعي.

## الحوار البنّاء

يحلل المحرك الفكرة التي يحددها المستخدم صراحة، ويعرض تعريفها وأهدافها
المعلنة ومنافعها المحتملة ومخاطرها وأسئلة التحقق منها. لا يستنتج دين
الشخص أو مذهبه أو توجهه السياسي، ولا ينشئ ملفًا حساسًا، ولا يستخدم
الإقناع القسري أو الاستهداف السياسي أو الديني الشخصي.

## فحص نزاهة الفكرة

ينظم الفحص متطلبات التعريف والدليل والدليل المضاد واتساق الغاية
والوسيلة ومنع الضرر والحقوق والمشروعية وعدالة التوزيع والبيئة والتعافي
والمساءلة. حالته الافتراضية `EVIDENCE_REQUIRED`، ولا يقرر أن الفكرة
صحيحة أو باطلة أو موافقة للشرع؛ بل يحيل الاستنتاج إلى مراجعة بشرية
مؤهلة مع تسجيل جوانب النقص.

## برنامج المنفعة المجتمعية

يحول الأهداف المختارة صراحة إلى مسودة رؤية ورسالة وأهداف قابلة للقياس
وبرامج للمعرفة، والمعاش العادل، والعلوم والمهارات، والحوار، والبيئة،
والسلامة الرقمية، والحوكمة والتعافي. تبقى خطوط الأساس والأهداف العددية
فارغة حتى يقدم المجتمع المحلي قياسًا ويعتمدها مالك بشري.

## توليد الأفكار والأطر الهادفة

يبدأ التوليد من مشكلة محددة ونتائج يختارها المستخدم وأطر معرفية معلنة.
ينتج اسمًا ورؤية ورسالة، وثمانية مبادئ مضبوطة بقيود منع إساءة الاستخدام،
ونظرية تغيير من خمس مراحل، وسبعة برامج أولية، وتوترات غير محسومة،
وبوابات دليل وحقوق وتظلم وإيقاف وتعافٍ. لا يبدأ تنفيذًا أو نشرًا أو
حملة، ولا يصنف الأشخاص أو يستهدفهم لتغيير معتقد أو توجه.

يمر الحوار بالمراحل التالية:

1. توضيح المصطلحات والنطاق.
2. عرض أقوى صياغة عادلة للفكرة.
3. فصل الهدف عن الدعوى والوسيلة.
4. طلب الدليل والدليل المضاد.
5. تقييم المنافع والمخاطر والحقوق والضرر.
6. تحديد المشترك والاختلاف.
7. عرض خيارات غير قسرية.
8. تسجيل عدم اليقين وما يحتاج خبيرًا.
