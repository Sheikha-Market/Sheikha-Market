# Sheikha Neural Data Fabric

Sheikha Data is not a single database. It is a governed neural data fabric.

## Hierarchy

Governance
↓
Neural Routing
↓
Data Fabric
↓
Database Engines
↓
Runtime APIs
↓
Applications / AI / IDE / CLI

## Engines

- SQL Server: transactions, ERP, governance, audit.
- PostgreSQL: runtime relational core.
- MariaDB / MySQL: compatibility and service integrations.
- MongoDB: dynamic documents and runtime metadata.
- Redis: neural cache, queue fabric, and streaming memory.
- Vector Database: embeddings and semantic retrieval.
- Neural Memory Layer: orchestration and routing.

## Rule

No database engine becomes production-core until it is registered, measured, verified, governed, audited, and recoverable.
