# Sheikha-Core AI Foundations Runtime

## التعريف

`Sheikha-Core` هي نواة Sheikha للذكاء الصناعي وقواعده وأساسياته. تجمع:

- Sheikha Provider API Keys
- Usage Metering
- Enterprise Auth
- Multi-Model Router
- GPU Scheduler
- Local Vector Memory
- Sheikha Cloud Node
- Sheikha IDE Runtime
- Local RAG Stack
- Internal Registry & Governance Engine
- Sheikha Editor

## قواعد الذكاء الصناعي

1. الله وحده الخالق والمالك، والتقنية سبب وأداة لا تستقل ولا تدعي علم الغيب.
2. لا حكم بلا علم، ولا تنفيذ بلا تحقق.
3. البيانات أمانة: تصنيف، خصوصية، منع تسريب، منع تضليل.
4. الخوارزميات أدوات قياس وتحليل، وتخضع للتفسير والمراجعة.
5. النماذج لا تدعي وعياً ولا يقيناً مطلقاً؛ مخرجاتها توصيات قابلة للمراجعة.
6. لا ضرر ولا ضرار، وكل تشغيل صناعي أو روبوتي يحتاج حدود أمان ومراجعة إنسان.
7. كل خدمة تجارية يجب أن تكون مباحة، واضحة، عادلة، وخالية من الغش والربا والظلم.
8. لا نشر ولا دمج ولا تشغيل مؤثر بلا موافقة المالك.

## Sheikha Editor

`Sheikha Editor` هو محرر آمن للتعديل والتوثيق وإعادة الهيكلة، يعمل مع Git diff، MCP SDK، RAG محلي، وشبكة الخلايا العصبية الجذرية.
