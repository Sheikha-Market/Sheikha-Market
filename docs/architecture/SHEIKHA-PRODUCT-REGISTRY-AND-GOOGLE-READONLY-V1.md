# سجل منتجات شيخة والتكامل المقيد

## النطاق والحالة

هذه الحزمة تنفذ سجلًا محليًا قابلًا للبحث والمراجعة، وخطة تجربة قابلة للتنزيل، وموصل جرد Google للقراءة فقط.
ليست تنفيذًا مكتملًا للخدمات المرجعية أو استبدالًا لها. تضم القائمة المرفقة 129 بندًا في 18 مجالًا، بما فيها منتجات أطراف أخرى ومداخل إدارة؛ ليست قائمة شاملة لجميع منتجات Google.

- `config/sheikha-cloud-products.v1.json`: أسماء مستقلة مقترحة لشيخة، تصنيف النطاق، معايير القبول الأولية، وربط مبدئي لثماني واجهات.
- `core/cloud-fabric/sheikha-product-registry-v1.cjs`: تحقق النطاق والمرفق وأدلة الملفات وموصل القراءة.
- `tools/sheikha-cloud/build-product-console-v1.cjs`: بناء حزمة خاصة تعمل مباشرة من ملف HTML.
- `runtime/cloud-products/index.html`: مدخل المراجعة المستقر؛ لا يحتاج خادمًا.
- `runtime/cloud-products/snapshots/`: لقطات مستقلة لا يعاد تحريرها؛ لكل منها بصمات المخرجات وسجل الاتصال وورقة التجربة.

وجود ملفات تنفيذ مرتبطة بستة بنود مسجل بوصفه `LOCAL_CANDIDATE_NOT_ACCEPTED` فقط، دون استيرادها أو تشغيلها. بقية البنود `PROPOSED_NOT_IMPLEMENTED`. جميع المنتجات غير معتمدة إنتاجيًا في هذا السجل. أدلة الملفات قراءة زمنية وليست لقطة معاملات لجميع ملفات المشروع.

## البناء

```bash
node tools/sheikha-cloud/build-product-console-v1.cjs build
node tools/sheikha-cloud/build-product-console-v1.cjs build --request '/path/to/Pasted text.txt'
node tools/sheikha-cloud/build-product-console-v1.cjs build --request '/path/to/Pasted text.txt' --probe
node tools/sheikha-cloud/build-product-console-v1.cjs probe
```

المطابقة تقرأ مقطع قائمة المنتجات وتستهلك جميع بنوده بالترتيب. ترفض أي اختلاف أو حدود مكررة، وتحفظ البصمة وأرقام الأسطر والعدد فقط. لا تنسخ نص المحادثة الكامل أو بيانات اعتمادها، ولا تنفذ السكريبتات المنقولة فيها. تشغيل البناء دون `--request` يعلن غياب مطابقة المرفق.

اللقطات ومخرجاتها محلية بصلاحيات `0700` و`0600`. الملفات الأصلية وجدولة الإنتاج المحلي القائمة لا تتغير. نسخ المراجعة على القرص نفسه ليست نسخًا احتياطية خارجية. التخزين المحلي في المتصفح وسيلة راحة وليست مصادقة أو سجل اعتماد. تنزيل اختيار التجربة يحافظ دائمًا على `executionAuthorized: false` و`publicationApproved: false`.

## جرد Google

المشروع والرقم يطابقان الإعداد المحلي القائم في `runtime/external-alignment/google-cloud/project-mapping/sheikha-google-project-map.json`. هذه مطابقة إعدادات، وليست إثبات ملكية أو اتصال.

يفحص الموصل مسارًا واحدًا فقط:

```text
GET https://serviceusage.googleapis.com/v1/projects/PROJECT_NUMBER/services
filter=state:ENABLED&pageSize=200
```

التفويض، عند اعتماده خارج هذه الحزمة، يأتي من متغير العملية `SHEIKHA_GOOGLE_READONLY_ACCESS_TOKEN`. يستخدم رمز وصول قصير العمر ملائمًا للقراءة؛ لا يُطلب إرساله في المحادثة، ولا يُكتب في الملفات أو الواجهة أو السجلات. معرف عميل OAuth وملف client secret وحدهما ليسا رمز وصول ولا إثبات اتصال. الأداة لا تنشئ رموزًا ولا تقرأ مخازن اعتماد أو ملفات `.env` ولا تستخدم `gcloud`.

تتطلب واجهة الجرد صلاحية `serviceusage.services.list` ونطاق تفويض تدعمه الواجهة، ومنها `cloud-platform.read-only`. يجب أن يراجع مسؤول المشروع الهوية والصلاحيات قبل توفير الرمز. مرجع [Service Usage services.list](https://docs.cloud.google.com/service-usage/docs/reference/rest/v1/services/list).

القيود المنفذة: طلبات GET فقط، مضيف ثابت، رفض التحويلات، مهلة مشتركة للطلب والجسم، عشرة صفحات كحد أقصى، مليون بايت تقريبًا لكل استجابة، تحقق المشروع وأسماء الخدمات والحالة، ورفض التكرار ودورات الصفحات. لا تعاد محاولة تلقائية. أي فشل يعيد حالة غير مكتملة بلا قائمة جزئية قد تُفهم على أنها جرد كامل. لا تحفظ رسائل المزود الخام أو عناوينه أو بياناته الإضافية.

الحالة `ENABLED_API_INVENTORY_OBSERVED` تعني جرد واجهات مفعلة في وقت محدد، لا تشغيل منتج أو اختبار صلاحيات بياناته. لا توجد عمليات تفعيل APIs أو نشر أو شراء أو استعلام BigQuery أو تعديل IAM في هذا الموصل. لا توجد مراقبة سحابية دورية مفعلة.

## الشراكات والتوليد

العلامة في الحزمة هي شيخة فقط؛ أسماء المراجع تشير إلى خدماتها الأصلية ولا يعاد تسميتها باعتبارها مملوكة لشيخة. وثائق Google تمنع الإيحاء بعلاقة غير قائمة ودمج علامتها في اسم منتج مستقل. مرجع [ضوابط العلامة](https://about.google/brand-resource-center/guidance/).

ورقة `pilot-review.ar.md` مسودة مراجعة نطاق وأهداف وليست عقدًا. لم تُرسل مراسلات، ولم يُتحقق من اتفاقية موقعة أو قبول طرف مقابل أو صلاحية إعلان مشترك. استكشاف المسار الرسمي عبر [شركاء Google Cloud](https://cloud.google.com/partners) لا يعني التسجيل أو القبول. لا تعتمد هذه الحزمة العبارات أو التقديرات أو الاتفاقيات المزعومة في المحادثات والوثائق التاريخية كأدلة.

التوليد الخارجي المتكرر يبقى متوقفًا لعدم اختيار المزود والميزانية اليومية. لا يغير هذا سجل المرئيات المحلي أو خدمات واتش والحارس الموجودة.

اختبارات الموصل تستخدم استجابات مصطنعة، ولا تثبت اتصالًا حيًا. اختبارات المتصفح تقيس واجهة السجل وتصفية النطاق والتصدير واستمرار الاختيار وقيود التخزين وأبعاد سطح المكتب والجوال وتحميل المرئية المرجعية ومنع الطلبات الخارجية. نجاحها لا يرفع حالة المنتجات المرجعية إلى معتمدة. تقرير المتصفح يحمل بصمة HTML ولقطة البناء المرتبطة به.

مرجع النطاق العام: [كتالوج منتجات Google Cloud](https://cloud.google.com/products). الأسماء والمقارنات المبدئية ليست ضمانًا للتوفر أو التكلفة أو التكافؤ الوظيفي.
