# Sheikha Read-Write-Publish Runtime

## التعريف
طبقة تشغيل آمنة تربط القراءة والكتابة والنشر عبر شبكة خلايا Sheikha الجذرية.

## القاعدة الحاكمة
كل مسار يمر عبر:

مدخلات -> قراءة موثقة -> تصنيف بيانات -> فحص شرعي وأمني -> خطة كتابة -> diff وفحص -> اعتماد بشري -> نشر -> سجل تدقيق.

## الضوابط
- لا نشر للأسرار أو المفاتيح أو ملفات البيئة.
- لا كتابة مؤثرة دون مراجعة بشرية.
- لا حذف أو reset دون أمر صريح.
- لا push أو release قبل الفحص وقراءة diff.
- الحوكمة مبنية على التوحيد، الكتاب والسنة، منع الضرر، وحفظ الأمانة.

## واجهات API
- `GET /api/sheikha/read-write-publish/status`
- `POST /api/sheikha/read-write-publish/plan`
- `POST /api/sheikha/read-write-publish/evaluate`

- خلية التوحيد والنية.

- بوابة الكتاب والسنة.
- خلية البرمجة.
- خلية Git وGitHub وGitLab.
