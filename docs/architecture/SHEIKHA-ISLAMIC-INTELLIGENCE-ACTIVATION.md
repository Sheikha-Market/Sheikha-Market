# Sheikha Islamic Intelligence Activation

## الاسم
Sheikha Islamic Intelligence Engine

## الهدف
تفعيل منظومة ذكاء إسلامية تشغيلية داخل Sheikha، مرتبطة بالكتاب والسنة، وتعمل كطبقة توجيه وفلترة ومراجعة قبل البرمجة والتطوير والتشغيل.

## النموذج التشغيلي
- `sheikha-islamic-intelligence-v1`
- `sharia-compliance-classifier`
- `sheikha-rag-reasoner-v1`

## المسارات الرسمية
- `GET /api/sheikha/islamic-intelligence/status`
- `POST /api/sheikha/islamic-intelligence/query`
- `POST /api/sheikha/islamic-intelligence/train`
- `POST /api/sheikha/chat`

## ضوابط الحوكمة
- الأمانة: لا تعديل مؤثر إلا بوضوح ومراجعة أثر.
- التثبت: كل قرار تقني يبدأ بفحص المصدر والمسار والحالة.
- الوفاء بالعقود: عدم كسر الواجهات والسجلات دون خطة انتقال.
- منع الضرر: الأمن والخصوصية وسلامة البيانات مقدمة.
- الإتقان: لا يكتمل العمل حتى يمر بالتوثيق والاختبار.

## حالة التفعيل
تم ربط Sheikha Chat بمحرك الذكاء الإسلامي بحيث يخرج ردودًا تشغيلية مخصصة حسب النية:
- مراجعة المشروع
- التطوير
- التدريب
- الحوكمة الشرعية
- API وMCP SDK

## حدود الاستخدام
هذه المنظومة تقدم حوكمة تشغيلية وتوجيهًا تقنيًا وشرعيًا مساعدًا، ولا تستبدل أهل العلم في الفتوى أو القضاء أو الاعتماد الشرعي الرسمي.
