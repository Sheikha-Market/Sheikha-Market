# Sheikha Root Architecture V3

## Root hierarchy

```text
Islamic Reference Governance
        ↓
Ethics, Justice and Harm Prevention
        ↓
Identity, Scope and Constitution
        ↓
Logic and Reasoning Governance
        ↓
Sheikha System Builder
        ↓
Sheikha Bare Metal + Sheikha UEFI
        ↓
Gardens and Trees Operational Taxonomy
        ↓
Unified Product Runtime + Site + CLI + APIs
```

## Gardens and Trees

The terms are an operational taxonomy and do not simulate life.

- Roots: reference, ethics, identity and evidence.
- Trunks: System Builder, Bare Metal, UEFI, Runtime and Governance.
- Branches: Driver ABI, hardware compatibility, site, CLI and APIs.
- Leaves: protocols, routes, drivers, components and tests.
- Fruits: verified services, recoverable releases and safe outcomes.

Every capability must be attached to a branch, trunk and root.
Every completion claim requires evidence.

## Islamic reference governance

The system stores verified reference metadata, provenance, edition,
hashes and qualified review records. It does not claim divine
authority, replace qualified scholars or issue autonomous fatwas.

## UEFI registry

The registry covers foundation services, console and HII, device
and driver protocols, firmware execution, networking, security,
TPM and confidential-computing capabilities.

Registration means that a capability is tracked. It does not mean
that the capability has been implemented, tested or physically
verified.
