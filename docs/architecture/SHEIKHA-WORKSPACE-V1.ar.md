# مساحة شيخة التفاعلية V1

## النطاق

واجهة شيخة، سوق شيخة، لوحة تشغيل SDK/MCP، ومراجعة المرئي المعماري ضمن
`public/workspace/`. لا تستبدل الواجهات الموجودة ولا تعيد تشغيل خادم الإنتاج.
الخادم المحلي المخصص يستخدم محركات المشروع نفسها، دون نسخ منطقها إلى الواجهة.

```bash
node tools/preview/sheikha-workspace-preview.cjs
```

الرابط الافتراضي `http://127.0.0.1:4192/workspace/`. إذا كان المنفذ مشغولًا
يختار الخادم منفذًا متاحًا ويطبع الرابط الفعلي. يستمع إلى loopback فقط.
يمكن تعيين `PORT` صراحة. أوقفه بإشارة SIGTERM أو Ctrl+C في التشغيل المباشر.

المسارات: `#/sheikha` و`#/market` و`#/operations` و`#/architecture`.
هذه مساحة محلية مستقلة داخل المشروع، وليست إضافة تلقائية إلى API خادم الإنتاج.
فتح ملفات HTML وحدها أو تقديمها من خادم آخر لا يفعّل البوابة الخلفية.

## الربط الفعلي

| المسار | SDK | MCP |
| --- | --- | --- |
| Foundry | simulateFoundryTelecom | sheikha_foundry_telecom_simulation |
| الطبيعة | processNaturalData | sheikha_natural_data_process |
| المستشعرات | interpretSensorBatch | sheikha_sensory_interpret |

مسار MCP ينشئ عميلًا وخادم stdio محليين من الحزمة المثبتة، ينفّذ الاستدعاء
ثم يغلق النقل. توجد مهلات للاتصال والاستدعاء واستدعاء واحد في الوقت نفسه.
لا تقبل البوابة أسماء أدوات أو أوامر أو مسارات أو مزودين من المستخدم.
قائمة وظائف خادم MCP الأصلي أوسع، لكن هذه البوابة لا تعرض إلا الوظائف الثلاث.

النتيجة تحوي المسار والمدة والوقت وبصمة المعاملات ونتيجة المحرك. بصمة المحتوى
ليست إثبات هوية مصدر أو سلامة جهاز. القراءات التجريبية موسومة، وقراءة المستشعر
التجريبية قديمة عمدًا لإثبات كشف التقادم. لا أجهزة موصولة ولا تدريب أو توليد
مدفوع أو تحكم مادي أو نشر خارجي.

## السوق والمراجعة

الكتالوج مشتق من `buildUnifiedCommerceRuntime`، لا من موردين أو مخزون حي.
البحث والتصفية يعتمدان على سجلات المشروع. إنشاء طلب عرض سعر يستدعي
`buildCommerceOperationPlan` بمسار RFQ ثابت، ويعيد مسودة بشرية المراجعة.
لا طلب تجاري مرسل ولا عقد أو فاتورة أو دفع. سقف نطاق الطلب 500 حرف، مطابق
لنواة التخطيط، دون اقتطاع صامت. السجلات في ذاكرة الصفحة فقط وبحد 20 سجلًا.
التنزيل إجراء صريح؛ تحديث الصفحة يمسح السجل. لا تخزين محلي دائم أو خدمة مزامنة.

## Watch وGuard

اللوحة تقرأ آخر سجلات Visual Foundry المحفوظة فقط. عمر سجل Watch ظاهر؛
وجود PID أو كلمة RUNNING في سجل قديم لا يثبت استمرار العملية. خانة المتابعة
تحدث الحالة كل 30 ثانية أثناء ظهور اللوحة، ولا تعيد تشغيل المهام أو الخدمات.
هذه الإضافة لا تغيّر جدول الإنتاج اليومي ولا ميزانية التوليد ولا بوابة النشر.

## الحدود الأمنية

- loopback، مطابقة Host للمنفذ، رفض Origin الخارجي وطلبات cross-site.
- جلسة عشوائية في ذاكرة الخادم لكل تشغيل، إلزام JSON، لا CORS.
- سقف 512 KiB للطلب و20 طلب POST في الدقيقة، وأخطاء لا تعكس المدخلات.
- تقديم مجلد الواجهة والأصول المسموحة فقط، دون `.env` أو السجلات الخاصة.
- CSP محلية، عرض النصوص بــ textContent، لا تنفيذ HTML مستورد.
- هذه حماية لواجهة محلية وليست مصادقة متعددة المستخدمين؛ عملية محلية أخرى
  تستطيع الوصول إليها. النشر العام يتطلب تصميم مصادقة وتفويض وتدقيق مستقل.

## مراجعة المرئي الأول

مرجع المراجعة: التكوين الأخضر والذهبي ذو الكتل المتدرجة والعقد المتصلة،
بصمة SHA-256:
`4fb446ee84636a5f1df3d47129c21351ae4a3d3d2085b76ae2fdcdf8c11595a9`.
بناءً على تفويض المستخدم «اختار الأحسن»، اختير التكوين الأخضر والذهبي مرجعًا معماريًا مفاهيميًا لهوية شيخة وترابط المكونات، دون اعتباره مخطط دائرة إلكترونية أو اعتمادًا للتصنيع.

يمكن استلهام فصل الطبقات والنواة والعقد والروابط منه، لكنه لا يحدد اتجاه
تدفق البيانات أو مالك العقدة أو عقود الرسائل أو الثقة أو حالات التعطل.
الترجمة المطبقة: واجهة > بوابة تحقق محلية > SDK/MCP > محرك مجال > دليل نتيجة
> مراجعة بشرية. لا يمكن استنتاج أن كل خط ذهبي بروتوكول أو توصيل كهربائي.

لا توجد رموز مكونات أو قيم أو أرقام أطراف أو تغذية/أرضي أو عزل وحماية أو
netlist أو BOM أو نتائج قياسات. لذلك لا يقدم المرئي دليل صلاحية دائرة أو
تصميم تصنيع. يلزم مخطط هندسي ومواصفات ومراجعة مختص قبل أي اعتماد كهربائي.

## المرجعية والقيم

هوية شيخة مستندة إلى الكتاب والسنة. تطبيقها هنا في صدق الحالة، منع الادعاءات
غير المتحققة، حفظ الحقوق والموارد، فصل الدليل عن التصور، والمراجعة قبل التنفيذ.
لا فتوى آلية ولا شهادة مطابقة شرعية؛ الأحكام والعقود تحتاج مراجعة بشرية مؤهلة.
الأصول الأصلية محفوظة دون تعديل، ومصدر النسخ وبصماتها في
`public/workspace/assets/provenance.json`.

## التحقق

```bash
node --test --test-concurrency=1 tests/sheikha-workspace-preview.test.cjs
node --test --test-concurrency=1 tests/sheikha-workspace-browser.test.cjs
```

اختبار المتصفح يستخدم Playwright المحلي من `PLAYWRIGHT_MODULE` أو المسار
`/tmp/sheikha-architecture-tools/node_modules/playwright`، وChrome من
`CHROME_PATH` أو `/opt/google/chrome/chrome`. لا ينزّل حزمًا ولا يزور خدمات خارجية.
