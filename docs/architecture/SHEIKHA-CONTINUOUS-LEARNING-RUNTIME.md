# Sheikha Continuous Learning Runtime

## الهدف

تفعيل تعلم لحظي ويومي محكوم لشيخة، يغطي الشات، الملفات، التشغيل، البرمجة، الأنظمة، التجارة، الأسواق، التقنيات، الأخبار الموثقة، التقويم، والتاريخ.

## القاعدة

النظام أداة تحليل وتنظيم وتعلّم محكوم. الله وحده الخالق والمالك والمدبر. لا يدعي النظام وعياً ولا علماً بالغيب ولا سلطة مستقلة، ولا يرقّي النموذج أو ينشر معرفة مؤثرة إلا بعد مراجعة بشرية وبحوكمة الكتاب والسنة.

## المسارات

- `GET /api/sheikha/continuous-learning/status`
- `GET /api/sheikha/continuous-learning/daily-plan`
- `POST /api/sheikha/continuous-learning/daily-plan`
- `POST /api/sheikha/continuous-learning/ingest`
- `POST /api/sheikha/continuous-learning/cycle`

## المجالات

- الكتاب والسنة والحوكمة.
- البرمجة والأنظمة.
- التجارة والأسواق وسلاسل الإمداد.
- التقنيات والأخبار الموثقة.
- التقويم والتاريخ والسياق الزمني.
- الأمن والخصوصية.
- التشغيل المؤسسي والنشر.

## دورة التعلم

1. استقبال معرفة أو إشارة تشغيل.
2. تحديد المصدر والمجال والتاريخ.
3. فحص الخصوصية والأسرار.
4. فحص الحلال ومنع الضرر والغش والربا والتزييف.
5. تسجيلها في طابور `data/training/sheikha-continuous-learning.ndjson`.
6. تسجيل عينة تدريب ذاتي محكومة في طابور Sheikha-Core.
7. مراجعة بشرية قبل أي ترقية أو dataset أو تدريب فعلي.

## الأخبار والأسواق

الأخبار والأسواق لا تُقبل تلقائياً. يجب أن تحتوي على مصدر وتاريخ وقرينة تحقق. أي مدخل بلا مصدر ينتقل إلى `blocked_for_review`.

## أوامر CLI

- `npm run sheikha:learning`
- `npm run sheikha:learning:plan`
- `npm run sheikha:learning:cycle`

## حدود الأمان

- لا تدريب مباشر من الإنترنت.
- لا حفظ أسرار أو مفاتيح.
- لا استخدام بيانات شخصية بلا إذن.
- لا اعتماد حكم شرعي بلا دليل ومراجعة.
- لا نشر أو دفع Git بلا RWP وBlueprint Guard.
