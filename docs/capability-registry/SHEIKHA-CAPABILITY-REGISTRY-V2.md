# SHEIKHA_CAPABILITY_REGISTRY_V2
# سجل قدرات شيخة V2

## الهدف

تفعيل القدرات الكاملة داخل مشروع شيخة بدون سحب نموذج جديد، وذلك عبر تسجيل القدرات المسموحة وربطها بالقرارات والحوكمة والاستقرار.

## القدرات

- البرمجة والتعديل
- مراجعة PR
- حوكمة الدمج
- فحص الاختبارات
- فحص Lint
- منع Drift
- عقود API
- تكامل IDE/CLI
- تحويل المعرفة إلى قرار
- التحسين المستمر

## القاعدة

لا قدرة بلا تسجيل.
لا تنفيذ بلا قرار.
لا قرار بلا معرفة.
لا تشغيل مع Drift.
لا كسر للحوكمة.
لا دمج خام.

ولا حول ولا قوة إلا بالله.
