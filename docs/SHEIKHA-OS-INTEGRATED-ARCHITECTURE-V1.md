# شيخة — المعمارية المتكاملة V1

## الغاية والجذور
المرجعية القيمية المطلوبة: الكتاب والسنة، والعدل والصدق والنفع، وعدم الإضرار. تحويل هذه المبادئ إلى سياسات واختبارات برمجية يساعد التنفيذ، لكنه لا يمثل فتوى آلية أو اعتمادًا شرعيًا مستقلًا. مراجعة العقود والأحكام واللوائح تكون لدى المختصين، والامتثال القانوني الحالي غير مثبت.

## طبقات النظام ومعايير قبولها
| الطبقة | المسؤولية | الدليل المطلوب للتأهيل الكامل |
|---|---|---|
| boot | الإقلاع | إقلاع موثق على أهداف العتاد المعلنة |
| kernel | الذاكرة والمقاطعات والعزل | اختبارات حدود وصلاحيات وأعطال مستقلة |
| scheduler | جدولة المهام | قياس الاستجابة والإنصاف وحدود التنفيذ |
| hal | واجهات الأجهزة | مشغلات مؤهلة لكل جهاز مدعوم |
| storage | التخزين | استعادة موثقة وسلامة البيانات عند الانقطاع |
| network | الشبكات | اختبارات البروتوكولات والتشفير والصلاحيات |
| security | الأمن | نموذج تهديد وتحقق من منع التجاوز |
| packages | البرامج والتحديثات | سلامة الحزم واختبار التراجع |
| language | لغة شيخة | تحليل وأنواع وتنفيذ واختبارات رفض الأوامر المخالفة |
| desktop | الواجهة | جلسة تفاعلية قابلة للاستخدام والوصول |
| research | البحث | بروتوكول مناسب للسؤال وبيانات وتحليل ومراجعة |
| watch | المراقبة | مصدر قياس معلوم واكتشاف الانقطاع وقراءات قديمة |
| evidence | الأدلة | مصدر مسموح وبصمة وفحص الادعاء ومراجعة مستقلة |
| governance | الحوكمة | صلاحيات محددة وقرارات قابلة للتدقيق |
| migration | الانتقال | توافق التطبيقات والبيانات وخطة رجوع مجربة |
| recovery | الاستعادة | تجارب أعطال واستعادة قابلة للتكرار |

هذه عقود تصميم؛ وجود أسماء الطبقات لا يعني تنفيذ كامل وظائفها. يبقى تطوير Bare-Metal والمرافق الخمسة مستقلًا ومتوازيًا مع الروبوتات والتجارة والقياس والابتكار.

## الأدوات والربط الفعلي
- المصدر: `sheikha-language/foundations/sheikha-os-integrated-v1.shk`؛ يعالجه مترجم لغة شيخة الحالي وينفذه في آلة افتراضية مستضافة على Node.js.
- المحرك: `core/os/sheikha-os-integration-v1.cjs`؛ يشتق العقود الستة عشر من المصدر، يفحص الأنواع والتنفيذ، ويقرأ حالة آثار الإقلاع السابقة دون إعادة الإقلاع.
- الفحص: `node tools/environment/sheikha-os-integration-v1.cjs`؛ الخيار `--write` يحفظ تقريرًا محليًا في `runtime/sheikha-os-integration/v1/verification.json`.
- المراقبة: تجربة بيانات اصطناعية محلية تثبت اكتشاف `STALE_DATA`؛ ليست مراقبة مستمرة أو اتصالًا بمستشعر مادي.
- البحث: أحد عشر قالبًا بمتطلبات محددة؛ تشغيل قالب التخطيط لا يثبت تنفيذ دراسة علمية.

## المنهجية والإثبات
يبدأ كل برنامج بسؤال محدد، ومصادر مأذونة، وفرضية أو هدف قابل للقياس، وبروتوكول مناسب، وتجربة أو جمع بيانات، وتحليل وحدود استنتاج، ثم مراجعة مستقلة. يختار الباحث المنهج الملائم من الوصفي والتجريبي والإحصائي والاستقرائي والاستنباطي والمقارن والتاريخي والنوعي والمختلط والمحاكاة والمراجعة المنهجية.

تسجل وحدات القياس والمعايرة والزمن وعدم اليقين ومصدر البيانات. تفصل البيانات الاصطناعية عن الميدانية، والارتباط عن السببية، والنتيجة عن التفويض. SHA-256 يربط السجل بمحتوى محدد، ولا يثبت صحة ادعائه أو استحقاقه الشرعي. اعتماد جميع المنهجيات أو تحقيق AGI/ASI غير مثبت.

## القواعد الداخلية المقترحة
رفض التفويض المجهول، وعدم منح المولد سلطة اعتماد مخرجاته، وحفظ الخصوصية، وإبقاء القرارات المالية والعقود والصلاحيات المادية ضمن مسارات مراجعة منفصلة. القواعد التنظيمية هنا سياسات مشروع مقترحة؛ ليست تشريعات نافذة أو شهادة امتثال.

لا يغير محرك الفحص الخدمات أو الشبكات أو الأقراص، ولا ينفذ شراءً أو نشرًا أو حركة مادية. ولا يعيد المراحل التاريخية المسجلة `RERUN_ALLOWED=false`.

## النتيجة الحالية
نجح اختبارا التكامل المخصصان. تحقق الفحص المحلي من العقود والتنفيذ وقوالب البحث واكتشاف البيانات القديمة، وقرأ سلامة آثار النموذج الأصلي وسجل إقلاعه السابق. لم ينفذ إقلاعًا جديدًا. النواة الأصلية نموذج تطوير محدود، وجاهزية بديل كامل لـLinux هي `false`؛ يلزم استكمال العزل والتخزين والشبكات والمشغلات والواجهة والتوافق والاستعادة مع أدلة مستقلة.
