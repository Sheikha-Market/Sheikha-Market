# منظومة شيخة الصناعية

تاريخ الإضافة: 2026-10-20، بتوقيت الرياض.

## الرؤية وحدودها

نحو أوسع منظومة صناعية وأكثرها نفعًا وخيرًا وكرمًا، بخدمة الإنسان وحفظ الموارد.
هذه رؤية طموحة وليست إثباتًا للأكبر عالميًا أو كونيًا، أو ادعاء امتلاك منشآت أو قدرة على إنتاج كل شيء.
النطاق الحالي تخطيط محلي قابل للتوسع، وليس تصنيعًا أو تشغيلًا أو اعتمادًا هندسيًا.
مرجعية العمل الكتاب والسنة وقيم الصدق والعدل والأمانة، مع مراجعة مؤهلة عند الحاجة دون فتوى آلية.

## البنية

- عنقود صناعي: مجمعات ومزارع موارد وفوندري مشترك وخدمات وبحوث.
- مزرعة صناعية: وحدات موارد متكررة ومعالجة ومراقبة وصيانة مشتركة؛ تشمل التصورات الزراعية والحوسبية والموارد بحسب القطاع.
- فوندري: تصميم وتأهيل وخلايا إنتاج ومختبر تحقق، مع اختلاف التنفيذ بين المواد والإلكترونيات والإنتاج الرقمي.
- مجمع صناعي: مصانع ومرافق ومستودعات وخدمات متكاملة.
- خط إنتاج: محطات عمل ونقاط فحص وتسليم وتتبع.

القطاعات الاثنا عشر: المعادن، الغذاء، الطاقة، المياه، الإلكترونيات، الروبوتات، البرمجيات، المرئيات، التدوير، البناء، اللوجستيات، وبحوث الصناعة الفضائية.
التوافق بين القطاع والبنية محدد في السجل؛ ليست كل البنى صالحة لكل قطاع.
أفق البحث الفضائي يحوّل مراحل أي قطاع إلى دراسة بحثية فقط. قطاع الصناعة الفضائية لا يقبل أفق الإنتاج الأرضي.
لا توجد وصفات تشغيل أو معاملات هندسية معايرة أو إجراءات إطلاق أو تحكم بالأجهزة.

## التطبيق

- النواة: `core/industrial/sheikha-industrial-planner-v1.cjs`.
- الواجهة: `/workspace/industry.html` ضمن خادم مساحة العمل المحلي.
- `GET /api/sheikha/workspace/v1/industry/catalog`: السجل وحدود الادعاءات والمؤشرات.
- `POST /api/sheikha/workspace/v1/industry/plan`: مسودة بمدخلات محددة، خلف حواجز المضيف والأصل والجلسة وحدود الحجم والمعدل القائمة.
- روابط محلية للفوندري والروبوتات والسوق والمرئيات. لم تُضف أدوات MCP أو صلاحيات جديدة، ولم تُغير إعدادات GPT/Codex.

المدخلات: اسم المشروع، نوع البنية، القطاع، الأفق، عدد المخرجات 1–1000000، فترة التخطيط 1–3650 يومًا، وحصة المنفعة المجتمعية 0–100 بالمئة.
تُرفض المفاتيح الزائدة والقيم الكسرية أو غير المحدودة ومحاولات تمرير موافقات أو أوامر أو عناوين تنفيذ.
المخرجات تشمل معرّفًا مستقلًا ومراحل مترابطة وموارد غير متحققة ومسؤولين غير معينين ومراجعات معلقة.

المعدل اليومي = سقف (المخرجات المستهدفة / الأيام).
الحصة المجتمعية = أرضية (المخرجات المستهدفة × النسبة / 100).
هذه قسمة لأهداف المستخدم وليست محاكاة سعة أو توقع تسليم. لا تشمل التوقفات والعائد والقيود الفعلية أو تقييم قابلية التنفيذ.
لا تُختلق قدرة أو تكلفة أو موعد فعلي أو نتيجة قياس.

## المراجعة والتحسين

توجد مراجعات للنطاق والجدوى، والهندسة والجودة، والسلامة والبيئة، والحقوق والحوكمة، ثم الإذن المحدد بالتجربة أو التسليم.
إنشاء المسودة لا يجيز أيًا منها، ولا توجد واجهة لتحويلها آليًا إلى موافقات.
المؤشرات: النفع، إتاحة المنفعة المجتمعية، الإتقان، حفظ الموارد، السلامة والحقوق، والنمو المتحقق. القياسات الحالية فارغة وليست أصفارًا تجريبية.

Watch الصناعي مقترح لمراجعة يومية، غير مجدول وغير موصول بمستشعرات.
Guard هنا وصف لبوابة أدلة، وليس متحكم سلامة أو إيقافًا ماديًا.
مراقب حوكمة البيئات السابق مستقل عن هذا المخطط ولا يشغّل المصانع.

المسودة في ذاكرة الصفحة فقط وتختفي عند التحديث؛ يمكن تنزيل JSON صراحة.
لا تخزين خادمي ولا نشر ولا دفع ولا رسائل موردين ولا استدعاء مزود خارجي.
الأصول البصرية الأصلية لم تتغير.

## التحقق

```bash
node --test --test-concurrency=1 tests/sheikha-industrial-planner-v1.test.cjs tests/sheikha-industrial-planner-browser.test.cjs tests/sheikha-workspace-preview.test.cjs tests/sheikha-workspace-browser.test.cjs tests/sheikha-industrial-network-v1.test.cjs
```

اختبار المتصفح يستخدم Playwright وChrome المحليين، ويلتقط مرئيات عند عروض 1440 و390 و320 بكسل.
اختبارات HTTP تحتاج السماح بالاستماع على loopback، ولا تتصل بمزودين خارجيين.
حزمة التحقق المحددة أعلاه: 20 اختبارًا، وتشمل التخطيط الجديد والشبكة الصناعية ومساحة العمل القائمة. ليست اختبارًا شاملًا لكل المستودع.
لتشغيل المعاينة: `node tools/preview/sheikha-workspace-preview.cjs`؛ يختار الخادم منفذًا متاحًا عند انشغال الافتراضي ويطبع الرابط.
