1. اختيار مسار SDK المقصود وإعداد تعديل محدد لـPATH وcompletion مع نسخة احتياطية؛ ثم التحقق في shell جديد من المسار والإصدار الفعليين. لا حاجة لحذف النسختين اعتمادًا على هذه القراءة.

3. بعد التحقق من المصدر واكتمال الملفات، اختبار إصدارات العملاء محليًا فقط وتثبيت المكونات اللازمة للعمل المطلوب. تتبع إدارة المكونات طريقة تثبيت SDK؛ يوضح ذلك [مرجع Google للمكونات](https://docs.cloud.google.com/sdk/docs/components).
4. لإثبات التكامل، إجراء عملية حساب قرائية محددة لكل خدمة مطلوبة وتسجيل وقتها ونتيجتها ونطاقها دون أسرار. لا تتحول أسماء الخدمات الستة إلى صلاحيات مثبتة بمجرد إدراجها في catalog.
