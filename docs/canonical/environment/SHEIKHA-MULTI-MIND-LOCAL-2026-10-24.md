# عقول شيخة: التشغيل المحلي المحكوم

تاريخ التحقق: 2026-10-24، بتوقيت الرياض. النطاق: إصلاح الوحدة الموجودة وربط وظائف محلية محددة وحفظ تعريفات الأدوار. ليست هذه شهادة تفعيل نماذج ذكاء أو وكلاء موزعين أو أجهزة أو بيئة إنتاج.

## ما تغيّر

كانت `runtime/minds/sheikha_multi_mind_matrix.js` تنشئ 58 خانة لكل دور، وتعلن تنفيذ أي أمر دون تنفيذه، وتسمح بإضافة خانات بلا سقف. وكان `routes/minds.js` يعرض أوامر GET غير محمية، لكنه غير مربوط بالنسخة الحالية من البوابة. أُصلحت الوحدتان في مكانهما مع الحفاظ على مفاتيح الأدوار العشرة القديمة وإضافة الحارس والمراقب والمحرر.

التغيير في `server.js` سطران فقط مقارنة بالنسخة المحلية المختبرة قبل هذه المهمة: محدد معدل ومسار `/api/minds` قبل محلل المدخلات القديم. لم تُستبدل تغييرات المستخدم الأخرى. يستعمل المسار سلسلة المصادقة نفسها في الكيرنل: مفتاح JWT مهيأ صراحة، ثم التحقق من الرمز، ثم صلاحية `admin`. لا تمنح الرؤوس أو حقول الموافقة صلاحيات.

## المعمارية

```text
Admin JWT / explicit local OS invocation
  -> fixed role/action allowlist + bounded JSON
  -> shared immutable kernel reference policy
  -> role-scoped deterministic computation or reviewable plan
  -> private locked state transaction + bounded metadata journal
```

المركزية هنا للسياسة والميزانية والقيد؛ فصل الأدوار محلي داخل العملية، لا توزيع تنفيذ بين أجهزة. لا صلاحيات تورث من GPT أو Codex أو من نصوص المرفقات. مرجعية الكتاب والسنة قائمة، مع `automatedReligiousCertification: false`؛ لا تصدر الوحدة حكمًا شرعيًا أو تحققًا من معاملات حقيقية.

كل عقل له معرف بوت جذري ثابت داخل سجل محدود يستعمل `SheikhaInfiniteAgentKernel`. الخلايا الإضافية تعريفات وليست عمالًا أو عمليات أو نماذج مدربة. سجل العقول منفصل عن السجل المؤقت لمسارات `/api/infinite-agent` و`/api/sheikha-kernel`؛ لا تُجمع أعدادها بوصفها وكلاء حيّة.

| الدور | الأمر | النتيجة الفعلية |
| --- | --- | --- |
| `governor`, `guardian` | `review-operation` | قرار رفض للعمليات الخارجية وتغيير السياسة؛ مقترح للعمليات المحلية المعروفة |
| `trader` | `compare-offers` | حساب تكلفة عروض ومخزون من مدخلات المستخدم، دون طلب شراء |
| `scholar` | `summarize-sample` | إحصاء وصفي محدود، دون استنتاج سببي |
| `scholar`, `heavens_earth`, `cosmic`, `omni` | `research-plan` | خطة بحث، والنتيجة العلمية `UNKNOWN` |
| `ceo` | `work-plan` | خطة توزيع مهام مسموحة، دون إرسال متكرر أو تفويض آلي |
| `strategist` | `roadmap` | مراحل مراجعة ضمن أفق زمني محدود |
| `engineer` | `kernel-self-test` | تشغيل الفحص المحلي المعزول للمكونات الموجودة |
| `earth` | `simulate-water` | محاكاة اتزان مائي اصطناعية |
| `watch` | `status` | قراءة سجل العقول عند الطلب، لا مراقبة مستمرة |
| `editor` | `prepare-change` | قائمة خطوات مراجعة، دون كتابة كود أو إنشاء رقعة |

`executed: true` يعني استدعاء دالة حسابية محلية فقط. التخطيط والرفض يعيدان `executed: false`. لا استدعاء shell أو كود حر أو مزود أو نشر أو تداول أو تحريك أجهزة. `omni` دور بحثي عام، وليس تصريحًا شاملًا. إضافة تخصص جديد تحتاج تعديل الكتالوج واختبارات وحدوده؛ لا يُقبل تحميل دور أو أداة من الطلب.

## الحفظ والحدود

- البداية 13 تعريفًا، بحد إجمالي 128، وحد 16 لكل دور، وإضافة حتى 8 في الطلب الواحد. الأعداد تشمل الجذر. لا توجد حلقة تكاثر أو خدمة خلفية.
- التخزين الخاص في `runtime/private/minds`، مع صلاحيات `700` للمجلد و`600` للسجل، وكتابة ذرية وقفل مشترك بين العمليات باستعمال مخزن المشروع الموجود. لا يكتب استيراد الوحدة أو GET أي حالة.
- يحتوي السجل المخطط والأعداد وآخر 128 ملخص عملية فقط، بحد 64 KiB. لا تُحفظ نصوص الأسئلة أو العروض أو نتائجها أو رموز الدخول. لا تحفظ آلية الحفظ أوزان نموذج أو ذاكرة محادثة.
- يقرأ كل طلب الحالة الأحدث تحت قفل الكتابة عند التعديل. فشل القفل أو فساد الملف يمنع العملية، دون إعادة ضبط صامتة أو انتقال إلى سجل في الذاكرة.
- إذا بقي `.write-lock` بعد انهيار عملية، يُراجع المشغّل مالك الكتابة والعمليات أولًا. لا تحذف الوحدة القفل تلقائيًا.
- رفض الروابط الرمزية والملفات غير العادية لا يعزل النظام عن مستخدم محلي يملك تعديل مجلداته. السجل قابل للتعديل وغير موقّع، وليس ختمًا أو سجل تدقيق غير قابل للعبث.
- بقاء الحالة بعد إعادة العملية مشروط ببقاء الملفات. قرص حاوية مؤقت لا يضمن بقاء الحالة بعد استبدالها؛ لا يوجد تخزين موزع أو نسخ احتياطي سحابي هنا.
- ملفات `private` مستبعدة من Git وسياق الحاوية والنشر الحاليين، وخارج مجلدي الملفات الثابتة `public` و`docs`.

## الاستخدام

تم تنفيذ التهيئة المحلية فعليًا وحُفظت 13 خانة عند المراجعة 1، ثم قُرئت من عملية مستقلة. لا يبدأ الأمر التالي خادمًا ولا يحتاج جلسة سطح مكتب أو مفاتيح مزود:

```bash
node tools/runtime/sheikha-minds.cjs status
```

`node tools/runtime/sheikha-minds.cjs initialize` يحفظ الحالة الحالية دون إعادة الأعداد إلى البداية؛ إعادة استدعائه تضيف ملخص تهيئة آخر. صلاحية CLI هي صلاحية حساب نظام التشغيل، وليست رمز JWT ضمنيًا.

كل المسارات التالية تتطلب مديرًا، بما فيها القراءة:

| المسار | الجسم |
| --- | --- |
| `GET /api/minds/status` | لا شيء |
| `GET /api/minds/:mind/status` | لا شيء |
| `GET /api/minds/journal` | لا شيء |
| `POST /api/minds/initialize` | `{}` |
| `POST /api/minds/replicate` | `{"mind":"engineer","count":2}` |
| `POST /api/minds/:mind/command` | `{"action":"...","input":{...}}` |

طلبات POST تتطلب `application/json` بحد 16 KiB، ولا تُقبل معاملات query أو الحقول الإضافية. لا تنفذ GET الأوامر. التكرار POST ليس مفتاح idempotency؛ لا تُعد طلب زيادة الخلايا تلقائيًا عند انقطاع الاتصال دون فحص العدد الحالي.

مثال جسم إلى `POST /api/minds/scholar/command`:

```json
{"action":"research-plan","input":{"question":"كيف نختبر نموذج الاتزان المائي؟","method":"simulation","evidenceIds":[]}}
```

مثال إلى `POST /api/minds/trader/command`:

```json
{"action":"compare-offers","input":{"quantity":5,"offers":[{"id":"offerA","unitPriceMinor":100,"shippingMinor":20,"availableQuantity":10,"leadDays":2}]}}
```

المقارنة بوحدات نقدية صغرى صحيحة وبعملة واحدة يحددها المشغّل لجميع العروض؛ لا تحويل عملات ولا تحقق من المورد أو الأسعار أو الضرائب أو إبرام عقد. تكلفة المثال 520 وحدة صغرى.

## التحقق

- 63 اختبار Node نجحت، تشمل 21 اختبارًا جديدًا للعقول ومساراتها، دون تخطٍّ أو إخفاق في التشغيل النهائي.
- 21 اختبار Python لسياق البناء نجحت. السياق 2930 ملفًا و75,526,566 بايت، بلا ملفات `private` أو نتائج حجب مانعة.
- بناء Node 20 محلي دون شبكة، ثم 78 فحص HTTP ناجحًا داخل حاوية بلا شبكة أو منافذ منشورة أو مجلدات مضيف. نجح حفظ الحالة وقراءتها من عملية ثانية داخل الحاوية، مع خروج الخادم بصفر وحذف الحاوية المؤقتة.
- فُحص تطابق بصمات 2930 ملفًا مع السياق المختبر بعد التنفيذ؛ لا اختلاف. تعريفات العقول المحلية بقيت 13؛ الزيادة إلى 15 كانت في حاوية الاختبار المحذوفة فقط.
- منع العزل منافذ loopback في المحاولة الأولى؛ أُعيدت اختبارات HTTP بإذن المضيف. صُحح أيضًا إرسال حمولة prototype في اختبار واحد لتصل كسلسلة JSON خام، ثم اجتازت المجموعة كاملة.

الحاوية المحلية: `localhost/sheikha-main-portal:minds-local-20261024`، المعرّف `3bd1613d4b8e7cdc3e199886b103665097cdda1b7681d730793de09e1f431497`. الاختبار استخدم `SHEIKHA_ENABLE_ALL_ENGINES=false`؛ لا يثبت نجاح جميع الخدمات الاختيارية أو جاهزية الإنتاج.
