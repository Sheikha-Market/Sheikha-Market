# Sheikha Technical Experience Runtime V1

## الغرض

تربط هذه الطبقة كتالوج منتجات شيخة بشرح علمي وهندسي متعدد المستويات،
ومرصد تقني يعرض قياسات العملية المحلية دون تحويل القياس إلى وعد تسويقي.

## الواجهات

- `/technology/`: مرصد التقدم التقني، المعمارية، القياسات، ومسار SSE الحي.
- `/product-technical/`: شرح المنتج ومدخلاته ومخرجاته ومعادلاته ومصطلحاته.
- `/api/sheikha/technical-experience/v1`: مصدر الحالات والقياسات والملفات التقنية.

## مستويات الشرح

- `guided`: غرض المنتج، المدخلات، المخرجات، وخطوة البدء.
- `practitioner`: الواجهات، التكامل، المراقبة، والفشل والتعافي.
- `expert`: المعمارية، نماذج القياس، الحدود، وأدلة الاختبار.

العقد والحدود لا يتغيران بتغير مستوى الشرح؛ الذي يتغير هو عمق العرض والأدوات.

## القياس

يعرض المرصد زمن جولة طلب المتصفح وحجم الاستجابة ومعدل نقل الحمولة المشتق
من هذين القياسين. ويعرض الخادم ذاكرة عملية Node الحالية ومدة تشغيلها وتأخر
دورة أحداث مرصودًا في لحظة الطلب. هذه ليست نتيجة Benchmark شاملة للشبكة أو
الجهاز أو بيئة الإنتاج.

المعادلات المشتركة:

```text
L = t_done - t_start
T = B_transferred / delta_t
C_e = N_verified / N_required x 100
```

لكل منتج مقياس إضافي مرتبط بمجاله، ويُعرض بوصفه طريقة قياس لا نتيجة مختلقة.

## المركزية واللامركزية

المعمارية هجينة ومحكومة:

```text
Browser / Sector Adapter / Local Analyzer
                  |
                  v
Schema -> Governance -> Analysis -> Explanation -> Audit
                  |
                  v
        Governed Product Interface
```

الحوكمة والكتالوج والهوية والأدلة مركزية محليًا. قياس المتصفح وموصلات
القطاعات والتحليل المحلي ومستهلكو الأحداث عقد تنفيذ محدودة. لا يُدعى وجود
اتحاد خارجي أو تشغيل لامركزي عالمي دون دليل مستقل لكل بيئة.

## ملف ما بعد الشراء

المعاينة العامة لا تكشف ملف التشغيل الكامل. المسار الكامل يتطلب هوية موثقة
ومنحة نشطة في سجل الخادم مرتبطة بأمر شراء أو عقد موقع وحالة تحقق `VERIFIED`.
القيمة القادمة من المتصفح لا تمنح الاستحقاق.

يتضمن الملف المستحق عقود الواجهات وخطة النشر والفشل والتعافي والاختبارات
ونماذج القياس المتقدمة. الوضع الافتراضي هو المنع.

## حدود الادعاء والحوكمة

- لا شراء أو دفع أو عقد تلقائي.
- لا وصول عام إلى الملفات الكاملة.
- لا تنفيذ عالي الأثر دون مراجعة بشرية.
- لا فتوى آلية ولا ادعاء سلطة شرعية للبرنامج.
- لا ادعاء شهادة أو اعتماد خارجي دون جهة مانحة ودليل صالح.
- لا عرض لوصول النموذج بوصفه ناجحًا حتى يجري الاختبار اليدوي وتصل أحداث SSE.

تعكس الحوكمة مبادئ الصدق والأمانة والوفاء بالعقود والتثبت ومنع الضرر، مع
إحالة المسائل الشرعية الاجتهادية إلى أهل الاختصاص.

## التحقق

```bash
npm run -s ops:technical-experience:activate:v1
npm run -s ops:technical-experience:test:v1
npm run -s ops:site:catalog:v2
npm run -s ops:site:smoke:local:v1
```

توجد العقود والسجل والتقرير تحت `runtime/technical-experience/v1/`.
