# وزن شيخة المعرفي الفيزيائي

حزمة معرفية محلية تربط المقاييس والمادة والطاقة والكيمياء والاستقلاب والجسم والرؤية ودورتي الماء والكربون والمقاييس الفلكية. التعريفات والآليات ملخصات عربية أصلية مرتبطة بمصادر أولية من NIST وCERN وNASA وNIH وUSGS وnano.gov في `core/scientific-knowledge/knowledge.json`. لا تُنزّل الحزمة مصادرها أو نماذج أو بيانات تدريب.

طول بلانك نحو `1.616255e-35 m` مقياس نظري مميز وليس أصغر طول مثبت. نطاق النانو نحو `1–100 nm`؛ الجسيم الأولي النقطي في نموذج فيزيائي ليس روبوتاً مصنعاً. أمثلة الأحجام تقريبية ذات نطاق محدد؛ لا يوجد ادعاء بأصغر أو أكبر أو أقوى شيء مطلقاً. الرؤية الحيوية موضحة كآلية ضوء وشبكية وإشارة عصبية؛ فهم الصور برمجياً يحتاج بيانات ونموذجاً واختباراً مستقلين. محتوى الجسم والطاقة تعليمي دون وصفة طبية أو غذائية.

مرجعية المستخدم `BOUND_BY_QURAN_SUNNAH` محفوظة كمرجعية للمشروع. لا يمثل ذلك شهادة تدقيق علمي أو شرعي بنسبة 100%.

## الأوامر

من جذر المستودع، افحص الحزمة والسجل الحالي دون كتابة:

```bash
node tools/scientific-knowledge/sheikha-scientific-knowledge-v1.cjs
```

أنشئ ملف مقترحات جديداً بموافقة صريحة عبر `--output`، مع قراءة السجل الحالي كما هو:

```bash
node tools/scientific-knowledge/sheikha-scientific-knowledge-v1.cjs \
  --registry SHEIKHA-CORE/blockchain/registry.json \
  --output /tmp/sheikha-intelligence-profiles-new.json
```

الأمر يرفض ملف إخراج موجوداً، ولا يعدّل السجل أو المكافآت أو ملفاً مستخدماً. لا يبدأ تدريباً أو نشرًا أو اتصالات أجهزة. النتيجة تضم مقترحاً لكل سجل ولكل فئة، وحالتها جميعاً `requires_dataset_model_training`؛ حقول checkpoint والبيانات والرخصة والتقييم والمراجعة البشرية فارغة، والقدرات المعتمدة خالية. لا تعني هذه المقترحات امتلاك نموذج مدرّب لكل سجل.

تقبل القراءة قائمة سجلات أو `{weights:[...]}` أو `{records:[...]}` أو `{ledger:[...]}` أو قاموساً مسطحاً بمفتاح معرف لكل سجل. تُستخدم `category` ثم `family` عندما تكون موجودة؛ وما عدا ذلك مصنف `uncategorized` دون اختراع تخصص من الاسم. العد ديناميكي ويلائم نمو السجل. حد المصدر 8 MiB و20,000 سجل؛ الروابط الرمزية والمصدر المتغير والهوية المكررة والقيم غير المحدودة مرفوضة. لا تطبع الحزمة محتوى السجل أو بيانات أصحابه؛ المخرجات تحمل معرفاته وفئاته وبصماته فقط.

```bash
node --test tests/scientific-knowledge/scientific-knowledge.test.cjs
```

## البصمة والإسناد

`manifest.json` يحمل SHA-256 للتسلسل القياسي للمعرفة: مفاتيح كائنات مرتبة، ترتيب القوائم محفوظ، وترميز UTF-8. تغيّر المعرفة يتطلب مراجعة صريحة وتحديث البيان؛ لا تُحدّث البصمة تلقائياً أثناء القراءة. البصمة تكشف اختلاف المحتوى ولا تثبت هوية المؤلف أو صحة العلم أو تسجيلاً رسمياً للملكية الفكرية.

نسبة الإعداد إلى مشروع شيخة تصريح محلي عن ترتيب الحزمة والكود والملخصات. لا تشمل ملكية الحقائق الفيزيائية أو نصوص ومصنفات الجهات المرجعية. الروابط مرجع للمصدر، ولا تمنح رخصة تلقائية لإعادة توزيع محتواه. مصدر ملف البيانات في `dataset` ورخصة النموذج في `model` يحتاجان تحققاً مستقلاً قبل أي تدريب أو استخدام معتمد.

## التعدين والمسابك

تتضمن الحزمة ثلاث خطط مجال إضافية: التعدين الجيولوجي، المعادن والمسابك، والتعدين الحاسوبي للبيانات. تسند التعريفات إلى USGS وNIST، وتربط المقترحات بمهام فهرسة الأدلة وفحص الوحدات والبيانات المكانية. لا تعدّ مكامن مسجلة احتياطيات مثبتة، ولا تشغّل الحزمة استخراج خام أو أفراناً أو تعدين عملات أو إصدار رموز. عدد هذه الخطط الإضافية منفصل عن عدد مقترحات سجلات المستخدم وفئاتها.
