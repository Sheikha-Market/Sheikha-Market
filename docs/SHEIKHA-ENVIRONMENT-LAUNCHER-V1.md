# Sheikha Environment — بيئة التشغيل الأصلية التجريبية

مشغل محلي للنسخة الأصلية المحفوظة. الفحص: node tools/environment/sheikha-environment-v1.cjs --inspect. تشغيل تجربة VM عند اختيار المستخدم: node tools/environment/sheikha-environment-v1.cjs --boot-vm.

المشغل يفحص بصمات صورة الضيف، يستخدم QEMU وTCG و128MB، بلا شبكة وبوضع snapshot، دون ربط مجلدات المستخدم أو أقراصه المادية. ملفات OVMF والنتيجة وسجلserial داخل مجلد تجربة محلي خاص. تجربة محدودة30ثانية، وخروج33 متوقع بعد تنفيذ18عقدًا فيRAM. اسم VM هو Sheikha-Development؛ إعادة التسمية لا تجعل النظام مكتملًا.

لا واجهة سطح مكتب أو متصفح أو تطبيقات إنتاجية مكتملة ولا تخزين دائم وشبكة وعزل شامل. الضيف يشغل runtime أصليًا محدودًا؛ المضيف ما زال Pop!_OS/Node.js/QEMU. استبدال Pop!_OS الفعلي غير جاهز وغير منفذ. لا يثبت دليل VM تشغيلًا متواصلًا أو نظامًا عامًا كاملًا.

مسار الاستكمال: واجهات وتعريفات جهاز محدد، ذاكرة وعزل وجدولة، نظام ملفات دائم واستعادة، شبكة، محمل حزم وتوقيع، واجهة مستخدم، ثم تطبيقات وترحيل واختبارات قبول. لكل مرحلة دليل مستقل. التثبيت على جهاز فعلي يتطلب تحديد الجهاز ومراجعة النسخ الاحتياطي وخطة استعادة وموافقة مستقلة. مراحل RERUN_ALLOWED=false لا يعاد تشغيلها تلقائيًا.

هذه الجولة جهزت المشغل وفحصته فقط، ولم تُعد الإقلاع أو تثبت خدمة أو تغير قسمًا أو bootloader أو VPS. اختيار جهاز الهدف ما زال معلقًا.
