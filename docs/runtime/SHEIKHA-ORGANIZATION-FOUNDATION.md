# أساس شيخة التنظيمي

شيخة ليست تطبيقًا منفردًا فقط، بل منظومة ومنظمة جامعة لمنظمات متخصصة.

## الأصل
- شيخة: المنظومة الأم.
- منظمات شيخة: وحدات اختصاص تحت المنظومة.
- منظمة الأسواق: إحدى المنظمات الأساسية.
- سوق المدينة والأسواق الإسلامية: امتداد أصيل لمنظمة الأسواق.

## القاعدة
أي تطوير جديد يجب أن يحافظ على:
1. الهوية الأصلية لشيخة.
2. المرجعية الإسلامية.
3. تنظيم المنظمات داخل منظومة واحدة.
4. قابلية التطوير المستقبلي دون محو الأصل.
5. فصل المنظمات إداريًا وتقنيًا مع توحيدها تشغيليًا.

## المنظمات الأساسية
- منظمة الأسواق.
- منظمة التشغيل.
- منظمة التقنية.
- منظمة الحوكمة.
- منظمة القياس والمتابعة.
- منظمة الهوية.
- منظمة الخدمات.
- منظمة المعرفة.
