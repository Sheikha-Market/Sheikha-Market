# SHEIKHA_NATIVE_LANGUAGE_ARCHITECTURE_V1

## الهدف

تحويل لغة شيخة من لغة حوكمة وDSL مستضافة إلى لغة قادرة تدريجيًا على بناء
المترجم والمكتبة القياسية والنواة والخدمات. لا تعتبر هذه الوثيقة أو التقارير
الحالية النظام مكتملًا أو مستقلًا عن Node/Linux.

## المصدر المرجعي

المعمارية الأساسية مكتوبة في:

`sheikha-language/system/sheikha-sovereign-architecture-v1.shk`

ويمر المصدر عبر:

`Lexer -> Parser -> AST -> Type Check -> IR -> Bytecode -> Governed VM`

تدعم اللغة الآن تعريفين عربيين أصيلين:

```text
مرجعية القيم_العليا:
  الدور: قيم_وحدود_غير_تنفيذية
  الفتوى_الآلية: ممنوعة

سياسة الخير_والنفع_العام:
  يوجب: الصدق، العدل، الأمانة، الدليل
  يمنع: الضرر، الظلم، الغش، الخداع، الإكراه

منهج العربية_والعلوم_والاستدلال:
  علوم_العربية: النحو، الصرف، البلاغة، البيان
  علوم_الاستدلال: المنطق، الحجة، البرهان، الاستدلال
  منهج_الحساب: تعريفات، مسلمات، برهان، اختبار
  منهج_العلوم_التجريبية: ملاحظة، قياس، تجربة، تكرار
```

يعالج المترجم `مرجعية` و`سياسة` و`منهج` كعقد مستقلة في AST ثم
IR وBytecode. يسجلها الـVM كبيانات حوكمة، ويرفض المرجعية التنفيذية أو الفتوى
الآلية أو سياسة لا تتضمن الدليل ومنع الضرر والمراجعة البشرية للقرارات عالية الأثر.
كما يعالج `منهج` كتعريف أولي يفرض علوم العربية ومنهج البرهان والحساب
والتجربة وبيان درجة الثقة.

## الحوكمة

- الإيمان بأن الحكم لله وحده مرجعية عقدية وقيمية، وليس صلاحية تمنح للبرنامج.
- القرآن الكريم والسنة الصحيحة مرجعية قيم وحدود غير تنفيذية.
- النظام أداة برمجية لا يدعي الوحي أو العصمة أو السلطة الدينية.
- لا فتوى آلية، والمسائل الشرعية الملزمة يراجعها أهل العلم المؤهلون.
- الذكاء الصناعي للتحليل والاسترجاع والتخطيط والمساعدة فقط.
- الضرر والظلم والخداع وانتهاك الحقوق تمنع التنفيذ ولو ادعيت منفعة.
- لا تحول الآيات أو الأحاديث إلى تعليمات آلة، ولا تقبل نسبة نص أو حكم شرعي دون
  مصدر موثق ومراجعة مؤهلة.
- الاستدلال الشرعي له مصادره ومراجعته المؤهلة، والحساب له البرهان، والعلوم
  التجريبية لها الملاحظة والقياس والتجربة والتكرار. يمنع خلط هذه المجالات بلا
  دليل مختص.

## الحالة المثبتة

- يوجد مصدر معماري أصلي بلغة شيخة يترجم ويعمل في VM المعزول.
- توجد قواعد لغوية واختبارات نوع وتشغيل لمرجعية القيم غير التنفيذية وسياسة
  الخير والنفع العام.
- توجد قواعد لغوية واختبارات للعربية والنحو والصرف والبلاغة والبيان والحساب
  والمنطق والحجة والبرهان والاستدلال العلمي والشرعي المنضبط.
- يدعم المترجم حاليًا PHP وJavaScript وPython وJSON IR وBytecode.
- المترجم والـ VM مكتوبان حاليًا بـ JavaScript ويحتاجان Node.
- لا يوجد backend أصلي لإنتاج ELF أو UEFI أو machine code.
- بذرة Bare Metal الحالية مكتوبة بـ C وتملك دليل إقلاع QEMU، وليست نظام تشغيل
  عامًا مكتملًا بلغة شيخة.
- نسبة المصدر المكتوب بلغة شيخة تقاس آليًا في تقرير التفعيل ولا تستنتج من أسماء
  الملفات أو التقارير القديمة.

## الأساس العربي المتقدم السابق

التقرير الموحد يكتشف الآن العمل السابق بدل اختزاله في ملفات `.shk`:

- نواة اللغة العربية تحت `core/language/sheikha-arabic`، وتشمل Tokenizer وAST
  وIR ونظام أنواع وحسابًا عربيًا وBytecode وVM وVM V2 وRuntime وذاكرة وجدولة.
- طبقات اللغة V91 إلى V96: عنقود اللغة، والمترجم، والأنواع، والمكتبة القياسية،
  والـRuntime، ومدير الحزم.
- مكدس اللغة ومسارات SDK وCLI وIDE والإنتاج المسجلة في المستودع.
- اختبار تنفيذي يحول أمرًا محاسبيًا عربيًا إلى AST وIR وBytecode، ثم ينفذه في
  VM وVM V2 ويثبت القيد الناتج.
- اختبار حساب عربي فعلي يثبت أن `٢ زائد ٣` ينتج `5`، مع تطبيع
  الأرقام العربية والفارسية والغربية.

تصنيف هذا الأساس هو:

`ADVANCED_HOSTED_ARABIC_FOUNDATION_VERIFIED`

وهو أساس متقدم وفعال، لكنه مستضاف حاليًا على Node.js. هذا التصنيف مستقل عن
قياس نسبة الشيفرة المكتوبة بلغة شيخة نفسها، ولا ينفي الإنجازات السابقة ولا
يدعي في الوقت نفسه اكتمال المترجم الذاتي أو backend أصلي للآلة.

## خريطة التحول

1. تثبيت المصدر المعماري وعقد الحوكمة بلغة شيخة. مكتمل كأساس قابل للاختبار.
2. تثبيت Lexer وParser وTypes وIR وBytecode وVM الحاليين. مكتمل على Node كمرحلة bootstrap.
3. كتابة مترجم شيخة بلغة شيخة وتحقيق bootstrap متكرر ومتطابق.
4. إضافة backend أصلي موثق لإنتاج machine code وELF/UEFI.
5. بناء مكتبة قياسية وHAL وذاكرة وجدولة وأمن وتخزين وشبكة.
6. نقل النواة والتعريفات من C إلى لغة شيخة تدريجيًا مع اختبارات تكافؤ.
7. نقل خدمات المنصة من JavaScript إلى لغة شيخة حسب سجل الأولوية والمخاطر.
8. إزالة Node/Linux من مسار النواة بعد نجاح الإقلاع والتعافي والتأهيل.
9. تأهيل x86_64 وAArch64 على QEMU ثم على أجهزة فعلية مصرح بها.
