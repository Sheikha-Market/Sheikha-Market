# SHEIKHA ENTERPRISE WORKSPACE V1

## الهدف

توحيد واجهات شيخة داخل مساحة عمل مؤسسية واحدة بدل صفحات منفصلة.

## القاعدة

- Human Mode هو الوضع الافتراضي للمستخدم التجاري.
- Developer Mode للمطور والمدير التقني.
- JSON لا يظهر للمستخدم النهائي إلا عند فتح الوضع المتقدم.
- جميع الوحدات تعمل تحت Shell موحد.

## الوحدات

- لوحة القيادة
- التجارة
- معرفة المنتجات
- الحوكمة
- Sheikha IDE
- التكاملات
