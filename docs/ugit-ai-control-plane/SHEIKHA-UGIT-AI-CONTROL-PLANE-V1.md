- لا حوسبة فعلية بلا دليل عتاد أو عقد مزود.
- لا إنفاق سحابي بلا موافقة ميزانية.
- لا معالجة بيانات عملاء بلا عقد وحقوق بيانات.
- لا نشر نموذج بلا تقييم ومراقبة.
- لا ادعاء KPI خارجي بلا قياس موثق.

- لا اختيار مزود أو GPU بلا سجل مزود وعقد وميزانية.

- لا اعتبار التشغيل التجاري الحقيقي مكتملًا قبل وجود عميل وعقد ودفع ومزود موثق.
