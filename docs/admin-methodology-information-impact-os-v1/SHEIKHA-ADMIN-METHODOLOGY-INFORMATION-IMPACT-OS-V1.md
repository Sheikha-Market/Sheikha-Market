الدائرة:
معلومة → تحقق → تصنيف → أثر → قيمة → قرار → تنفيذ → قياس → تحسين → معرفة

القيم:
اقتصادية، تجارية، فنية، تنموية.

الضوابط:
لا معلومة بلا مصدر.
لا بيانات خاصة بلا إذن.
لا قرار عالي الأثر بلا مراجعة بشرية.
لا تنفيذ بلا صلاحية.
ولا حول ولا قوة إلا بالله.
