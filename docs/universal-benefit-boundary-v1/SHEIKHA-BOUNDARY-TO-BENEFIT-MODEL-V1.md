# نموذج شيخة العربي لتحويل الحد إلى منفعة آمنة V1

## حالات الحد

`WITHIN_BOUNDARY`: الطلب ضمن الحد المأذون، فيمر إلى بوابة التفويض التالية دون أن يكتسب إذنًا تلقائيًا.

`AT_BOUNDARY`: الطلب عند الحد، فيحتاج موافقة أو دليلًا أو عزلًا أو تقليل بيانات أو ميزانية أو صيغة وصول أو مراجعة مختص.

`BEYOND_BOUNDARY`: الطلب خارج الحد، فيمنع التنفيذ ويعاد بديل آمن.

لا تمنح أي حالة تصعيد صلاحية أو كتابة خارجية.

## أنواع النطاق التشغيلي

`INTERNAL`: داخل نطاق ملكية وثقة وتشغيل محدد، مع الإذن والدليل ومنع الضرر.

`EXTERNAL`: عبور إلى مالك أو مؤسسة أو شبكة أو ولاية أخرى، ويحتاج تفويضًا بشريًا صريحًا وهوية وتشفيرًا وأقل صلاحية.

`CROSS_BOUNDARY`: اتصال مخطط بين الداخل والخارج عبر محول وبوابة سياسة وعقد بيانات وتدقيق ورجوع.

هذه نطاقات تقنية قابلة للقياس وليست تعريفًا لحدود الله أو حكمًا بالحلال والحرام. البرنامج يحيل طلب الحكم الشرعي إلى أهل العلم المؤهلين ولا يصدره.

## مسارات التحويل

| الحالة | التحويل النافع الآمن |
| --- | --- |
| غياب الإذن | طلب موافقة محدد النطاق |
| نقص الدليل | «غير معلوم» مع بحث محلي، وخطة مصادر وإسناد وقياس ومراجعة |
| ارتفاع الخطر | عزل أو محاكاة أو قراءة فقط |
| وجود بيانات شخصية | تقليل وإخفاء هوية ومدة احتفاظ |
| غياب الأداة | تقرير متطلبات وخطة بديلة |
| عدم دعم العتاد | محاكاة بلا ادعاء دعم أصلي |
| ارتفاع التكلفة | بوابة ميزانية وتجربة صغيرة |
| غياب الاتصال | تشغيل محلي وتأجيل المزامنة |
| حاجز الوصول | عربية وRTL ونص وصوت وCLI وAPI وواجهة مبسطة |
| احتمال الضرر | إيقاف وتحذير وتعاف وإصلاح وإحالة بشرية |
| الأمن الدفاعي | نطاق مأذون وحفظ أدلة وإصلاح مسؤول |
| قرار عالي الأثر | إنسان مسؤول ومختص مؤهل ومسار اعتراض |
| مشاركة بشرية بلا رضا أو حق انسحاب | منع المشاركة وحفظ الكرامة |

| المطلوب أعلى من المتاح | محاكاة وتحديد المقدار عند المتاح الموثق |
| اتصال خارجي بلا تفويض | مراجعة دون اتصال أو نقل بيانات |

## مسار المقدرة إلى المنفعة

1. تسجيل القدرة والغرض والمالك والنطاق.
2. تصنيف نوع المقدرة دون معاملة الإنسان كمورد.
3. التحقق من الرضا والملكية والإذن.
4. التحقق من المقدار والوحدة والدليل وخط الأساس.
5. فحص الضرر والخصوصية والعدالة والميزانية.
6. تحديد مسار داخلي أو خارجي بأقل صلاحية.
7. إنشاء خطة اتصال وعقد مدخلات ومخرجات وتدقيق ورجوع.
8. تسليم الخطة إلى الإنسان وبوابة تفويض منفصلة.

لا تنتج هذه الخطوات طاقة فيزيائية ولا تنفذ اتصالًا. «تحويل المقدرة» يعني إعداد تخصيص تشغيلي قابل للقياس، أما الطاقة الفيزيائية فتحتاج قياسًا هندسيًا خاصًا.

## قاعدة الدليل

الإشارة غير المتحقق منها ليست دليلًا موثقًا. عند غياب الدليل المطلوب يكون القرار `REVIEW` وحالة الدليل `UNKNOWN`، وتبدأ المنظومة بحثًا منضبطًا دون تخمين. المصدر الذي عُثر عليه يبقى مرشحًا حتى تثبت سلامة النص والمصدر والإسناد عند انطباقه والسياق والاستدلال والقياس، ثم يعتمد الإنسان المؤهل النتيجة.

النص الشرعي لا يستخدم بديلًا عن القياس التجريبي لدعوى تقنية، والقياس التجريبي لا يتحول إلى وحي أو تفسير شرعي. البحث الخارجي لا ينفذ إلا بموصل واتصال مأذونين، ويصرح النظام بما نُفذ وما بقي مؤجلًا.

## قاعدة التنفيذ

واجهتا التقييم وتحويل الحد بوابتان استشاريتان للحوكمة. حتى قرار `ALLOW` يعيد `executionAllowed: false` و`decisionGrantsAuthorization: false`. يلزم مسار تنفيذ منفصل يتحقق من الهوية ورمز القدرة والسياسة الحالية والموافقة وخطة الرجوع والتدقيق.

## قاعدة المرجعية

الكتاب والسنة الصحيحة مرجعية قيمية مكتوبة للعقد. النص الشرعي لا يتحول إلى شيفرة حكم ملزم، والمسألة الشرعية تعرض على أهل العلم المؤهلين.
