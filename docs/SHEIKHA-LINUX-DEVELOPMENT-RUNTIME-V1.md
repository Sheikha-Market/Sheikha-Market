# شيخة — تشغيل تطوير على Linux

الخدمة `tools/environment/sheikha-linux-development-runtime-v1.cjs` تربط لوحة قراءة محلية بقدرات ثبت تنفيذها محليًا؛ لا تمنح اعتمادًا خارجيًا.

التشغيل: `node tools/environment/sheikha-linux-development-runtime-v1.cjs`.
العنوان: `http://127.0.0.1:39731`، والقياسات: `/status`.

تقيس الذاكرة وحمل Linux كل خمس ثوان؛ تعرض حالة مترجم شيخة، و16 طبقة معمارية، و11 خطة بحث، وسلامة آثار الإقلاع السابقة. تجربة مراقبة الحمولات اصطناعية ومنفصلة عن القياسات الحقيقية لLinux. لا اتصال بمستشعر مادي أو إقلاع أصلي جديد.

تقبل GET فقط وترفض Host أو Origin الخارجي. هذه القيود لتقليل الوصول العرضي من صفحات خارجية وليست مصادقة مستخدم؛ أي عملية محلية تستطيع قراءة الخدمة. لا تستخدمها لبيانات حساسة ولا تنشرها على الشبكة.

جلسة التطوير تنتهي تلقائيًا بعد 60 دقيقة، وتنتهي عند إيقاف العملية؛ ليست خدمة دائمة أو مراقبة 24/7. لا تعيد تشغيل خدمة موجودة ولا تثبت حزمًا أو تغير النواة أو الجدار الناري. تشغيل دائمي مستقل يتطلب اختيار طريقة الإدارة ونطاق الخدمة وتأهيلها.

لوحة SDP عند /sdp-dashboard تعرض النطاق الداخلي ونتائج مراجعة آثار البناء وسجل المراقبة المحفوظين. البيانات عند /sdp. العرض عند الطلب، بكاش خمس ثوان، ولا يعيد تشغيل البناء أو جلسات المراقبة؛ الأدلة غير المتاحة تعرض UNKNOWN دون تفاصيل مسارات خاصة.

قياس خدمة المضيف: /service-health، ويُعرض أيضًا في /sdp-dashboard. الوجهة مثبتة على 127.0.0.1:8080/health وGET فقط، لا تقبل عنوانًا من المستخدم ولا تحفظ جسم الرد، والمهلة ثانيتان. رمز 200 مشاهدة لاستجابة HTTP فقط. خيار --preview يشغّل جلسة منفصلة على 39732 لمدة ساعة دون إيقاف جلسة 39731.

التسجيل المحلي: فحص GET عند الطلب قد يكتب سجل مشاهدة محدودًا في runtime، لكنه لا يعدل الخدمة المفحوصة أو إعدادات التشغيل. يعرض /service-history آخر 20 قياسًا، مع حد 720 قياسًا للجلسة وحالة الحفظ. الخدمة واجهة قراءة وتحفظ سجلات قياس محلية؛ ليست عديمة الكتابة إلى القرص.

أرشيف القياسات: /service-archive يقرأ سجلات القرص بعد انتهاء جلساتها. خيار --auto-port يطلب منفذًا محليًا متاحًا من النظام ويطبع العنوان الفعلي، مع مدة الجلسة المعتادة ساعة ودون إيقاف خدمة قائمة.
