### **الخطوة 2: إعداد Zapier (10 دقائق)**

```bash
# Step 1: إنشاء حساب Zapier مجاني
1. اذهب: https://zapier.com
2. اختر "Sign Up"
3. استخدم Gmail الخاص بك: hello@sheikha.cloud
4. اختر "Free Plan"
5. تحقق من البريد

# Step 2: إنشاء Zap جديد
1. اختر "Create Zap"
2. اختر "Google Sheets" كـ Trigger
3. اختر "New Row" (جديد صف)
4. ربط حسابك (الموافقة على الصلاحيات)

# Step 3: Trigger Configuration
الحقول:
├─ Drive: "My Drive"
├─ Spreadsheet: "Sheikha Email Campaign"
├─ Worksheet: "Sheet1"
└─ حفظ واختبار

# Step 4: إضافة Action (Gmail)
1. اختر "Add Step"
2. اختر "Gmail"
3. اختر "Send Email"
4. ربط حسابك (hello@sheikha.cloud)

# Step 5: Email Configuration
الحقول:
├─ To: (من Google Sheet Column) = Email
├─ Subject: (من Google Sheet Column) = Subject
├─ Body: (من Google Sheet Column) = Message
└─ حفظ واختبار

# Step 6: تفعيل الـ Zap
✅ اضغط "Turn on Zap"
✅ الآن كل صف جديد = بريد فوري!
```
