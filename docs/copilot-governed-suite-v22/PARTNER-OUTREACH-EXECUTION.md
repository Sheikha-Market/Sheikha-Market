## 9. Email Sending Safety Checklist

### Deliverability Best Practices

- [ ] **SPF/DKIM/DMARC Configured**
  - Sender domain has valid SPF record
  - DKIM signature on all outgoing emails
  - DMARC policy set to "quarantine"

- [ ] **Warm-up Complete**
  - Don't send 1,000s of emails from new domain
  - Start with small batches (10-20)
  - Ramp up volume gradually over days

- [ ] **Recipient Validation**
  - No typos in email addresses
  - Remove duplicates
  - Verify no inactive/bouncing addresses

- [ ] **Content Optimization**
  - No spam trigger words ("FREE", "URGENT", "ACT NOW")
  - Avoid excessive links/attachments
  - Use text-only formatting (no HTML tricks)
  - Keep line length reasonable
