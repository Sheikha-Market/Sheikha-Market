## ⚠️ TROUBLESHOOTING

**Problem**: "Email looks broken (formatting issue)"
- **Solution**: Gmail might have changed formatting
- **Fix**: Send plain text version instead

**Problem**: "Attachment too large"
- **Solution**: Files might be > 10 MB total
- **Fix**: Send 2 files, then follow up with 3rd file

**Problem**: "Bounced email (recipient not found)"
- **Solution**: Email address is wrong
- **Fix**: Check recipient email via LinkedIn or Google

**Problem**: "Spam folder (Gmail thinks it's spam)"
- **Solution**: This can happen with bulk sends
- **Fix**: Include unsubscribe link, write more personal tone
