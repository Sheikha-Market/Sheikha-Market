# Sheikha VS Code Extension Experience Apex V1

The extension is the highest governed developer-experience surface, not an authority above
governance. It consumes the conversation stack, Orchestrator Fabric, Layer Governance L18,
Enterprise Management OS, SDK/Fabric/MCP, Git, workspace context, and the Enterprise Inspector.

Normal chat is conversational and contextual. Enterprise Inspector remains in the background
and appears in chat only for an explicit system-health request. Short session history is kept
inside the webview process for continuity and is not persisted unless the user grants memory
consent.

Vitality means responsive, contextual, useful interaction. It does not mean consciousness,
human feeling, hearing, sight, unseen knowledge, AGI, or ASI.
