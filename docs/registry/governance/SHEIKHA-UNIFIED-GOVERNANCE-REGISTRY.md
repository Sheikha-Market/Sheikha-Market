# 5. قواعد الحوكمة

## 5.1 منع التنفيذ غير المصنف

أي Runtime أو Script أو Layer غير مصنف:
- لا يدخل الإنتاج
- لا يعمل تلقائيًا
- لا يتم دمجه

---

## 5.2 منع التوسع غير المنضبط

أي توسع جديد يجب أن يمر عبر:

- Ownership
- Classification
- Validation
- Isolation
- Governance Review
