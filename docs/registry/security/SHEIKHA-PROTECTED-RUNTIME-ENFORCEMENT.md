# سياسة فرض حماية Runtime في منظومة شيخة

## الهدف الأعلى

لا ضرر ولا ضرار.

## نطاق الحماية

المسارات التالية محمية:
- core/
- runtime/
- governance/
- routes/
- scripts/
- tools/governance/

## قاعدة المنع

لا يتم اعتماد أي تعديل في المسارات المحمية إلا بعد:
- تصنيف الملف
- تحديد المالك
- فحص السلامة
- فحص السرية
- فحص عدم الضرر
- مراجعة الحوكمة

## الملفات المحجوبة دائمًا

- ملفات الأسرار الحقيقية
- المفاتيح الخاصة
- كلمات المرور
- ملفات البيئة غير النموذجية
- أي ملف يحتوي بيانات سرية غير مصرح بها

## القرار

أي ملف يخالف هذه السياسة يتم تصنيفه BLOCKED.
