# فصل حالات Runtime في منظومة شيخة

## الهدف

منع اختلاط:
- ملفات Git
- الحالة التشغيلية
- الحالة المؤقتة
- recovery
- checkpoints

داخل نفس الطبقات.

## التصنيف

| النوع | الوصف |
|---|---|
| ephemeral | بيانات مؤقتة قابلة للحذف |
| durable | بيانات تشغيل مستمرة |
| checkpoints | نقاط استعادة |
| recovery | حالات الاسترجاع |

## القرار

لا يتم تخزين runtime state العشوائي داخل المسارات الأساسية مباشرة.

الهدف الأعلى:
لا ضرر ولا ضرار.
