# سجل بكسلات شيخة

## الهدف
تنظيم بكسلات التسويق والتحليلات والتحويلات دون كشف أسرار أو تفعيل تتبع غير مصرح.

## القاعدة
- أرقام Pixel لا تحفظ في Git.
- رموز CAPI لا تحفظ في Git.
- كل بكسل يحتاج غرضًا واضحًا.
- كل بكسل تسويقي يحتاج طبقة موافقة.
- لا يتم الحقن العام قبل اكتمال Consent Layer.
