# حوكمة بكسل شيخة

## الهدف
تنظيم كل ما يتعلق بالبكسل البصري والتسويقي والتحليلي في موقع شيخة.

## النطاق
- Visual Pixel
- Marketing Pixel
- Tracking Pixel
- Conversion Pixel
- Analytics Pixel
- Consent Governance

## القواعد
لا يتم تفعيل أي Pixel إلا بعد:
- تحديد الغرض
- منع التتبع غير المصرح
- احترام الخصوصية
- الموافقة عند الحاجة
- عدم التضليل
- ربطه بهدف تسويقي مشروع
- حفظ الهوية البصرية الأصلية

## الهوية البصرية
يجب أن يخدم البكسل:
- الفخامة
- الأصالة
- الهدوء
- الثقة
- الطابع الاستشاري المؤسسي

## المنع
يمنع:
- التتبع الخفي
- جمع بيانات غير لازمة
- التضليل التسويقي
- أي استخدام يضر المستخدم
- أي Pixel غير مصنف
