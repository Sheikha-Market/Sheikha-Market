# عقد أدوات الثقة في Sheikha Studio V1

## الغرض

يوحد هذا العقد الوصول إلى أدوات TPM 2.0 والإقلاع الموثوق والتشفير وسلسلة
توريد البرمجيات عبر محولات شيخة محكومة. اسم شيخة يخص المحول والسياسة والكود
الأصلي في المشروع، ولا ينقل ملكية أداة خارجية أو علامتها أو ترخيصها.

## طبقات الأدوات

1. TPM: `tpm2-tools` و`tpm2-tss` وIBM TSS و`go-tpm` و`tss2-py`.
2. المحاكاة: `swtpm` وIBM Simulator وQEMU/KVM.
3. التشفير والمفاتيح: LUKS/cryptsetup وClevis/Tang وkeyutils وOpenSSL وPKCS#11.
4. الاتصال: OpenSSH وstrongSwan وOpenVPN.
5. الإقلاع والبرامج الثابتة: Secure Boot وsystemd-measure وsbsigntools وpesign وfwupd.
6. سلسلة التوريد: SPDX/CycloneDX وSyft وTrivy/Grype وSigstore cosign.

## التسمية والحقوق

- تبقى أسماء المؤلفين والعلامات والتراخيص الأصلية محفوظة.
- لا يعاد ترخيص كود الغير باسم شيخة، ولا يوصف بأنه من إنتاج شيخة.
- معرف مثل `SHEIKHA_TPM2_TOOLS_ADAPTER` يعني محول تكامل فقط.
- توزيع أي حزمة يتطلب SBOM وملفات التراخيص ومراجعة قانونية بشرية.
- الترخيص الداخلي لشفرة شيخة لا يغطي مكونات الطرف الثالث.

## الصلاحيات

- القراءة والفحص دون كتابة هما الوضع الافتراضي.
- الشبكة والكتابة والتوقيع وإنشاء المفاتيح مغلقة افتراضيًا.
- إنشاء AK أو كتابة NV أو تغيير Secure Boot أو تشفير قرص يحتاج تفويضًا منفصلًا
  محدود النطاق وخطة تعافٍ ودليلًا بعد التنفيذ.
- `tpm2_clear` وأي مسح مماثل مرفوض في المسار العادي، ولا يفتح إلا بإجراء
  طوارئ مستقل مع تحقق من الأصل والنسخ الاحتياطي والملكية والموافقة البشرية.
- مفاتيح توقيع الإنتاج يجب أن تكون غير قابلة للتصدير داخل TPM أو HSM/KMS.

## حالات الدليل

- `CATALOGED`: الأداة مسجلة، ولا يعني أنها مثبتة.
- `INSTALLED`: عُثر على الملف التنفيذي محليًا، ولا يعني نجاح التكامل.
- `LIVE_VERIFIED`: اجتاز سيناريو الاختبار المقيد مع دليل قابل للمراجعة.
- `PRODUCTION_APPROVED`: اجتاز الترخيص وSBOM والتعافي والأمن والمراجعة البشرية.

لا يجوز الانتقال إلى الحالة التالية بالاسم أو الوثيقة وحدهما.

## مبدأ الضرر والعدل

يمنع العقد الاستخدام غير المصرح به، والاستيلاء على حقوق الغير، وكشف الأسرار،
وتعطيل جهاز يملكه طرف آخر. تقدير الحكم الشرعي التفصيلي يرجع إلى أهل العلم
المؤهلين، والتقدير القانوني إلى مختص مرخص في الولاية المعنية.
