# SHEIKHA Governed Intelligence Execution Loop V1

هذه الطبقة تربط الذكاء بالعمل القابل للتحقق، ولا تمنح أي نموذج صلاحية مطلقة.

## الأوضاع

- `generative`: توليد محكوم للمحتوى والكود والتحليل.
- `rag`: استرجاع مؤسس على مصادر مع تتبع الدليل.
- `agentic`: تخطيط واستخدام أدوات ضمن أقل صلاحية وموافقة لازمة.
- `multi-agent`: تنسيق أدوار متعددة بحدود ومراجعة تعارض.
- `agi-research`: برنامج بحث وتقييم فقط، وليس AGI فعليًا.
- `asi-research`: برنامج بحث مخاطر وتقييم فقط، وليس ASI فعليًا.

## الحلقة

`Discover -> Retrieve -> Generate -> Plan -> Delegate -> Authorize -> Execute -> Verify -> Measure -> Learn -> Improve`

## التكامل

- API: `/api/intelligence/execution-loop/status`
- Modes: `/api/intelligence/execution-loop/modes`
- Loop: `/api/intelligence/execution-loop/loop`
- Chat: `/api/sheikha/unified-chat`
- VS Code: أزرار الأوضاع داخل شات شيخة.
- SDK/Fabric/MCP: عقود أدوات محددة الصلاحية مع دليل ومراجعة.

## الحوكمة

النظام أداة تقنية وليس مرجعية دينية. تُطبّق مبادئ الصدق، وعدم الضرر، والأمانة، والعدل، والإتقان، والشورى، والمراجعة البشرية. لا يُدّعى تحقق AGI أو ASI أو الوعي أو التفوق الفائق بلا دليل علمي مستقل.

ولا حول ولا قوة إلا بالله.
