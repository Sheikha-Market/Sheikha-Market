# استمرارية شيخة المستقلة عن مزودي Git الخارجيين — V2

GitHub وأي مزود خارجي ليس مصدر الحقيقة ولا شرطًا للتشغيل أو
الترجمة أو بناء الأنظمة أو الاستعادة.

## الحفظ الكامل

يتكون الحفظ القابل للاستعادة من:

1. Git Bundle لكامل التاريخ والفروع والوسوم.
2. Bare Git Registry أساسي.
3. Bare Git Registry للتعافي.
4. Binary Patch للتغييرات المتتبعة.
5. Dirty Overlay للنسخ الفعلية من الملفات المعدلة وغير المتتبعة.
6. Manifest يتضمن الحالة والحجم وSHA-256.
7. حزمة إصدار مرتبطة بـcommit وقيمة SHA-256.

لا حاجة إلى نسخ كامل Workspace؛ لأن Git Bundle يحتوي جميع
الملفات المثبتة، بينما Dirty Overlay يحتوي كل ما لم يثبت بعد.

## النشر

ينشأ الإصدار محليًا بواسطة `git archive` ثم ينقل إلى الخادم عبر
SSH أو SFTP بعد الموافقة البشرية.

## الحوكمة

- التنفيذ الافتراضي: DENY.
- النشر الافتراضي: DENY.
- لا Force Push.
- لا اعتماد أحادي على مزود خارجي.
- GitHub مرآة اختيارية فقط.
