# شيخة — معمارية متعددة البيئات V1

الغاية النفع والعمران والبحث المسؤول وفق القيم المطلوبة. لا يمكن إثبات دعم كل أنظمة الكون؛ يعتمد الدعم على منصة محددة ووظائف واختبارات معلنة. لا يدل ذلك على حياة بيولوجية أو عقل واعٍ أو AGI/ASI.

## الهيكل
عقد المنصة ← النواة وHAL ← مشغلات الأجهزة ← خدمات محدودة الصلاحيات ← ذكاء معزول ← بوابة تكامل ذات إصدارات ← سجل أدلة وحوكمة.

الذكاء يقدم التحليل والتخطيط. لا يوضع محرك استدلال كبير داخل مسار التحكم الحرج؛ تُخصص وظائف التوقيت والتحكم الحرج بتصميم حتمي واختبارات مستقلة. هذا متطلب معماري، وليس تنفيذًا حاليًا للتحكم بالطائرات أو السفن.

## سجل المنصات
يغطي السجل 11 مجالًا: التطوير، الحواسب المحمولة، الجوالات، مراكز البيانات والحوسبة الضخمة، الصناعة والمعامل، الروبوتات، الإدارة الحكومية، الملاحة البحرية، الطيران، الفضاء والأقمار، والدعم الدفاعي غير التسليحي. المجال الأخير لا يتضمن استهدافًا أو استخدام أسلحة.

الدليل الحالي نموذج محدود x86_64 في المحاكاة وأدوات تطوير على Linux. بقية المجالات مقترحات أو بحث فقط؛ لا يوجد إثبات تأهيل مادي لها. يلزم نقل معماري ومشغلات وقياسات وتأهيل مستقل لكل جهاز وموقع ووظيفة.

## عقد التكامل المقترح
إصدار مخطط، هوية مصدر، توقيت، وحدات قياس، جودة، تسلسل، ونطاق تفويض. رفض البيانات القديمة أو غير المأذونة؛ ولا يحول استقبال القياس إلى صلاحية التحكم. هذا العقد مقترح، وليس اتصالًا منفذًا بين جميع المنصات.

## بوابات التنفيذ
تعريف الجهاز والوظيفة → تطبيق adapter → اختبار محلي ومحاكاة → قياس التوقيت والأعطال → تقييم السلامة والأمن والأنظمة لدى المختصين → تجربة محدودة مأذونة → دعم معلن بوظائفه وحدوده. لا يغني اعتماد مجال عن اعتماد مجال آخر.

تشغيل الفحص: `node tools/environment/sheikha-platform-capabilities-v1.cjs --write`. التقرير يصف دعمًا مقترحًا ودليلًا محدودًا، ولا يفعّل الأجهزة أو الشبكات. يستمر Bare-Metal بالتوازي مع بقية البرامج.
