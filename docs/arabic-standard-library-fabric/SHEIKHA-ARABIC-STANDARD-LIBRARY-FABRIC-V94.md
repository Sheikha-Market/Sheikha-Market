# SHEIKHA_ARABIC_STANDARD_LIBRARY_FABRIC_V94

طبقة المكتبة القياسية العربية للغة شيخة: النصوص، الرياضيات، المجموعات، JSON، الوقت، التحقق، الإدخال والإخراج، الأدلة، الحوكمة، وأدوات وقت التشغيل.

## الحوكمة

- العربية أولاً.
- الكتاب والسنة قيماً وضوابط.
- لا ضرر ولا ضرار.
- الإنسان صاحب القرار.
- الذكاء الصناعي أداة حساب وتحليل فقط.
- الدليل مطلوب.
