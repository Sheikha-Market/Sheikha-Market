# سجل مكونات SDP

`node tools/environment/sheikha-sdp-inventory-v1.cjs --write`

يتتبع الفحص استيرادات CommonJS الحرفية المحلية من أدوات SDP الأربعة، ويحفظ الملفات وأحجامها وبصماتها وإصدار Node والموديولات المدمجة وأسماء استيرادات الحزم الخارجية إن وجدت. لا يثبت أو يشغل أداة بناء ولا يرسل الشفرة.

هذا جرد أولي، وليس SBOM شاملًا أو إثباتًا قانونيًا للرخص أو تحليلًا ساكنًا كاملًا للJavaScript. قد لا يرى استيرادات ESM أو eval أو تحميلًا مشروطًا أو مولدًا، ويصرح بأي require غير حرفي يكتشفه. وجود node:child_process في VM يعني أن مراجعة الأمن يجب أن تشمل فرع الموصلات؛ الاستخدام المقيد الحالي يمنع التشغيل الحي، ولا يعني أن الكود لا يحتوي هذه الإمكانية.

يبقى ترخيص Node والأطراف الثالثة منفصلًا عن ترخيص شيخة. الجرد يساعد مراجعة التوزيع والتأهيل لكنه لا يمنح إذنًا خارجيًا. أسماء الملفات وبصماتها في التقرير لا تتضمن محتوى السجل الشخصي أو مفاتيح.
