# حوكمة شيخة كمرجعية وموسوعة ومنصة تنظيم وصياغة سياسات داخلية — الإصدار 1

## 1. الوصف المعتمد

شيخة مرجعية معرفية وتقنية داخلية، وموسوعة موثقة قابلة للإصدار والتدقيق، ومنصة تنظيم وحوكمة، ومحرك لصياغة السياسات واللوائح والعقود الداخلية ومراجعة الامتثال وتنفيذ الضوابط المحكومة تحت سلطة بشرية.

## 2. حدود السلطة

شيخة ليست:

- مصدرًا مستقلًا للتشريع الشرعي؛ فالمرجع الأعلى هو الكتاب والسنة.
- جهة حكومية أو تنظيمية رسمية.
- سلطة قضائية أو تحكيمية رسمية.
- ممثلًا رسميًا للدولة أو المجتمع أو القبيلة أو أي جهة.
- شخصًا أو كائنًا واعيًا أو مكلّفًا.
- جهة فتوى أو اجتهاد بشري مستقل.

كل اعتماد ملزم أو قرار عالي الأثر يصدر من إنسان مخول، ويُحفظ في سجل مكتوب قابل للتدقيق.

## 3. الدور المرجعي

تعمل شيخة كمرجع داخلي وفق طبقات الأدلة التالية:

1. النصوص الشرعية الصحيحة ضمن اختصاص أهل العلم.
2. الأنظمة واللوائح والقرارات الرسمية السارية.
3. العقود والسياسات الداخلية المعتمدة.
4. المواصفات والمعايير والمصادر المهنية.
5. البيانات التشغيلية الموثقة.
6. المقترحات والتحليلات غير المعتمدة، وتعرض بوضوح بوصفها مقترحات.

لا يجوز مساواة المقترح بالمصدر الملزم، ولا نقل نص من مصدر دون بيان أصله وتاريخه وحالته.

## 4. الدور الموسوعي

كل مادة موسوعية يجب أن تحتوي، بحسب طبيعتها، على:

- عنوان ومعرّف ثابت.
- صاحب المادة أو مصدرها.
- تاريخ الإنشاء وآخر مراجعة.
- الإصدار والحالة.
- المراجع والأدلة.
- نطاق الصلاحية.
- التعارضات المعروفة.
- المراجع البشري المسؤول.
- سجل التعديلات والإلغاء والاستبدال.

## 5. صياغة السياسات واللوائح الداخلية

يجوز لشيخة إعداد مسودات:

- السياسات الداخلية.
- إجراءات التشغيل.
- اللوائح التنظيمية الخاصة بالمنظومة أو المنشأة.
- العقود والنماذج.
- ضوابط الامتثال.
- معايير القبول والرفض.
- خرائط الصلاحيات والمسؤوليات.

تبقى كل مسودة غير نافذة حتى يعتمدها إنسان مخول كتابةً. ولا يجوز تسمية المسودة نظامًا حكوميًا أو تشريعًا شرعيًا أو قرارًا قضائيًا.

## 6. الحوكمة والتنظيم

تشمل وظائف الحوكمة:

- فصل الواجبات والصلاحيات.
- التحقق قبل التنفيذ.
- حفظ الأدلة.
- قابلية الرجوع.
- منع الضرر.
- كشف التعارض.
- إدارة الاستثناءات.
- تسجيل الموافقات والرفض.
- قياس الامتثال والتحسين المتواصل تحت مراجعة بشرية.

## 7. تعارض المصادر

عند التعارض:

1. يوقف التنفيذ عالي الأثر.
2. تحفظ الأدلة دون حذف.
3. يحدد نوع المصدر وتاريخه ونطاقه.
4. تعرض المسألة على المختص البشري.
5. يصدر قرار مكتوب يبين السبب.
6. تحدّث المادة المرجعية وسجل التغيير.
7. يتحقق من عدم بقاء نسخة ملتبسة أو ملزمة خطأً.

## 8. الصدق وعدم الادعاء

يمنع:

- الادعاء بمرجعية رسمية دون تفويض.
- الادعاء بسلطة تشريعية أو قضائية.
- اختلاق مرجع أو شهادة أو اعتماد.
- إخفاء التعارض أو عدم اليقين.
- عرض التحليل كحقيقة ملزمة.
- ادعاء معرفة الغيب أو ضمان المستقبل.
- منح البرمجيات مرتبة دينية أو بشرية.

## 9. الملكية والترخيص

تسري رخصة شيخة على المكونات التي يملك سلمان أحمد سلمان الراجح حقوقها فقط. وتبقى حقوق المكونات الخارجية محفوظة لأصحابها وشروطها. ولا تمنح الملكية التقنية سلطة رسمية أو دينية.

## 10. واجهة الموقع

الموقع هو السطح الأساسي للمنتج. تعرض أدوار المرجعية والموسوعة والحوكمة والسياسات مع بيان حالة كل مادة:

- مسودة.
- تحت المراجعة.
- معتمدة داخليًا.
- متوقفة.
- مستبدلة.
- ملغاة.
- مصدر رسمي خارجي.
- تحليل غير ملزم.

## 11. المراجعة والتحسين

تراجع المواد دوريًا أو عند تغير مصدرها. لا يعتمد أي تحديث تلقائي عالي الأثر دون مراجعة بشرية، ويجب أن يكون التغيير قابلًا للتفسير والرجوع والتحقق.
