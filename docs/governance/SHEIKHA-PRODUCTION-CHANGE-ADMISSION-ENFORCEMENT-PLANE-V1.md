# Sheikha Production Change Admission Enforcement Plane V1

## الغرض

هذه الطبقة تربط قرار بوابة قبول التغييرات بمسار ترقية محلي منضبط دون أن تنفذ أوامر أو تعدّل الإنتاج بنفسها.

## الحدود

- السلطة بشرية فقط.
- طلب HTTP لا يمنح الموافقة.
- حقول الموافقة الواردة من طلب غير موثوق لا تمنح القبول.
- لا بد من سجل موافقة محلي مستقل مرتبط ببصمة SHA-256.
- السجل يرتبط بإصدار المرشح وبصمة الحزمة ونطاق المسارات.
- السجل توثيق تقني لموافقة الجلسة، وليس إثبات هوية تشفيريًا أو مستندًا قانونيًا.
- الطبقة لا تشغّل أوامر ولا تعيد تشغيل خدمات ولا تثبت حزمًا ولا تنفذ تنظيفًا.
- أي نقص أو اختلاف يؤدي إلى `SAFE_HOLD`.

## مسار القرار

1. بوابة HTTP تبقى في حالة `AWAITING_HUMAN_APPROVAL`.
2. لا تمنح بوابة HTTP قبولًا إنتاجيًا.
3. طبقة التنفيذ المحلية تقرأ سجل الموافقة من مسار محلي مطلق.
4. تتحقق من بصمة السجل والمرشح والحزمة والنطاق.
5. تتحقق من خط الأساس والضمان التشغيلي وعدم وجود انحراف وجاهزية الرجوع.
6. تمنح قبولًا لمسار العمل المنضبط فقط.
7. التنفيذ الفعلي يبقى مسؤولية سكربت منفصل يخضع لمراجعة وموافقة مستقلة.

## الحوكمة

المرجع: الكتاب والسنة.

القاعدة: لا ضرر ولا ضرار.

نمط الاحتفاظ: `DENY_BY_DEFAULT`.
