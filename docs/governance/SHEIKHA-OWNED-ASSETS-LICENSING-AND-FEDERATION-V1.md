## التصنيف الحقوقي

### OWNED

يستخدم فقط للأصول التي يوجد لها دليل إنشاء أو نقل ملكية صحيح.

### LICENSED

أصل أو صلاحية مستخدمة وفق ترخيص محدد. لا تعني الملكية.

### INTEGRATED

أداة أو نظام مرتبط تقنيًا مع شيخة. لا يعني نقل الحقوق.

### FEDERATED

اتحاد تقني تعاقدي بين أنظمة مستقلة.

### AUTHORIZED

صلاحية موثقة ومحددة النطاق.


## ما لم يتم بعد

```text
REMOTE_MUTATION_PERFORMED=false
PRODUCTION_DEPLOYMENT_EXECUTED=false
CLEANUP_AUTHORIZED=false
RETENTION_MODE=DENY_BY_DEFAULT
```

القيم السابقة لا تُحوّل إلى true بمجرد تغيير النص؛ بل تحتاج نشرًا
إنتاجيًا مثبتًا أو اختبار استعادة أو قرار تنظيف مستوفٍ لشروطه.

لشيخة، ولا تمنح إعادة الترخيص دون حق صريح.
