# Sheikha ELF — الملف التنفيذي الأصلي الوسيط

المقصود هنا صيغة الملف ELF ضمن سلسلة Runtime وKernel، وليس اسم مصنع ذكاء اقتصادي. المصدر sheikha-language/foundations/sheikha-elf-v1.shk يؤسس عقد فحص محلي؛ أداة tools/production/sheikha-elf-v1.cjs تترجمه وتنفذه في VM ثم تقرأ الملف الأصلي الموجود بـreadelf وnm، دون تنفيذ ELF على المضيف.

المسار الموجود: برنامج إنتاج .shk محدود → حزمة تعليمات مضمّنة → مصدر C أصلي → GCC/ld → runtime.elf → objcopy → BOOTX64.EFI بصيغة PE32+ → صورة FAT → إقلاع UEFI في QEMU. لغة شيخة ليست حاليًا مترجمًا عامًا مباشرًا إلى ELF لكل البرامج؛ الملف الأصلي يفسر تعليمات إنتاج محدودة مشتقة منها.

ELF64، little-endian، EXEC، x86-64؛ نقطة دخول 0x4015c0. فحص nm لا يظهر رموزًا غير محلولة. يوجد فصل مقاطع R وRX وRW، وGNU_STACK غير تنفيذي في تعريف الملف؛ لا يعني ذلك اختبار حماية صفحات في الضيف. OS/ABI System V بيانات صيغة ولا يثبت اعتمادًا على Linux.

ملف الإقلاع الذي نفذته UEFI هو EFI، وليس ELF مباشرة. محمل ELF ديناميكي وتحميل تطبيقات عامة وتنفيذ ELF داخل نواة شيخة UNKNOWN. الفحص لا يثبت إعادة إنتاج الملف من المصدر الحالي ولا توقيعه؛ مصدر البناء ونتائج الإقلاع تُراجع بصورة مستقلة. الدليل runtime/sheikha-elf/v1/verification.json وسجل readelf.txt. لم يحدث نشر أو اتصال شبكة أو كشف أسرار أو تشغيل عتاد فعلي.
