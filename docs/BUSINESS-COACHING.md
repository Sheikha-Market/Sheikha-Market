## I. إطار البزنس كوتش (Business Coaching Framework)

### تعريف البزنس كوتش (Definition)

```
البزنس كوتش الحقيقي:
├─ مرشد + موجه + مدرب + مستشار + صديق
├─ يساعد الفريق على تحقيق الأهداف
├─ يطور المهارات والقدرات
├─ يزيل العوائق والتحديات
├─ يبني القيادة الحقيقية
└─ ينقل المعرفة والخبرة

الفرق بين:
├─ Coach: Develops people (القيادة الداخلية)
├─ Consultant: Solves problems (المشاكل المباشرة)
├─ Mentor: Shares wisdom (التجارب السابقة)
├─ Manager: Oversees work (التشغيل اليومي)
└─ Sheikha needs: All of these combined

Our Model: Integrated Coaching
├─ Strategic level (رؤية)
├─ Operational level (تنفيذ)
├─ Personal level (تطوير فردي)
└─ Collective level (فريق قوي)
```

│  ├─ أسبوع 1: تحديد الأهداف والتحديات

المستوى 2: الكوتشينج الجماعي (Team Coaching)
├─ الفريق: كل قسم (dev, ops, shar'ia, etc)
