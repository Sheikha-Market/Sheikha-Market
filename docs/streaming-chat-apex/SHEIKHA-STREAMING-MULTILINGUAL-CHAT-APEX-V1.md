# Sheikha Streaming Multilingual Chat Apex V1

SHEIKHA_STREAMING_MULTILINGUAL_CHAT_APEX_V1 raises the chat stack above L20 with governed response streaming and multilingual direction handling.

## Purpose

- Stream chat responses with Server-Sent Events.
- Keep JSON chat as a safe fallback.
- Detect RTL/LTR message direction per request.
- Keep the extension local-runtime-first before proxy or remote gateways.
- Preserve governance boundaries: no secrets, no destructive actions, no AGI/ASI/consciousness claims.

## Routes

- `GET /api/sheikha/streaming-chat-apex/v1/status`
- `POST /api/sheikha/streaming-chat-apex/v1/chat`
- `POST /api/sheikha/streaming-chat-apex/v1/stream`
