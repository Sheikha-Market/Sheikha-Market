# شيخة — واجهة قدرات Linux V1

تستخدم هذه الواجهة Linux المضيف الموجود بالفعل، وتربط فحص موارده وأدواته بمحرك عقود شيخة. ليست نقلًا لكل وظائف Linux إلى نواة شيخة الأصلية، ولا إعادة تسمية للنظام المضيف.

التشغيل المحلي: `node tools/environment/sheikha-linux-capabilities-v1.cjs`.
حفظ القياس: أضف `--write`، فيحفظ التقرير داخل `runtime/sheikha-linux-capabilities/v1/verification.json`.

تقيس الواجهة عدد المعالجات والذاكرة المتاحة ومدة التشغيل، وتستعلم عن إصدارات ثماني أدوات بأوامر ثابتة ومهلة محدودة، ثم تنفذ فحص شيخة المحلي. لا تعرض أسماء المستخدمين أو عناوين الشبكات أو متغيرات البيئة أو سجلات الخدمات.

## الهيكل والتأهيل
| مجال Linux | الاستخدام في تطوير شيخة | الإثبات المتبقي |
|---|---|---|
| النواة والعمليات والذاكرة | المضيف الحالي يشغّل أدوات التطوير | عزل وجدولة نواة شيخة الأصلية |
| البناء واللغات وELF | أدوات المضيف ومترجم شيخة | توافق البرامج وتكرار البناء |
| المحاكاة والحاويات | فحص توفر الأدوات | تأهيل كل بيئة دون افتراض تشغيل خدماتها |
| التخزين والاستعادة | مرحلة تكامل لاحقة | تجارب انقطاع واستعادة ونسخ احتياطي |
| الشبكات والأمن | مرحلة تكامل لاحقة | اختبار البروتوكولات والسياسات والصلاحيات |
| سطح المكتب والمشغلات | مرحلة تكامل لاحقة | دعم الأجهزة وتوافق التطبيقات والوصول |

وجود أداة مثبتة لا يثبت صلاحية تشغيلها أو عمل خدمتها أو سلامتها. التقرير المحلي لا يمنح اعتمادًا إنتاجيًا. الانتقال من Pop!_OS يحتاج صورة قابلة للإقلاع وتوافق الأجهزة والتطبيقات وخطة رجوع مجربة؛ لم يُنفذ هنا. يستمر Bare-Metal والفوندريات دون تغيير الخدمات الحالية.
