# Sheikha Runtime / Kernel / UFW — تأسيس وتحقق محلي

المصدر sheikha-language/foundations/sheikha-runtime-kernel-ufw-v1.shk يحدد الكيانات وسياسة DENY الافتراضية واستثناء LOCAL_DIAGNOSTIC. المحرك يترجم المصدر ويتحقق من ثلاثة كيانات وسياسة محددة، ويشغّل العلامة في VM، ثم يقيّم عقود تدفق محلية من القيم في المصدر. لا تنفيذ shell أو أوامر شبكة من لغة المصدر.

Runtime: مترجم وVM يعملان على Node.js في المضيف، مع منفذ أصلي محدود سبق بناؤه لـ18 عقدًا داخل ضيف UEFI. Kernel: نموذج إقلاع وتجهيز تشغيل أصلي تجريبي، وليس نظام تشغيل عام مكتمل. UFW: معنى مؤقت لسياسة جدار ناري شيخة؛ ليس برنامج Linux ufw ولا مرشح حزم عاملًا.

السياسة الحالية تقبل فقط محاكاة تشخيص محلي؛ ترفض الاتصالات الشبكية والقياسات والحركة والحقول الإضافية والعقود غير الصالحة. هذا تقييم قرار برمجي وليس حماية شبكة فعلية. enforcementVerified وnativePacketFilterVerified UNKNOWN.

أداة tools/production/sheikha-runtime-kernel-ufw-v1.cjs تقرأ سلامة صورة الإقلاع ثم تقلع الصورة المحفوظة في QEMU بلا شبكة وsnapshot مع نسخة OVMF_VARS محلية، وتحفظ سجلًا جديدًا في runtime/sheikha-runtime-kernel-ufw/v1/verification.json. لا تعيد بناء Kernel أو تضيف UFW داخله. kernel.freshBootStatus يثبت نتيجة هذا الإقلاع فقط، وأي غياب دليل UNKNOWN. الملف serial.log دليل الإقلاع الحالي.

الشبكة والتخزين الدائم وعزل التطبيقات والتوقيع والتحميل الديناميكي وترحيل الخدمات غير مكتملة. UFW يحتاج عقد بروتوكول فعلي وبرامج تشغيل ومرشح حزم وتحققًا إنتاجيًا مستقلاً. لا قواعد DNS أو شبكة أو VPS أو Hostinger تغيرت، ولا تم نشر أو تشغيل عتاد حقيقي. بيانات المالك والأسرار غير مدرجة.

القيم المعلنة الكتاب والسنة وبلا ضرر ولا ضرار تتطلب مراجعة مؤهلة؛ لا اعتماد شرعي أو هندسي آلي. التفعيل هنا LOCAL_FOUNDATION، والتفعيل الإنتاجي غير معتمد.
