# SHEIKHA_RESOURCE_SOURCE_REGISTRY_V1
# سجل شيخة لمصادر الموارد والمواد

## الهدف
تنظيم كل مصادر المواد داخل شيخة حسب نوع المصدر، نوع المادة، HS Code، الموقع، الكمية، الجودة، الملكية، الأثر الأخضر، والربط اللوجستي.

## أنواع المصادر
- مورد طبيعي.
- منجم ذهب / فضة / حديد / نحاس / معادن.
- محجر.
- مصهر.
- مصنع أولي.
- مصنع تحويلي.
- مصنع تدوير.
- مصدر سكراب.
- منطقة تجميع سكراب.
- مصدر هدم.
- مناطق ردم واسترداد.
- تشليح.
- تجمع صناعي / كلاستر.
- مصدر مينائي.
- مصدر مستودعي.

## الدورة
Source → Verification → HS Code → Inspection → Quantity → Authorization → Logistics → Contract/PO → Delivery → Payment → Impact

## القاعدة
لا مصدر بلا تحقق.
لا بيع بلا ملكية أو تفويض.
لا ادعاء وفرة بلا دليل.
لا شحنة بلا تصنيف.
لا تعامل مع مصدر غير نظامي.
ولا حول ولا قوة إلا بالله.
