# محرك قواعد بيانات ومعرفة شيخة

## الهدف
ربط قواعد بيانات شيخة مع منظومة رياض الجنة للعلم والمعرفة والابتكار، بحيث تجمع القرآن والسنة والعلوم التطبيقية والتقنية والذكاء الصناعي والمجتمع والويكي ومختبر الابتكار.

## القاعدة
العلم الشرعي لا يُنسب إلا لمصدر.
لا فتوى بلا أهل اختصاص.
لا كذب ولا تزوير ولا نسبة خاطئة.
العلوم التطبيقية تميّز بين الحقيقة، التجربة، المقترح، والافتراض.
بيانات المجتمع محمية ومحكومة.

ولا حول ولا قوة إلا بالله.
