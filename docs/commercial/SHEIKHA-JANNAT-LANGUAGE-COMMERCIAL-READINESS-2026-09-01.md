## الحوكمة الإسلامية

الكتاب والسنة مرجعية قيمية عليا معلنة للمنظومة، مع قواعد العدل، الوفاء، الأمانة، منع الضرر، حفظ الحقوق، والمراجعة البشرية. النظام لا يدعي العصمة أو الإفتاء أو الحلول محل العلماء والقضاء والجهات النظامية. المسائل الشرعية المتخصصة والالتزامات القانونية النهائية تتطلب مراجعة بشرية مؤهلة.

## موانع الإطلاق التجاري الكامل

1. Redis الحالي محلي وغير مناسب للإنتاج الموزع؛ يلزم Redis TLS دائم واختبار atomic nonce operations.
2. تدقيق npm سجل `14` ثغرة عالية و`7` متوسطة في شجرة الإنتاج؛ بعض الإصلاحات المتاحة كاسرة وتحتاج مسار ترقية واختبار مستقل.
3. مساحة Git غير نظيفة وبها مئات التغييرات؛ يجب تقسيمها إلى دفعات إصدار قابلة للمراجعة.
4. يلزم KMS/HSM خارجي، مفتاح Ed25519 عام مسجل، وسجل WORM خارجي قبل الحوكمة الموزعة.
5. TPM الفيزيائي ظاهر في sysfs، لكن عقد `/dev/tpm*` وأدوات `tpm2-tools` وعقد preflight الحقيقي لم تكتمل بعد.
6. Firmware التجاري يحتاج Secure Boot والتوقيع والتعافي وQuote حقيقيًا وبوابة إصدار مستقلة.

## حدود الادعاء

- لغة شيخة لغة عربية مستضافة ومحكومة مع backend أصلي محدود، وليست مترجمًا ذاتي الاستضافة كاملًا.
- منطق محدد من Kernel مولد من مصدر `.shk`، وليس Kernel كاملًا مكتوبًا بلغة شيخة.
- صورة الإقلاع مثبتة تجريبيًا، وليست Firmware OEM/ODM معتمدًا للإنتاج.
- القرار الحالي يسمح ببيع Pilot تعاقدي محدود فقط، ولا يسمح بوصف المنظومة بأنها إنتاج تجاري موزع كامل.
