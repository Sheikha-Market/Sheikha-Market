# SHEIKHA WEBSITE SALES FUNNEL V1

## الهدف

تحويل زائر الموقع إلى طلب تجاري قابل للتتبع، ثم إلى عرض
سعر وأمر خدمة وطلب دفع أولي، دون تحصيل أو اعتراف آلي بالإيراد.

## المسارات

- الصفحة الرئيسية: `/commercial/index.html`
- نموذج الطلب: `/commercial/request.html`
- الشروط: `/commercial/terms.html`
- الخصوصية: `/commercial/privacy.html`
- الاسترداد: `/commercial/refund.html`

## واجهات API المقترحة

Base path:

`/api/commercial/v1`

Endpoints:

- `GET /status`
- `GET /offers`
- `POST /leads`
- `POST /quotes`
- `POST /orders`
- `POST /proforma`

## دورة الإغلاق

1. تسجيل Lead.
2. تأهيل الحاجة.
3. إنشاء عرض سعر.
4. اعتماد المالك.
5. قبول العميل للنطاق.
6. إنشاء أمر الخدمة.
7. توقيع الاتفاق.
8. إنشاء طلب دفع أولي.
9. التحقق من التحصيل.
10. التنفيذ.
11. قبول العميل.
12. الاعتراف بالإيراد.

## التخزين

تُخزن بيانات العملاء افتراضيًا في:

`~/.local/share/sheikha/commercial-sales-v1`

ولا تُحفظ داخل Git.

- لا تنشر إلى الإنتاج.
- لا تجمع بيانات بطاقات.
- لا تصدر فاتورة ضريبية نهائية.
- لا تعترف بإيراد.
