# إغلاق فجوات مثبتات وتوزيعات شيخة وفحص نطاق الإنتاج — الإصدار 1

## الهدف

تفعيل مصفوفة بناء وتوثيق تشمل 26 هدفًا:

- Windows: مثبت مستخدم، مثبت نظام، ZIP، وCLI لمعمارية x64 وArm64.
- Linux: DEB وRPM وtar.gz وCLI لمعمارية x64 وArm32 وArm64، إضافة إلى Snap.
- macOS: DMG لمعالج Intel وApple silicon وحزمة Universal، وCLI لمعالجي Intel وApple silicon.

## قاعدة الإثبات

لا يعد الهدف مفعّلًا بالكامل بمجرد وجود إعداد بناء أو ملف حزمة. يلزم لكل هدف:

1. ربط البناء بـ commit محدد.
2. إتمام البناء على بيئة أصلية أو بيئة تحقق معتمدة للمنصة والمعمارية.
3. وجود الحزمة.
4. تسجيل SHA-256.
5. إنشاء SBOM.
6. تسجيل مصدر البناء وإجراءاته.
7. نجاح اختبار التثبيت.
8. نجاح اختبار التشغيل الأساسي.
9. نجاح اختبار الإزالة.
10. تسجيل حالة التوقيع بصدق.
11. تنفيذ البوابات الإضافية الخاصة بالمنصة.
12. اعتماد بشري للإصدار.

## حالات الهدف

- `FULLY_EVIDENCED`: جميع البوابات المطلوبة والمنطبقة ناجحة.
- `ARTIFACT_PRESENT_EVIDENCE_INCOMPLETE`: وُجدت الحزمة، لكن الأدلة غير مكتملة.
- `BUILD_CONFIGURATION_PRESENT`: إعداد البناء موجود دون حزمة موثقة.
- `DECLARED_ONLY`: الهدف مذكور دون تنفيذ مثبت.
- `GAP_CONFIRMED`: لا يوجد دليل كافٍ.

## التحسينات الملزمة

- بناء قابل للتكرار.
- أسماء إصدارات موحدة.
- بصمات لكل حزمة.
- SBOM لكل هدف.
- سجل مصدر وإجراءات البناء.
- فصل أسرار التوقيع عن المستودع.
- اختبار تثبيت وتشغيل وإزالة على كل منصة ومعمارية.
- منع النشر عند فشل أي بوابة.
- حفظ الأدلة مع الإصدار.
- إتاحة الرجوع دون حذف الأدلة السابقة.
- عدم جعل التشغيل الفعلي للمنتج معتمدًا على GitHub.

## نطاق الإنتاج

لا تدخل الحزم في نطاق النشر الإنتاجي إلا بعد وصول الهدف إلى `FULLY_EVIDENCED`. يبقى إطار الحوكمة وخطط البناء صالحين للدمج والمراجعة قبل بناء الحزم، لكن لا يجيزان إعلان اكتمال جميع المثبتات.

## الاعتماد الخارجي

- النشر في متجر Snap يحتاج دليل رفع وحالة نشر فعلية.
- توقيع Windows يسجل كحالة مستقلة ولا يفترض وجود شهادة.
- توقيع macOS والتوثيق لدى Apple يسجلان كحالتين مستقلتين.
- لا تحفظ مفاتيح أو شهادات أو رموز وصول داخل المستودع أو تقارير الأدلة العامة.
