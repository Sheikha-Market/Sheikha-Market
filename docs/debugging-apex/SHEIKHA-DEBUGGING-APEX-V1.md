# SHEIKHA DEBUGGING APEX V1

SHEIKHA_DEBUGGING_APEX_V1 is the highest governed debugging and diagnostics layer for Sheikha.

It unifies:

- Vital Chat Apex
- Conversation debug pipeline
- Enterprise Inspector
- Intelligent Inspector
- Log Intelligence V2
- VS Code diagnostics
- Git and workspace awareness
- Runtime health, PM2, and port policy
- Self-governance readiness

## Rule

Debugging is read-first and evidence-first. No deletion, destructive Git action, secret exposure, or high-impact runtime action is allowed without human approval.
