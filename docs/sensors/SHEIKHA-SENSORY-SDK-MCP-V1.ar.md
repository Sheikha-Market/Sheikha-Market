## عقد الاستدعاء

```javascript
const { createSheikhaClient } = require('./sdk/sheikha-js');
const sample = require('./docs/examples/sheikha-sensory-sdk.synthetic.json');
const report = createSheikhaClient().interpretSensorBatch(sample);
console.log(report.explanations);
```

الأداة `sheikha_sensory_interpret` تقبل الوسيط نفسه في `arguments`:

```json
{
  "language": "ar",
  "batch": {
    "schemaVersion": 1,
    "tenantId": "sheikha-local-lab",
    "observations": [
      {
        "sourceId": "ENV-TEMP-01",
        "sequence": 1,
        "observedAt": "2020-01-01T00:00:00.000Z",
        "value": 77,
        "unit": "[degF]",
        "quality": "VALID",
        "calibration": "UNKNOWN",
        "uncertainty": null
      }
    ]
  }
}
```

هذا مثال اصطناعي تاريخي، ويظهر قديمًا عن قصد. `language` إلزامية وتقبل `ar` أو `en`. بقية شروط الدفعة هي شروط نواة المرصد: مصادر مسجلة، وحدات مسموحة ومناسبة للكمية، زمن صالح، تسلسل متزايد، جودة ومعايرة معلنتان وعدم يقين واضح. الحد 500 قراءة و512 KiB للوسائط المتسلسلة بعد التحقق.

تحول الدالة 77 فهرنهايت إلى نحو 25 مئوية، وتحتفظ بالأصل وبحالته؛ لا تصف قراءة قديمة أو مجهولة المعايرة بأنها سليمة. تستخدم ساعة العملية للتقييم؛ الساعة ليست متحققة مستقلًا ولا يمكن للمستدعي استبدالها بحقل `asOf`.

## الحوكمة وحدود العزل

- التحقق داخل الدالة فعلي، وليس مجرد `readOnlyHint` في قائمة MCP. الحقول الإضافية مثل URL أو مسار ملف أو رمز سري أو طلب صلاحية إنتاج مرفوضة.
- استدعاءات SDK المباشرة ترفض getters والحقول الخفية والرمزية ومصفوفات السجلات المتقطعة وخطافات `toJSON` قبل التسلسل. هذا ليس عزلًا لشفرة JavaScript عدائية تعمل أصلًا داخل العملية نفسها.
- بيانات المصدر والمعايرة غير موثقة. وضع النواة دائمًا `IMPORTED_UNVERIFIED`، حتى لو كانت القيم داخل نطاق مرجعي.
- العملية لا تجلب ملفات أو بيانات من شبكة، ولا تكتب بيانات المستخدم، ولا تستدعي نموذج ذكاء أو أوامر أجهزة. تحميل وحدات الشفرة وملف الإعداد المحلي عند بدء SDK ليس قراءة ملف يختاره المستدعي.
- `tenantId` مطابقة نطاق ثابت وليست مصادقة مستخدم أو خدمة متعددة المؤسسات.
- كل استدعاء مستقل. منع التكرار داخل الدفعة فقط؛ لا يوجد سجل منع تكرار دائم عبر الاستدعاءات، ويصرح التقرير بذلك.
- بصمة `normalizedArgumentsSha256` تخص تمثيل الوسائط المقبولة بترتيب حقول ثابت، لا بايتات ملف المستخدم الأصلي ولا أصالة الجهاز.
- هذا الضبط خاص بالأداة الجديدة؛ لا يدعي فرض حوكمة شاملة على جميع خوادم MCP أو أجهزة العالم. اعتماد مصدر مستقبلي يكون بحسب الدقة والإذن والترخيص والخصوصية وعدم الضرر، لا بحسب دين أصحابه أو هويتهم.
