# Sheikha Live Arabic First Token L65 V3

يوفر المسار `/api/sheikha/live/chat/v1` استجابة SSE عربية لا تتوقف على
زمن تحميل النموذج المحلي.

## ترتيب البث

1. `ack`
2. `meta`
3. `heartbeat`
4. `token` عربي سياقي محلي
5. Tokens النموذج عند وصولها، أو Token تعافٍ محلي
6. `done`

الـToken المحلي الأول جزء تمهيدي من الرد، وليس ادعاءً بأن النموذج أكمل
الاستدلال. طلبات النص الحرفي الموثقة تُنجز مباشرة عبر
`EXACT_OUTPUT_CONTRACT` دون استدعاء نموذج.

## التوجيه

- العربية العامة: `Sheikha-Core`.
- البرمجة الصريحة: `qwen2.5-coder:7b`.
- الاستدلال الصريح: `deepseek-r1:8b`.
- كلمة «اختبار» وحدها لا تحول الطلب إلى مسار البرمجة.

## التعافي الزمني

إذا لم يصل أول Token من النموذج ضمن الميزانية، يُلغى طلب Ollama ويُرسل:

- Token من `governed-local-time-budget-fallback`.
- حدث `done` بالمسار `GOVERNED_LOCAL_TIME_BUDGET_FALLBACK`.
- `modelCompleted: false`.

الميزانيات الافتراضية لأول Token من النموذج:

- سريع: 8 ثوانٍ.
- امتداد VS Code العميق: 12 ثانية.
- برمجة: 20 ثانية.
- استدلال: 30 ثانية.

يمكن ضبطها بمتغيرات البيئة المخصصة، ولا تمثل شهادة أداء عتادي.

## حدود الادعاء

- القياس المحلي الأخير لأول Token السياقي كان 47ms، وهو قياس واحد لا
  يمثل SLA.
- `Sheikha-Core` يعمل حاليًا على CPU، وقد تجاوز ميزانية أول Token في
  الاختبار الحي؛ لذلك فُعل التعافي بدل إبقاء الواجهة معلقة.
- لا يخفي التعافي فشل النموذج، ولا ينسب الرد المحلي إليه.
- لا ينفذ الشات أوامر نظام أو نشرًا خارجيًا، ولا يصدر فتوى أو حكمًا
  شرعيًا آليًا.
