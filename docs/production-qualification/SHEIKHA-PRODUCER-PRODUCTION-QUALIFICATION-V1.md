# منظومة شيخة لتأهيل المنتجين وجاهزية الإنتاج V1

## الغرض

توحد هذه المنظومة ملفات المنتج والمنتج المرشح في مسار واحد قائم على
الأدلة. وهي تدير التأهيل الداخلي وجاهزية الإصدار، ولا تصدر ترخيصًا
حكوميًا أو شهادة سلامة أو اعتمادًا خارجيًا.

الحالة الحالية:

- 13 منتجًا مسجلًا.
- 31 متطلب ملف إنتاج.
- 10 متطلبات إدارية.
- 11 متطلبًا هندسيًا.
- 10 متطلبات إنتاج وتشغيل.
- لا يوجد منتج جاهز للإنتاج دون ملف ومراجعة وتفويض.
- لا توجد شهادة خارجية صادرة عن شيخة.
- لا يوجد عتاد مادي مؤهل حتى تسجل تجربة فعلية موثقة.

## حدود السلطة

تستطيع شيخة إصدار:

- تأهيل داخلي لمنتج محدد وإصدار محدد.
- تفويض إنتاج داخلي محدود بعد قرار بشري موثق.

ولا تستطيع شيخة إصدار:

- ترخيص حكومي أو نظامي.
- اعتماد مختبر أو شهادة سلامة مستقلة.
- تصريح بيع عام دون عقد تجاري ملائم.
- تصريح تشغيل حرج دون الشهادات المطلوبة من الجهات المختصة.

أي دليل خارجي يبقى منسوبًا إلى مُصدره المختص، وتتحقق المنظومة من
مرجعه ولا تعيد إصداره باسمها.

## مسار القرار

```text
طلب المنتج
  -> التحقق من المخطط والحقول
  -> اكتمال الملف الإداري
  -> مراجعة هندسية مؤهلة
  -> مراجعة العتاد والسلامة عند انطباقها
  -> التحقق من دليل الجهة الخارجية عند وجوبه
  -> قرار بشري صريح
  -> تفويض إنتاج داخلي محدود
  -> سجل تدقيق
  -> تجديد أو تعليق
```

السياسة الافتراضية هي `DENY`. اكتمال الملف لا يعني صحة أدلته،
والتحقق الداخلي لا يحل محل الترخيص النظامي.

## ملفات الإنتاج

### الملفات الإدارية

تشمل هوية المنتج وإصداره، مرجع الكيان والمفوض، الملكية، العقد،
شروط الترخيص الداخلي، مصفوفة الجهات المختصة، الخصوصية، المسؤولية،
وأدلة الجهات الخارجية عند انطباقها.

### الملفات الهندسية

تشمل مواصفات المتطلبات، المعمارية وعقود الواجهات، خط أساس المصدر،
قوائم مكونات البرمجيات والعتاد، تأهيل العتاد، نموذج التهديدات،
تحليل السلامة، خطط ونتائج الاختبار، ومعايير الجودة.

### ملفات الإنتاج والتشغيل

تشمل خطة الإنتاج، المنشأة والمعدات عند انطباقها، كفاءة الفريق،
تتبع الموردين، الطاقة والموارد، التغليف والتوزيع، الرصد والدعم،
التعافي والتراجع، إدارة التغيير، ووثائق المستخدم والإدارة.

السجل التنفيذي الكامل موجود في:

```text
runtime/producer-production-qualification/v1/registries/
  production-file-requirements.json
```

## حماية المرشحين

التقييم يخص الكيان وقدرته على إنتاج منتج محدد فقط. تمنع المنظومة:

- جمع كلمات المرور والمفاتيح والرموز السرية.
- تصنيف الإيمان أو المذهب أو العرق أو الرأي السياسي.
- استنتاج السمات الحساسة.
- الرفض الآلي النهائي للمرشح.
- ترتيب المرشحين آليًا على أساس بيانات شخصية حساسة.

يستخدم ممثل الكيان مرجعًا معتمًا بدل تخزين هوية شخصية مباشرة في
سجل التأهيل.

## دور الذكاء الصناعي

يسمح للذكاء الصناعي بفحص الاكتمال والبصمات والاتساق وكشف النواقص.
ولا يسمح له بإصدار القرار النهائي، أو التحقق الحكومي من الهوية، أو
إصدار اعتماد خارجي، أو تجاوز المراجع البشري.

مرجعية القيم المعلنة هي الصدق والعدل والأمانة والوفاء بالعقود
والتثبت ومنع الضرر. هذه القيم ليست سلطة فتوى تنفيذية؛ وتبقى الأحكام
الشرعية الاجتهادية لمراجعة بشرية مؤهلة.

## API

المسار الأساسي:

```text
/api/sheikha/production-qualification/v1
```

المسارات العامة:

- `GET /status`
- `GET /requirements`
- `GET /requirements?family=ADMINISTRATIVE|ENGINEERING|PRODUCTION`
- `GET /products`
- `GET /products/:id`
- `POST /applications/evaluate`

المسارات المحمية:

- `POST /applications`: مسؤول أو مشغل أو حوكمة.
- `GET /applications`: مسؤول أو مشغل أو حوكمة.
- `POST /applications/:id/review`: مسؤول أو حوكمة.
- `POST /applications/:id/authorize`: مسؤول أو حوكمة.
- `POST /authorizations/:id/renew`: مسؤول أو حوكمة مع إعادة تحقق صريحة.
- `POST /authorizations/:id/suspend`: مسؤول أو حوكمة مع سبب موثق.
- `GET /authorizations`: مسؤول أو حوكمة.

لا تحفظ نقطة `evaluate` الطلب، ولا تثق بأدلة المرشح. الحفظ والمراجعة
والتفويض عمليات منفصلة ومحكومة.

## حالات الطلب

- `INVALID_APPLICATION`
- `INCOMPLETE_APPLICATION`
- `EVIDENCE_REVIEW_REQUIRED`
- `EVIDENCE_REJECTED_REMEDIATION_REQUIRED`
- `ENGINEERING_OR_REGULATORY_REVIEW_REQUIRED`
- `HUMAN_DECISION_REQUIRED`
- `ELIGIBLE_FOR_INTERNAL_PRODUCTION_AUTHORIZATION`
- `AUTHORIZED_INTERNAL`
- `AUTHORIZATION_SUSPENDED`

حالات التفويض تشمل `ACTIVE_INTERNAL` و`SUSPENDED_INTERNAL` و
`SUPERSEDED_INTERNAL`. لا يدخل التفويض المنتهي زمنيًا في حساب
الجاهزية حتى لو بقي السجل التاريخي محفوظًا.

```bash
npm run -s ops:production-qualification:test:v1
```

مخرجات التفعيل:

```text

  contracts/

  registries/

```

مرتبط بمنتج وإصدار ونطاق بعد مراجعة أدلته وقرار بشري صريح.
