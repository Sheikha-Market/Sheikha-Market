# حوار شيخة الفكري البنّاء بالذكاء الصناعي V3

## الغرض

تربط هذه الطبقة سجل شيخة التعليمي المكوّن من 19 إطارًا فكريًا
معاصرًا و18 إطارًا تاريخيًا بمزود الذكاء المحلي متعدد النماذج. وتحوّل
خطة الحوار المحكومة إلى جواب عربي يساعد على فهم الفكرة ومناقشة
أهدافها ودعاواها ووسائلها وأدلتها ومخاطرها.

لا تصنف الطبقة الإنسان ولا تستنتج دينه أو مذهبه أو توجهه السياسي.
المطابقة النصية تعني أن الموضوع قد يرتبط بإطار معرفي، ولا تعني أن
المستخدم ينتمي إليه.

## مسار التنفيذ

```text
رسالة المستخدم
      |
      v
بوابة منع التصنيف والاستهداف والإكراه
      |
      v
خطة الحوار المعرفي V2
      |
      v
سياق جمهور غير حساس يختاره المستخدم
      |
      v
مراجع منهجية مسجلة مع حدود الاستعمال
      |
      v
مزود ذكاء شيخة المحلي
      |
      v
فحص الجودة والاستشهاد والخصوصية
      |
      v
جواب بنّاء أو موجز حتمي آمن للمراجعة
```

## سياقات الجمهور

التكييف مبني على حاجة التواصل، وليس على سمة شخصية خفية:

- الجمهور العام.
- المتعلم.
- الممارس التقني.
- الباحث.
- ميسر الحوار المجتمعي.
- مراجع القرار.

كل سياق يغيّر مستوى المصطلحات وعمق الدليل وطريقة الافتتاح فقط.
لا يسمح بالاستدلال على العمر أو الدين أو المذهب أو السياسة أو تكوين
ملف شخصي.

## مرجعية الكتاب والسنة

تستخدم المنظومة بيانات الاستشهاد المسجلة لتطبيق قيم الحكمة والعدل
والتثبت ومنع الضرر وحفظ الكرامة. ولا تسمح للنموذج بنقل نص آية أو حديث
من ذاكرته أو اختراع مرجع.

المراجع هنا مراسي منهجية وليست سلطة تفسير آلية. لا تصدر المنظومة
فتوى أو حكمًا عقديًا أو تفضيلًا بين المذاهب، ويلزم عالم مؤهل لكل حكم
شرعي تفصيلي. وتظل حالة المصدر ودرجة الحديث المسجلة ظاهرة، فلا يستعمل
طريق ضعيف بوصفه دليلًا منفردًا حاسمًا.

## الخصوصية

- لا يحفظ محرك V3 نص الرسالة الخام.
- يسجل مزود الذكاء بصمات SHA-256 والقياسات فقط.
- عند المرور عبر Conversation Engine يمنع حفظ المحتوى في الذاكرة
  وPostgreSQL، ويكون سجل المحادثة ميتاداتا وبصمات فقط.
- لا يخزن معتقد المستخدم ولا ينشئ درجة فكرية أو دينية.

## واجهات API

- `GET /api/sheikha/constructive-thought-dialogue/v3/status`
- `GET /api/sheikha/constructive-thought-dialogue/v3/audiences`
- `GET /api/sheikha/constructive-thought-dialogue/v3/frameworks/matrix`
- `POST /api/sheikha/constructive-thought-dialogue/v3/respond`

ويمكن تشغيله من مسار الشات الأساسي بإرسال:

```json
{
  "message": "قارن بين الليبرالية والاشتراكية في مفهوم العدالة",
  "dialogueMode": "constructive",
  "audienceContext": "GENERAL_PUBLIC",
  "religiousLensRequested": true,
  "mode": "standard"
}
```

كما يلتقط الشات تلقائيًا الطلبات الصريحة مثل «قارن الليبرالية
والاشتراكية». هذا اكتشاف لموضوع الفكرة فقط، وليس استنتاجًا لانتماء
المستخدم. ويظل `dialogueMode: constructive` وسيلة التفعيل الصريح.

وضع `ultra` لا يعمل دون `ultraBudgetApproved: true`.

## التفعيل والتحقق

```bash
npm run -s ops:thought-dialogue:ai:v3
npm run -s ops:thought-dialogue:ai:test:v3
```

التقرير المحلي لا يثبت صحة كل إجابة ولا شمول جميع أفكار العالم.
الإجابة الذكية أداة تعليمية قابلة للنقد، والإنسان صاحب القرار
والمسؤولية.

ينفذ التفعيل Self-test حتميًا عبر عقد مزود الذكاء دون تشغيل نموذج حي،
ويحفظ بصمة المخرج والقياسات فقط. نجاحه يثبت سلامة الربط البرمجي، ولا
يثبت جودة النموذج الحي أو صحة الاستنتاجات الدينية.
