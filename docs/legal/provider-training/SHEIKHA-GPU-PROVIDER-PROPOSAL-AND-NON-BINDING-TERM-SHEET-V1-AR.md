# مقترح شيخة لمزودي الحوسبة واتفاق المبادئ غير الملزم V1

> **حالة الوثيقة:** مسودة تفاوضية غير ملزمة، لا تنشئ عقدًا أو شراكة أو وكالة أو تفويضًا أو طلب شراء أو التزامًا ماليًا. تخضع لمراجعة محامٍ مرخص قبل التوقيع أو الاستخدام.

## 1. الغرض

تستخدم هذه الوثيقة لطلب معلومات وعرض فني ومالي من مزود حوسبة GPU محتمل، دون السماح له بالوصول إلى بيانات شيخة أو كودها أو نماذجها أو حساباتها أو أسرارها، ودون بدء تدريب أو تشغيل أو نقل بيانات.

## 2. الأطراف المقترحة

- الطرف الأول: الكيان القانوني المالك لمنظومة شيخة، ويستكمل اسمه ورقم سجله وعنوانه قبل التوقيع.
- الطرف الثاني: المزود المرشح، ويستكمل اسمه القانوني ورقم تسجيله وعنوانه وصفة ممثله.
- لا يجوز استعمال الاسم التجاري وحده بدل البيانات القانونية المثبتة.

## 3. الطبيعة غير الملزمة وعدم التفويض

1. هذه الوثيقة بيان نوايا وطلب معلومات فقط.
2. لا تمثل قبولًا لشروط المزود، ولا اشتراكًا، ولا أمر شراء، ولا حجز سعة.
3. لا تمنح المزود وكالة أو نيابة أو ولاية أو تفويضًا بالتوقيع أو الشراء أو التعاقد أو الإنفاق أو تمثيل شيخة أمام الغير.
4. لا تمنح المزود صلاحية دخول أو إدارة حسابات شيخة أو إنشاء مستخدمين أو مفاتيح أو موارد باسمها.
5. لا تمنح المزود إذنًا بمعالجة أو نسخ أو نقل أو فحص أو استخدام أي بيانات أو كود أو أوزان أو مطالبات أو سجلات تخص شيخة.
6. لا يجوز للمزود وصف نفسه بأنه شريك أو وكيل أو ممثل أو مزود معتمد لشيخة استنادًا إلى هذه الوثيقة.
7. لا ينشأ أي التزام إلا بعقد نهائي مكتوب وموقع من أصحاب الصلاحية، وبعد استكمال مراجعات الأمن والخصوصية والقانون والميزانية.

## 4. الملكية وعدم الترخيص الضمني

1. يحتفظ كل طرف بكامل ملكية موارده السابقة على العلاقة، بما فيها البرمجيات والمعدات والعلامات والبيانات والمنهجيات والأسرار التجارية.
2. تبقى أصول شيخة، بما فيها البيانات والكود ومجموعات التدريب والتقسيمات وملفات الضبط والتقييمات والسجلات والأوزان التي تملكها أصلًا، ملكًا لصاحبها ولا تنتقل للمزود.
3. لا تمنح هذه الوثيقة أي ترخيص صريح أو ضمني في حقوق الملكية الفكرية لأي طرف.
4. لا يجوز استخدام اسم شيخة أو علامتها أو نتائج التقييم في الإعلان أو التدريب أو القياس المقارن أو دراسة الحالة.
5. ملكية أي نموذج أو مخرجات مستقبلية لا تُفترض بهذه الوثيقة، وتحدد فقط في العقد النهائي مع مراعاة حقوق البرمجيات والبيانات والنماذج السابقة المملوكة للغير.

## 5. المعلومات المطلوبة من المزود

يقدم المزود عرضًا مكتوبًا يشمل:

- أنواع GPU الفعلية، عددها، ذاكرتها، طوبولوجيا الربط، والشبكة والتخزين.
- المنطقة القانونية وموقع معالجة البيانات والنسخ الاحتياطية والدعم الفني.
- نموذج العزل: جهاز مخصص أو مستأجر متعدد العملاء، وحدود العزل الموثقة.
- دعم الشبكات الخاصة وmTLS وإدارة مفاتيح العميل والتشفير أثناء النقل والتخزين.
- صور تشغيل ثابتة ببصمات، وسجل تغييرات، وفحص ثغرات، وSBOM عند توفره.
- سياسة الموظفين ذوي الصلاحية، وسجلات الوصول، والإبلاغ عن الحوادث.
- سياسة الاحتفاظ والحذف وإثبات الإزالة بعد انتهاء التجربة.
- قابلية منع خروج الشبكة افتراضيًا وقائمة الوجهات المسموحة.
- الأسعار، الحد الأدنى، رسوم الإلغاء، رسوم نقل البيانات، والضرائب، دون إنشاء التزام.
- شروط الملكية والبيانات والتدريب على بيانات العملاء ومنع استخدامها لتحسين خدمات المزود.
- قائمة المعالجين الفرعيين ومواقعهم وآلية الاعتراض على تغييرهم.
- شهادات أو تقارير تدقيق موجودة فعلًا مع جهة الإصدار والنطاق وتاريخ الصلاحية.

## 6. متطلبات شيخة غير القابلة للتجاوز في العقد النهائي

- الاستخدام لغرض التدريب المحدد فقط، وبأقل صلاحية ولأقصر مدة.
- منع التدريب أو التحسين أو التحليل التجاري للمزود باستخدام أصول شيخة.
- منع البيع والمشاركة والإفصاح والنشر والتعدين والتنميط.
- منع المعالجين الفرعيين إلا بعد موافقة كتابية محددة.
- منع النقل بين المناطق أو خارج النطاق المعتمد دون مراجعة مكتوبة.
- بقاء مفاتيح التشفير والأسرار تحت تحكم شيخة أو خزنة معتمدة.
- حق التدقيق والحصول على سجلات الوصول والحوادث والاستهلاك.
- إبلاغ عاجل عن الحوادث مع حفظ الأدلة وعدم إتلافها.
- حذف قابل للتحقق للبيانات والنسخ والـcheckpoints المؤقتة عند انتهاء العمل.
- سقف مالي، وإيقاف تلقائي، ومنع إنشاء موارد مدفوعة بلا موافقة بشرية.
- حظر النشر التجاري للنموذج قبل بوابات الجودة والأمان والقانون والمراجعة البشرية.

## 7. حماية البيانات

لا تُنقل بيانات شخصية في مرحلة التفاوض. وإذا شمل العقد النهائي معالجة بيانات شخصية، فيجب تحديد دور المتحكم والمعالج، وتعليمات المعالجة، والغرض، والمدة، والفئات، والتدابير، والمعالجين الفرعيين، والإزالة، والتدقيق، ونقل البيانات عبر الحدود وفق الأنظمة المنطبقة. لا تحل هذه المسودة محل اتفاق معالجة بيانات أو البنود النظامية المطلوبة للنقل الدولي.

## 8. المقترح الفني المرحلي

1. **RFI بلا بيانات:** مقارنة السعة والمنطقة والأمن والتكلفة.
2. **إثبات قدرة ببيانات اصطناعية:** عقد محدود وميزانية محدودة وعقدة معزولة.
3. **تجربة بيانات غير شخصية ومرخصة:** بعد DPA ومراجعة الحقوق.
4. **تدريب موزع محكوم:** بعد قبول العقد والأمن والسعة وخطة التراجع.
5. **تقييم مستقل:** جودة وأمان وخصوصية وتكلفة واستقرار.
6. **Canary:** خدمة محدودة بلا ترقية تلقائية.
7. **تشغيل تجاري:** عقد نهائي واعتماد قانوني وتشغيلي منفصل.

## 9. انتهاء التفاوض

يجوز لأي طرف إنهاء التفاوض دون مسؤولية أو سبب. لا يجوز بعد الإنهاء الاحتفاظ بأي مادة سرية تم تبادلها بموجب اتفاق سرية ملزم مستقل. ولأن هذه الوثيقة غير ملزمة، يجب عدم تبادل أسرار أو بيانات أو كود قبل توقيع NDA/DPA ملزمين عند الحاجة.

## 11. حدود قانونية

هذه صياغة تشغيلية أولية وليست فتوى أو استشارة قانونية. يلزم محامٍ مرخص لتحديد القانون الواجب التطبيق، والاختصاص، وصحة البنود، والضرائب، وحقوق الملكية، ومتطلبات حماية البيانات ونقلها خارج المملكة.
