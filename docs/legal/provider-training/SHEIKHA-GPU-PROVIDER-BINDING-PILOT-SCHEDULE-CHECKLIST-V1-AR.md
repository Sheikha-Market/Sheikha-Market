# قائمة عقد تجربة GPU الملزم قبل أي تشغيل V1

هذه ليست موافقة تشغيل، بل قائمة البنود التي يجب تحويلها إلى عقد ملزم ومراجعتها قانونيًا قبل منح المزود أي وصول.

## التحديد

- الكيانان القانونيان وصفة الموقعين.
- الخدمة، المنطقة، نوع GPU، العدد، المدة، والسقف المالي.
- الغرض الوحيد وتعريف البيانات والأصول المسموحة تحديدًا.
- مصفوفة المسؤوليات، دون وكالة أو نيابة أو صلاحية تعاقد باسم شيخة.

## الإذن التقني الضيق

- يمنح المزود إذن معالجة تقنيًا محدودًا وضروريًا لتنفيذ المهمة المحددة فقط.
- الإذن ليس بيعًا أو تنازلًا أو ترخيصًا عامًا أو تفويضًا إداريًا أو وكالة.
- لا يجوز تجاوز تعليمات شيخة أو إعادة استخدام البيانات أو المخرجات.
- تنتهي الصلاحية تلقائيًا بانتهاء المهمة أو العقد.

## الملكية

- ملكية كل طرف لموارده السابقة محفوظة.
- بيانات شيخة وكودها وملفات الضبط والتقييم والسجلات لا تنتقل للمزود.
- تحديد ملكية checkpoints والأوزان والمخرجات كتابةً، مع استثناء حقوق الغير السابقة.
- منع أي حق حبس أو استخدام للمخرجات بسبب نزاع مالي إلا إذا أجازه القانون والعقد صراحة.

## الأمن والخصوصية

- شبكة خاصة، mTLS، تشفير، مفاتيح محكومة، RBAC، MFA، وأقل صلاحية.
- صورة ثابتة ببصمة، منع shell الإداري غير المصرح، ومنع الخروج افتراضيًا.
- سجلات وصول غير قابلة للتعديل، مزامنة وقت، ومراقبة تكلفة وموارد.
- إخطار حادث وفق مدة يحددها المستشار القانوني، مع احتواء وتحقيق وحفظ أدلة.
- معالجون فرعيون بموافقة مسبقة وقائمة مناطق وأغراض.
- حذف قابل للتحقق مع شهادة إزالة، بما يشمل النسخ المؤقتة والـsnapshots.
- DPA وبنود نقل دولي عند انطباقها.

## التشغيل والقبول

- معايير قبول الأداء والسعة والاتصال والاستقرار.
- اختبار استعادة checkpoint، انقطاع عقدة، وإيقاف آمن.
- عدم ترقية نموذج أو نشره أو بيعه تلقائيًا.
- بوابات جودة وأمان وترخيص وCanary وموافقة بشرية.
- خطة خروج ونقل artifacts بصيغ قياسية وعدم حبس المزود.

## المالية والمسؤولية

- سقف تكلفة صلب وتنبيهات وإيقاف تلقائي.
- منع أي مورد إضافي أو تجديد تلقائي دون أمر مكتوب.
- بيان الرسوم والضرائب ونقل البيانات والإلغاء.
- ضمانات وتعويضات وحدود مسؤولية يراجعها محامٍ بما يلائم المخاطر.
- تأمين سيبراني ومتطلبات استمرارية عند الحاجة.

## أدلة الإغلاق

- سجل الموارد والفواتير والاستهلاك.
- بصمات الصور والبيانات والـcheckpoints والمخرجات.
- نتائج الاختبارات والتقييم والحوادث.
- شهادة حذف وإبطال المفاتيح وإغلاق الحسابات المؤقتة.
