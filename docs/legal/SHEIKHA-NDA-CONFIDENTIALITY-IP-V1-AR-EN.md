## 2. المعلومات السرية

تشمل كل معلومة غير عامة أفصح عنها قبل أو بعد السريان وجرى تحديدها في الملحق (أ)، ومنها الأفكار والمدخلات والمحادثات والوثائق والكود والتصاميم والبيانات والنماذج والأوزان ومجموعات البيانات والأبحاث والخطط والأسعار والعملاء والموردون والمعلومات التجارية وغير التجارية والأدلة الأمنية والتشغيلية، بأي وسيط.

لا تسري الحماية بأثر رجعي على معلومة سابقة إلا إذا حددت بما يكفي في الملحق (أ) ووقع الطرفان على إدراجها. ولا تشمل المعلومات التي يثبت المستلم أنها أصبحت عامة دون خرق، أو كانت لديه بصورة مشروعة قبل الإفصاح، أو استلمها قانونيًا بلا التزام سرية، أو طورها استقلاليًا دون استخدام المعلومات السرية.

## 3. المنع الافتراضي والغرض

لا يمنح تسليم المعلومات ملكية أو ترخيصًا ضمنيًا. يحظر دون تفويض مكتوب ومحدد وموقع:

- النشر أو الإفصاح أو الإعلان أو الدعاية أو الإسناد العلني.
- النقل لطرف ثالث أو معالج فرعي أو خارج النطاق الجغرافي المعتمد.
- النسخ غير اللازم أو الترخيص أو الترخيص الفرعي أو البيع.
- الهندسة العكسية أو إنشاء منتج مشتق أو منافس باستخدام المعلومات السرية.
- إدخال المعلومات في تدريب أو ضبط أو تقييم نموذج ذكاء اصطناعي.
- استخدام اسم شيخة أو علاماتها أو نتائج العمل في قوائم العملاء أو الدراسات التسويقية.

يقتصر الاستخدام على الغرض المحدد، وبأقل صلاحية وكمية ومدة لازمة.

## 4. الملكية الفكرية ونتاج العمل

- تبقى الحقوق السابقة والمعلومات السرية مملوكة لمالكها النظامي.
- لا تنتقل ملكية المدخلات لمجرد إرسالها أو تخزينها أو معالجتها.
- ملكية نتاج العمل وترخيصه وحدود استخدامه تحدد في أمر خدمة أو ملحق ملكية منفصل موقع؛ ولا يفترض انتقالها في هذه الاتفاقية.
- أرقام السياسات والتراخيص الداخلية لشيخة معرفات تشغيلية، وليست براءة أو علامة مسجلة أو اعتمادًا حكوميًا ما لم يرفق دليل صادر عن الجهة المختصة.

## 5. البيانات الشخصية والتدريب

تعالج البيانات الشخصية وفق الغرض والسند النظامي ومبادئ تقليل البيانات والاحتفاظ المحدد وأقل صلاحية وحقوق أصحاب البيانات. لا تستخدم بيانات العميل أو أسراره في التدريب افتراضيًا. يحتاج أي تدريب إلى موافقة منفصلة صريحة قابلة للإثبات، وتعريف dataset وبصمتها، وفحص PII والأسرار، وحدود الاحتفاظ والسحب والحذف، واتفاقية معالجة بيانات عند انطباقها.

## 6. الحماية التشغيلية

يلتزم المستلم بالتشفير أثناء النقل والتخزين عند الاقتضاء، والفصل بين البيئات والعملاء، والمصادقة القوية، وسجلات تدقيق لا تحتوي النص السري، وإدارة الثغرات، ومنع الأسرار في المستودعات العامة. يبلغ الطرف المفصح عن الحادث دون تأخير غير مبرر وفق العقد والنظام وخطة الاستجابة.

## 7. الإفصاح الملزم نظاميًا

لا يعد الادعاء بوجود إلزام كافيًا. يتحقق المستلم قانونيًا من الأساس والنطاق، ويشعر مالك الحقوق قبل الإفصاح متى سمح النظام، ويكشف الحد الأدنى اللازم فقط، ويسجل القرار والأدلة. لا يجيز هذا البند إخفاء مخالفة أو تعطيل حق نظامي لصاحب بيانات أو جهة مختصة.
