# إشعار الخصوصية وملحق معالجة البيانات V1

الحالة: `DRAFT_FOR_PDPL_REVIEW`

## الأدوار والغرض

يحدد العقد هل SHEIKHA جهة تحكم أو معالجة لكل غرض. لا تجمع إلا البيانات اللازمة للتشغيل والأمن والفوترة والدعم، وبسند نظامي موثق.

## الضوابط

- سجل فئات البيانات والغرض والسند والاحتفاظ والمستلمين والموقع.
- منع الأسرار والبيانات الحساسة من التدريب افتراضيًا.
- تشفير النقل والتخزين، أقل صلاحية، سجلات تدقيق، وفصل المستأجرين.
- تقييم نقل البيانات خارج المملكة قبل النقل، وعقد مع كل معالج فرعي.
- استجابة لحقوق صاحب البيانات ضمن المدد النظامية، وإدارة الحوادث والإشعارات.
- حذف أو إعادة بيانات العميل عند انتهاء العقد وفق جدول الاحتفاظ والالتزامات النظامية.

## التدريب والتحسين

القيمة الافتراضية `NO_TRAINING_ON_CUSTOMER_DATA`. أي استثناء يحتاج موافقة منفصلة محددة، وDPA، ومصدر ومدة وحق سحب، وفحص PII وأسرار، وبصمة dataset.

## الحقول المطلوبة

`[هوية جهة التحكم، مسؤول الخصوصية، بريد الطلبات، فئات البيانات، الاحتفاظ، المعالجون الفرعيون، الدول، تدابير الأمن، آلية الشكوى]`.

هذا قالب امتثال وليس إثبات امتثال؛ يلزم سجل معالجة واختبار ضوابط ومراجعة PDPL قبل النشر.
