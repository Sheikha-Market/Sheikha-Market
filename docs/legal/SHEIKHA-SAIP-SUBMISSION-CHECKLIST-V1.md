# قائمة تجهيز إيداع شيخة لدى الهيئة السعودية للملكية الفكرية — الإصدار 1

## ملف البرمجيات

- [ ] اسم المصنف وإصداره.
- [ ] اسم صاحب الحق وصفته.
- [ ] أسماء المؤلفين والمساهمين وعقودهم أو تنازلاتهم عند وجودها.
- [ ] تاريخ الإنشاء وأول نشر.
- [ ] وصف وظيفي وتقني غير مضلل.
- [ ] نسخة إيداع خالية من كلمات المرور والمفاتيح والأسرار.
- [ ] بصمة SHA-256 لنسخة الإيداع.
- [ ] قائمة المكونات الخارجية ورخصها.
- [ ] بيان ما يملكه مقدم الطلب وما لا يملكه.
- [ ] إثباتات الهوية أو المنشأة بحسب صفة الطلب.

## ملف النص المكتوب

- [ ] الرخصة العربية.
- [ ] الترجمة الإنجليزية.
- [ ] بيان اللغة الحاكمة.
- [ ] سجل النسخة والتاريخ.
- [ ] سجل اعتماد المالك.
- [ ] مراجعة قانونية.
- [ ] بصمة الملفات.

## بعد التقديم

- [ ] حفظ رقم الطلب.
- [ ] حفظ الفواتير والإيصالات.
- [ ] حفظ كل مراسلة أو طلب استكمال.
- [ ] عدم إعلان صدور شهادة قبل صدورها فعلاً.
- [ ] عند صدور الشهادة: تسجيل رقمها وتاريخها ونطاقها ونسخة منها.
- [ ] تحديث واجهات الرخصة بالحالة الرسمية الدقيقة فقط.
