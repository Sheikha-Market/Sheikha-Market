# شيخة: فوندري تصميم الروبوتات والحركة

## الحالة الفعلية

نُفّذ استوديو محلي لتكوين روبوتات تصورية، ومعاينة حركتها ثلاثية الأبعاد، وتوليد فيديو MP4، وإدارة سجل الإنتاج والأدلة. الاسم التشغيلي: SHEIKHA Robotics Foundry ضمن SHEIKHA UGIT-RP.

المحرك «شيخة المحلي» يبني هندسة بارامترية باستخدام Three.js ويحوّل إطاراتها إلى فيديو باستخدام FFmpeg. ليس نموذج فيديو توليديًا مدرّبًا باسم شيخة، ولا خدمة سحابية متصلة، ولا روبوتًا حقيقيًا متحركًا.

الواجهة: `http://127.0.0.1:4193/workspace/robot-studio.html`

## العائلات والأدوات

| العائلة | الرمز | الأدوات المتاحة | ملف التحكم المقترح |
| --- | --- | --- | --- |
| المتحرك | SH-M01 | وحدة فحص بصرية، منصة حمل | قاعدة بعجلات، تحديد موضع وقراءة عوائق |
| الذراع | SH-A01 | قابض تصوري، وحدة فحص بصرية | قاعدة وكتف ومرفق ومعصم، قراءة موضع وعزم |
| الاستقبال | SH-R01 | واجهة عرض، منصة حمل | منصة ثابتة، واجهات محلية وتشخيص |
| الرقمي | SH-D01 | واجهة عرض، وحدة فحص بصرية | آلة حالات رقمية ونبض تطبيق |

هذه أربع عائلات أولية قابلة للتوسعة، وليست تغطية لجميع الروبوتات أو أدواتها. قوائم الحساسات والمحاور اقتراحات واجهات وليست مكونات مشتراة أو مختبرة. لا تعرّف على وجوه أو جمع بيانات أشخاص.

الألوان: الأخضر، الفاتح، الجرافيت، مع تفاصيل ذهبية وسيانية. المقياس 0.8–1.2 بلا وحدة هندسية. يختار المستخدم حركة عرض المهمة أو دوران الفحص. «استكشف بديلًا» يتنقل بين تكوينات محددة، ولا يدعي اكتشاف اختراع جديد.

## المعمارية

```text
واجهة التصميم والضوابط
  -> تحقق مغلق من العائلة/الأداة/التشطيب/المقياس/الحركة
  -> ملف تصميم ذي بصمة SHA256
  -> آلة الحالات الرقمية الموجودة في المشروع
  -> مشهد Three.js للحركة البصرية
  -> عامل إخراج محلي معزول من حيث نطاق الطلبات
  -> FFmpeg وffprobe وفك ترميز كامل
  -> دليل إنتاج وبصمة MP4
  -> مراجعة بشرية، دون نشر تلقائي
```

تعيد `buildDesign` استخدام `SheikhaDigitalRobot` و`runScenario`، ويعيد سجل القنوات استخدام `runConnectorScenario`. اختبار آلة الحالات منفصل عن تحريك المجسم؛ المجسم ليس محلل ديناميكا أو توأمًا معايرًا للأجهزة. حركة الذراع إظهار مفاهيمي، لا حل حركيات عكسية أو مسار موثق خالٍ من التصادم.

لكل عائلة قائمة وحدات هيكل وملف تحكم مستقلان. الكتلة والأبعاد الحقيقية والحمولة والمواد والطاقة ونسب التخفيض والعزم والحدود والبروتوكول والعتاد وFirmware غير محددة أو غير منفذة. الأسماء التصورية ليست BOM تصنيع.

## خط الإنتاج والإدارة

1. معماري النظام: تعريف المتطلبات والتكوين.
2. التحكم والبرمجيات: مراجعة عقد التحكم والمحاكاة.
3. فوندري المرئيات: بناء المشهد وإخراج 96 إطارًا.
4. الجودة والحارس: التحقق من 4 ثوانٍ و24 إطارًا/ثانية و960×540، وفك الترميز والبصمة.
5. مراجع بشري: اعتماد المحتوى والحقوق والوضوح، لم يُعيّن شخص بعد.
6. فريق هندسي: مراجعة العتاد والسلامة قبل أي انتقال إلى تصنيع أو تجربة جهاز.

الحالات: `RENDERING` ثم `DRAFT_REQUIRES_HUMAN_REVIEW` أو `FAILED`. بعد إعادة تشغيل الخادم لا تُعرض حالة عامل قديم باعتبارها تشغيلًا حيًا، بل `WORKER_UNVERIFIED`.

عامل واحد محلي في كل مرة، قفل ملف مشترك، مهلة ثلاث دقائق، وحد أقصى 24 مهمة. يُرفض بدء مهمة عند تجاوز الملفات المحفوظة 256 MiB؛ هذا حد قبول وليس حصة قرص صلبة للإطارات المؤقتة. لا حذف آلي للأصول أو للنتائج السابقة. المخرجات في `runtime/robot-studio/<job-id>/`، ومستثناة من Git:

- `blueprint.json`: ملف التصميم والمحاكاة والحدود.
- `video.mp4`: مرئي الحركة، بلا صوت.
- `poster.png`: لقطة مرجعية مشتقة من الإخراج.
- `evidence.json`: المواصفات والبصمة والتحقق.
- `job.json`: حالة العملية وتوقيتها.

الإنتاج متاح عند الطلب من الواجهة، وليس توليدًا يوميًا جديدًا مفعلًا تلقائيًا. عند تعطل العملية قد يبقى `.render.lock`؛ يجب فحص العامل والسجل إداريًا قبل إزالة قفل قديم. لا يوجد زر واجهة يحذف القفل أو يتجاوز حدود المراجعة.

## التكامل مع المنتجين

عقد `SHEIKHA_PRODUCER_REQUEST_V1` قابل للتنزيل، يضم ملف التصميم والتسليمات المطلوبة ومنع النشر والإنفاق والتحكم المادي. يظل `NOT_SENT`؛ تنزيله لا يعني إرساله إلى منتج.

يمكن استيراد JSON لا يتجاوز 8 KiB بعقد `SHEIKHA_PRODUCER_RECEIPT_V1`، يحمل `designId` مطابقًا واسم منتج ومرجع تسليم وبصمة ملف. النتيجة `CONTRACT_VALID_UNVERIFIED_CONTENT` تؤكد البنية فقط: لم يُجلب الملف، ولم تُفحص بصمته فعليًا، ولم تُوثّق هوية المنتج. يُرفض أي عنوان اتصال أو حقل إضافي أو مرجع تصميم مختلف. بيانات الاختبار لا تُعرض كتكامل منتج حقيقي.

لا مزوّد خارجي معتمد أو ميزانية أو أسرار إعداد؛ مسار الفيديو الخارجي معطّل. لا نسخ مفاتيح إلى ملفات التصميم أو الطلبات. إضافة مزوّد لاحقًا تحتاج محوّلًا موثقًا واختبارات عقد وهوية وصلاحيات وحد إنفاق وتخزين أسرار مستقلين، ومراجعة قبل النقل والنشر.

## واجهات محلية

البادئة `/api/sheikha/workspace/v1/studio`:

| المسار | الوظيفة |
| --- | --- |
| GET `/` | العائلات والخط والقنوات ومتطلبات الإخراج وسجل المهام |
| POST `/design` | بناء ملف تصميم ومحاكاة محلية |
| POST `/render` | إنتاج فيديو محلي محدود |
| GET `/jobs/:id` | حالة مهمة محددة |
| GET `/jobs/:id/:file` | أربع ملفات مسموحة فقط بعد نجاح المهمة |
| POST `/exchange` | إنشاء عقد طلب منتج غير مرسل |
| POST `/receipt` | التحقق البنيوي من سجل تسليم |
| POST `/physical-command` | رفض دائم 403، بلا إرسال أمر |

تطبق بوابة المعاينة تحقق Host وOrigin وSession وJSON وحد المعدل والحجم. لا يسمح للعميل بتحديد ملف إخراج أو أمر shell أو مزوّد أو URL. عامل المتصفح يمنع الطلبات خارج خادم loopback المحدد. هذه ضوابط تطبيق محلي، وليست شهادة عزل أمني لنشر متعدد المستخدمين؛ Chromium يعمل بإعداد الاختبار المحلي `--no-sandbox`، لذلك لا تُستخدم ملفات أو شيفرة مشاهد من جهات خارجية.

## العتاد الحقيقي

لا سواقات أجهزة أو أوامر حركة فعلية. الإيقاف بالواجهة يثبت حركة المعاينة فقط؛ ليس دائرة إيقاف طارئ أو وسيلة سلامة للأجهزة. الانتقال يحتاج طرازًا دقيقًا ومواصفات محركات وأدوات وحدودًا معايرة وهوية متحققة ومتحكم سلامة مستقلًا ومراجعة هندسية واختبارات جهاز مأذونة. لا تمنح راية يرسلها المستخدم صلاحية تجاوز ذلك.

الابتكار والتصميم والاستكشاف هنا لا يثبتان جدّة براءة اختراع، أو قابلية تصنيع، أو مطابقة معيار. مرجعية الكتاب والسنة تُترجم إلى الصدق والأمانة وحفظ الحقوق وعدم الإيهام، دون فتوى أو اعتماد شرعي آلي.

## التشغيل والتحقق

```bash
PORT=4193 node tools/preview/sheikha-workspace-preview.cjs
node tools/media/sheikha-robot-examples.cjs 4193
node --test --test-concurrency=1 tests/sheikha-design-studio.test.cjs tests/sheikha-robot-studio-browser.test.cjs
```

تحتاج أدوات الإخراج Node.js وFFmpeg/ffprobe وChromium وPlaywright. يمكن تحديد `FFMPEG` و`FFPROBE` و`LD_LIBRARY_PATH` و`CHROME_PATH` و`PLAYWRIGHT_MODULE` في بيئة الخادم، لا في طلب الواجهة. النسخ المؤقتة في `/tmp` ليست تثبيتًا دائمًا؛ عند غيابها تعرض الواجهة عدم جاهزية الإخراج وتمنع البدء.

تغطي الاختبارات العائلات والأدوات والمدخلات المرفوضة وعقود المنتجين وبوابة الأوامر المادية والتزامن وحالة العامل، إضافة إلى لقطات Playwright للحاسوب والجوال وفحص بكسلات المشهد والحركة والإيقاف وإنتاج MP4 فعلي وفحصه. أدلة الواجهة في `runtime/workspace-verification/robot-studio-browser-verification.json`.
