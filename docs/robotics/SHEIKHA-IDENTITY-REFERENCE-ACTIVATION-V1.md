# تفعيل مراجع هوية شيخة محليًا

تم فحص تسعة مراجع بصرية محليًا، وتسجيل بصماتها في runtime/sheikha-robotics/v1/identity-references.json. أُضيفت ست صور إلى لوحة الهوية المحلية؛ ثلاث صور تتضمن بيانات خاصة، لذلك لم تُنسخ إلى معرض العرض. الأصول بقيت دون تعديل.

الربط: الأساسات → الهوية والحوكمة → النواة والتخطيط → الحساسات → الروبوت والتوأم الرقمي → المصنع والإنتاج → سلسلة الإمداد. الصور مرجع تصميم وليست دليلًا على وجود مصانع أو تشغيل عتاد أو ملكية قانونية مثبتة.

اللوحة: sheikha-live-identity-v1.html. النطاق LOCAL_BROWSER_GALLERY. تشغيل الصور داخل الضيف الأصلي UNKNOWN، والتفعيل الإنتاجي غير معتمد. فحص سلامة صورة البيئة الأصلية منفصل؛ لا يثبت دمج واجهة رسومية فيها. لم يتم نشر أو تغيير VPS أو تشغيل عتاد.
