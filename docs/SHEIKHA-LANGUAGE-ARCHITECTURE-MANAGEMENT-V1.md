# هيكلة لغة شيخة وإدارتها ومعماريتها

## النطاق

لغة شيخة الحالية تنفيذ مستضاف على Node.js. التحقق المحلي للمترجم وبيئة التنفيذ منفصل عن النشر الإنتاجي وعن الاستضافة الذاتية أو تحويل جميع أنظمة المنصة. لا يُعلن التفعيل بمجرد وجود ACTIVE في سجل.

## الطبقات المعتمدة

| الطبقة | المكوّن | المسؤولية |
|---|---|---|
| المصدر والقواعد | sheikha-language/grammar وcompiler/lexer.js وparser.js | النص العربي والتحليل إلى AST |
| الدلالة والأنواع | compiler/type-checker.js | منع ترجمة البرامج ذات أخطاء الأنواع |
| التمثيل الوسيط | compiler/ir.js | خفض AST إلى خطوات تنفيذ |
| الترجمة | compiler/bytecode.js وtarget-generators.js | Bytecode وأهداف توليد الكود |
| التنفيذ | compiler/vm.js وbytecode-vm.js | تنفيذ محلي مستضاف مع توقف عند مخالفة الحوكمة |
| الحوكمة والعزل | compiler/governance.js وsandbox-policy.js | فحص الضوابط والعزل؛ المرجعية القيمية غير تنفيذية ولا تصدر فتوى |
| الإدارة الموحدة | core/language/sheikha-managed-language-v1.cjs | compile وrun وstatus بأدلة اختبار ذاتي فعلي |
| واجهات التكامل | routes/sheikha-managed-language-v1.cjs وSDK | الوصول المحدود للمترجم والتشغيل التجريبي |

## إدارة التشغيل

المسار المعتمد الجديد: /api/sheikha/language/managed/v1. يتطلب مفتاحًا قائمًا بصلاحية runtime:read. status يفحص ترجمة وتنفيذ برنامج محلي. compile وrun يقبلان source فقط، بحد 64 KiB. التشغيل هنا تجريبي دائمًا ومعزول؛ لا يمرر خيارات العميل إلى VM ولا ينفّذ أدوات الشبكة أو الخدمات فعليًا. واجهات اللغة القديمة باقية، ولا يُدّعى توحيد حوكمتها بالكامل.

SDK JavaScript المحلي يستدعي المترجم الحقيقي، وعميل API وPython يدعمان المسار الجديد. العميل المحلي يحتاج شجرة مصادر المشروع وNode.js؛ لا يُدّعى أنه حزمة مستقلة منشورة.

## المسؤوليات ودورة الإصدار

- مسؤول اللغة: القواعد والدلالة والتوافق بين AST وIR وBytecode.
- مسؤول الحوكمة: قواعد الصلاحيات والعزل والمراجعة المؤهلة.
- مسؤول التشغيل: حدود الموارد والمراقبة والاستعادة بعد اعتماد نشر مستقل.
- مسؤول الإصدار: توثيق الأدلة والتوافق واعتماد الإصدار.

هذه أدوار مقترحة؛ تعيين الأشخاص UNKNOWN. دورة التغيير: مقترح موثق، مراجعة قواعد وحوكمة، اختبارات نجاح ومنع، إصدار محلي، ثم موافقة نشر مستقلة.

## حدود الإثبات

التفعيل المحلي يُثبت بنتيجة LOCAL_RUNTIME_VERIFIED. التفعيل في الإنتاج UNKNOWN؛ المترجم الذاتي الأصلي وترحيل جميع الأنظمة UNKNOWN. عدد الخلايا أو وصف neural في البيانات لا يثبت وجود شبكة تعلم آلي. الفحوص القيمية برمجية محدودة ولا تقوم مقام الفتوى أو المراجعة المتخصصة.

حالة التنفيذ: LOCAL_RUNTIME_VERIFIED. لا نشر ولا إعادة تشغيل ولا تعديل استضافة.

التحقق: نجحت 25 حالة اختبار، وفحوص JavaScript وPython وفرق الملفات. الدليل المحلي محفوظ في runtime/sheikha-managed-language/v1/verification.json. واجهة HTTP اختُبرت بمعالجات معزولة، ولم يُشغّل خادم حي.
