# مشاريع SDP المحلية V1

إنشاء: `node tools/environment/sheikha-sdp-project-v1.cjs init hello-sheikha-v1`.
بناء: `node tools/environment/sheikha-sdp-project-v1.cjs build hello-sheikha-v1`.

يُنشئ مجلد مشروع جديدًا داخل runtime/sheikha-sdp/v1/projects، ومصدر src/main.shk قابلًا للتحرير. يرفض إعادة إنشاء مشروع موجود ولا يستبدله.

البناء يقرأ المصدر الثابت داخل المشروع، يفحص حجمه وأنواعه وأوامره، وينفذه محليًا ثم يحفظ نسخة المصدر وIR وbytecode ونتائج التنفيذ والبصمات في مجلد بناء جديد. إذا فشل الفحص لا ينشئ حزمة بناء.

هذا الإصدار يقبل أوامر العرض والرفض فقط؛ لا أوامر أجهزة أو شبكات أو قبول عقود أو نشر. أسماء المشاريع محدودة والمسار لا يخرج عن الجذر المخصص. يفترض الثقة في المجلدات الأب للنطاق المحلي. الحزم بلا توقيع موثق، ومخرجات العرض ليست شهادة اعتماد.

البيئة Node.js/Linux، وBytecode ينفذ في VM محكوم؛ ليس ملفًا أصليًا صالحًا لكل أنظمة التشغيل أو دليل جاهزية إنتاجية.

التجميع يتطلب مطابقة سجل الترخيص الداخلي والهيكل السابق. تتضمن الحزم الجديدة license-context.json بوصفه مرجعًا فقط؛ لا يمنح توزيعًا خارجيًا، ولا تتغير الحزم القديمة.
