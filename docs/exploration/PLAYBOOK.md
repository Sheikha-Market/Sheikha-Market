# منظومة الاستكشاف والبحث (حقيقي + رقمي)

الهدف: تشغيل دورة استكشاف وتجريب وبحث مستمرة تمنع الفشل المتكرر وتنتج أفضل مسار موثق دائمًا.

## نطاق البيئات
- بيئات حقيقية: تشغيل فعلي، بنية تحتية، شبكة، موارد.
- بيئات رقمية: محاكاة، اختبارات، بيانات، سيناريوهات افتراضية.
- بيئات استكشاف موسعة: أرض/سماء/فضاء كنطاقات موضوعية للبحث (نطاق domain)، مع نفس منهج القياس والتوثيق.

## الدورة المنهجية
1. قبل التجربة (Pre)
- سؤال البحث/الاستكشاف.
- الفرضية.
- الثوابت والمتغيرات.
- قياسات النجاح/الفشل.
- خطة التراجع.

2. أثناء التجربة (During)
- توثيق متغيرات البيئة الفعلية.
- تشغيل مسارات بديلة A/B/C.
- جمع العينات والنتائج في ملفات run.

3. بعد التجربة (Post)
- مقارنة المسارات بالBaseline.
- تحليل السبب الجذري للفشل إن وجد.
- استخراج أفضل مسار.
- توثيق الإجراء الوقائي لمنع التكرار.

## قاعدة منع الفشل
- لا قرار بدون قياس.
- لا تجربة بلا توثيق.
- أي فشل يجب أن يضيف Guard جديد.

## تشغيل سريع
- تهيئة دورة استكشاف:
  - bash tools/exploration/init-run.sh EXP-YYYY-NNN "scope-name"
- إكمال التقرير النهائي:
  - حدّث ملف run الناتج في docs/exploration/runs/

## المخرجات المطلوبة لكل دورة
- ملف run موحد يحوي: البيئة، المتغيرات، الخطوات، النتائج، القرار.
- تحديث سجل التجارب العام في docs/experiments/registry.md عند اعتماد مسار أفضل.
