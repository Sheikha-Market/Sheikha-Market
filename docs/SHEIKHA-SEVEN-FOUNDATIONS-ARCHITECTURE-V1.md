# تأسيس وحدات شيخة السبع

الحالة: LOCAL_FOUNDATIONS_ESTABLISHED_AND_VERIFIED.

## الهيكل والمعمارية

| الوحدة | المسؤولية | التبعيات | حدود التشغيل |
|---|---|---|---|
| UTF | سلامة النص العربي وترميز UTF-8 | لا شيء | ربط مؤقت بوحدة الترميز القائمة؛ المقصود النهائي UNKNOWN |
| Core | العقود والسجل وقبول القدرات | UTF | تحقق تركيب عقود محلي، وليس إثبات خدمة إنتاجية |
| Studio | مساحة المطور وأدوات اللغة | Core | قراءة مساحة محلية وفحص مترجم؛ تشغيل المحرر الحي UNKNOWN |
| Lab | التجارب المحدودة والتحقق قبل الترقية | Core، Studio | تجربة لغة محلية بلا تأثيرات خارجية |
| Visual | الهندسة والمشاهد وسياسة المحتوى | UTF، Core، Studio | حساب هندسي وفحص سياسة؛ التصيير والخدمة الحية غير مثبتين |
| Firmware | حوكمة البرامج الثابتة وقبول الأصول | لا شيء | فحص سياسة فقط؛ لا كتابة إلى جهاز |
| Bare Metal | ملفات إقلاع UEFI والنواة الأصلية | Firmware | مقارنة بصمات الملفات بأدلة سابقة، بلا إقلاع جديد |

فرع الخدمات المستضافة منفصل عن فرع الأجهزة. لا يحتاج Core المستضاف إلى تفليش Firmware أو إقلاع النواة الأصلية. لغة شيخة هي أداة مشتركة لـLab وStudio؛ الإدارة الجديدة لا تعيد تسمية الأصول الخارجية ولا تنقل حقوقها.

## الإدارة الموحدة

واجهة /api/sheikha/foundation/managed/v1 تتطلب مفتاحًا بصلاحية runtime:read. توفر status وcomponents/:component وcomponents/:component/activation-plan. خطة التفعيل تقبل local-foundation فقط؛ لا تشغّل خدمة ولا تمنح إذن نشر أو كتابة جهاز. SDK JavaScript وPython يدعمان الواجهة؛ MCP يوفر sheikha_foundation_status للقراءة المحلية.

## الحوكمة والأدوار

لكل وحدة مسؤول مكوّن ومراجع حوكمة ومعتمد إصدار؛ تعيين الأشخاص UNKNOWN. المسار: تصميم، تحقق محلي، مراجعة حوكمة، مراجعة إصدار، ثم نشر بموافقة مستقلة. أقل صلاحية ومنع افتراضي؛ لا تسجّل معاملات حساسة أو بيانات مالك شخصية. ملفات الملكية السرية تبقى منفصلة.

التأسيس المحلي يعني تنظيم وربط أدوات الإدارة والتحقق، ولا يعني بدء الخدمات أو اكتمال المنتجات. لا تتحول ACTIVE في سجل إلى دليل تفعيل. مقارنة SHA-256 تثبت الاتساق مع التقرير المسجل، ولا تثبت أصالة التقرير مستقلًا.

لا نشر ولا دفع ولا تغيير استضافة ولا إعادة تشغيل ولا تفليش ولا كتابة USB أو قرص فعلي. أي عمل لاحق من هذا النوع يتطلب تحديد المورد والإجراء والدليل وموافقة مستقلة. المرجعية القيمية بالكتاب والسنة لا تمنح البرمجيات سلطة فتوى، والمراجعة المختصة تبقى مطلوبة.

التحقق النهائي: 30 اختبارًا ناجحًا عبر التأسيس وحوكمة SDK/MCP واللغة. نجحت فحوص الصياغة وJSON وفرق الملفات. الدليل: runtime/sheikha-foundation-management/v1/verification.json. التشغيل الإنتاجي والعتادي UNKNOWN.
