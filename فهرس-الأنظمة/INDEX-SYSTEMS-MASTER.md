## 🔌 نقاط التفعيل (Activation Endpoints)

جميع الأنظمة متاحة عبر API endpoints:

```bash
# فحص الحالة
GET /api/systems/status

# تفعيل نظام
POST /api/systems/activate/:systemId

# إيقاف نظام
POST /api/systems/deactivate/:systemId

# جلب المعلومات
GET /api/systems/info/:systemId

# جلب الخواص
GET /api/systems/properties/:systemId

# تشغيل العمليات
POST /api/systems/execute/:systemId
```
