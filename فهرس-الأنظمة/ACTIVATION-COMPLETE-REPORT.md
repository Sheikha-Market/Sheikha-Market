## 🚀 كيفية التشغيل الفوري

### **الخيار 1: محرك التفعيل المباشر**
```bash
npm run systems:activate
```

### **الخيار 2: تفعيل عبر curl**
```bash
# تفعيل جميع الأنظمة
curl -X POST http://localhost:8080/api/systems/activate-all

# جلب التقرير
curl http://localhost:8080/api/systems/report
```

### **الخيار 3: من داخل الكود**
```javascript
const { SystemsActivationEngine } = require('./lib/systems-activation-engine');
const engine = new SystemsActivationEngine();

// تفعيل جميع الأنظمة والحصول على التقرير
engine.activateAllSystems().then(result => {
  console.log('✅ التفعيل:', result);
  console.log('📊 التقرير:', engine.generateReport());
});
```
