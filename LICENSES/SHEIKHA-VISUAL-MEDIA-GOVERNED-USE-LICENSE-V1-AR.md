# ملحق رخصة شيخة للوسائط المرئية والاستعمال المنضبط - الإصدار 1

**المعرف الداخلي:** `SHEIKHA-VISUAL-GOVERNED-USE-1.0`

## الطبيعة والنطاق

هذا ملحق داخلي لرخصة `SHEIKHA Proprietary Governed Use License Version 1`. يسري فقط على كود شيخة الأصلي ومواصفاتها وأصولها المرئية التي يملك المرخص حقوقها، ولا ينقل أي حق في نموذج أو codec أو مكتبة أو علامة أو بيانات لطرف ثالث.

هذه الوثيقة ليست تسجيل علامة تجارية أو براءة أو شهادة حكومية، ولا تُصدر حقًا لا يملكه المرخص. التشغيل أو البيع للعميل يحتاج أمر ترخيص مكتوبًا يحدد المنتج والإصدار والمدة والنطاق والمقابل والبيانات والمزودين.

## الحقوق المشروطة

يجوز منح حق داخلي أو تجريبي أو تجاري بعقد مستقل موقع. كل حق غير ممنوح كتابة يبقى محفوظًا. ويجب حفظ بصمة الإصدار، وسجل القبول، ومصدر كل أصل، وترخيص كل اعتماد خارجي.

## ضوابط الوسائط

- الوضع الافتراضي لمنتجات شيخة المرئية هو الرسم غير التجسيدي: الأشكال والمباني والمنتجات والآلات والخرائط والمناظر والنبات والماء والسماء والبيانات والخط والزخرفة والتجريد.
- يستبعد هذا الوضع رسم الأشخاص والوجوه والحيوانات والشخصيات المجسدة وإعادة البناء الحيوي، ويقف عند غموض الموضوع للمراجعة.
- المصطلحات العامة المفضلة هي: رسم، مشهد، جرافكس، مجسم، حركة، رسم متحرك ومحاكاة. تبقى المصطلحات التقنية مثل image وvideo داخل metadata والتوافق البرمجي عند الحاجة.
- تغيير المصطلح لا يغير حقيقة المحتوى ولا يُستعمل للتحايل على حكم أو نظام. الحكم الشرعي التفصيلي يعتمد من أهل العلم المؤهلين، لا من البرنامج.
- يجب وسم الوسائط المولدة آليًا وحفظ provenance قابل للمراجعة.
- يلزم رضا صحيح لمعالجة الوجه أو الصوت أو القياسات الحيوية أو التقاط الحركة.
- يمنع الانتحال والتزييف المضلل والابتزاز والاستغلال والمحتوى الجنسي المحظور والإضرار بالسمعة والخصوصية.
- أنظمة المراقبة والتحليل تخضع للأنظمة المحلية، وتحديد الغرض، وتقليل البيانات، وضبط الوصول، وسياسة احتفاظ وحذف موثقة.
- لا يستخدم محتوى العميل للتدريب افتراضيًا؛ يحتاج ذلك إلى موافقة منفصلة صريحة وحق قانوني في البيانات.
- الأحكام الشرعية التفصيلية تُحال إلى مراجعة بشرية مؤهلة، ولا يدعي البرنامج سلطة شرعية أو عصمة.

## codecs والمزودون

H.264 وH.265 وغيرهما قد تخضع لبراءات ورسوم وشروط موزعين؛ ذكر الصيغة أو إنشاء adapter لا يمنح ترخيص codec. كما تبقى Sora وVeo وRunway وKling وLuma وFirefly وHeyGen وSynthesia وسائر العلامات حقوقًا لأصحابها، واستخدامها اختياري وباشتراك وشروط منفصلة.

## السلامة والجودة

لا يوصف منتج بأنه تجاري أو الأعلى دقة أو المتفوق قبل وجود أصول مرخصة، واختبارات أداء وأجهزة وإتاحة وسلامة، ومراجعة بشرية للإصدار. المرجعية الأخلاقية هي الصدق والعدل والوفاء بالعقود وقاعدة لا ضرر ولا ضرار، مع الالتزام بالأنظمة المختصة.
