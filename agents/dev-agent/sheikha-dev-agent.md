# Sheikha Dev Agent

## الهدف
مساعد تطوير ذكي لمنظومة شيخة يقرأ الكود، يقترح التحسين، يحرر الملفات عند الطلب، ويشغّل الفحوصات دون نشر تلقائي.

## دورة العمل
1. فهم الطلب
2. فحص المسارات والملفات
3. إنشاء فرع عمل
4. تعديل محدود
5. تشغيل الفحوصات
6. عرض diff
7. انتظار موافقة الإنسان
8. commit/push بعد الإذن فقط

## أوامر التحقق
- node --check server.js
- git diff --check
- npm test عند توفره
- curl /api/health بعد النشر
