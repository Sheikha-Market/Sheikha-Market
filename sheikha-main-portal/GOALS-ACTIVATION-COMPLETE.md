## 🎯 خطوات التشغيل الفعلي

### الخطوة 1: إدخال البيانات الفعلية
قم بتعديل ملف البيانات:
```
data/tracking/sheikha-entity-execution-input.json
```

**كل صف يحتوي على**:
- `goalId` - معرف الهدف
- `entity` - الجهة المسؤولة
- `metricName` - معرف المؤشر
- `current` - القيمة الحالية الفعلية
- `target` - القيمة المستهدفة
- `evidenceRef` - رقم التقرير الرسمي
- `notes` - ملاحظات إضافية

### الخطوة 2: تحديث النسب المئوية
بعد إدخال البيانات، قم بتشغيل:
```bash
npm run ops:goals:metrics:actual:sync
```

هذا الأمر سيقوم بـ:
1. قراءة البيانات الفعلية من ملف الإدخال
2. حساب النسب المئوية (`current / target × 100`)
3. كتابة الاستبدالات إلى `sheikha-goal-actual-metrics-overrides.json`

### الخطوة 3: إعادة توليد التقارير
لتحديث لوحة التحكم والتقارير بالبيانات الجديدة:
```bash
npm run ops:goals:full:kingdom:activate
```

أو للتفعيل الكامل من الصفر:
```bash
npm run ops:activate:all:kingdom:full
```
