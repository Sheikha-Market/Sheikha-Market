خطة التفعيل
🔄 مزامنة market@sheikha.top مع Google Workspace

خطوات ربط حسابك الحالي وتفعيل المزامنة الكاملة

1
تسجيل الدخول عبر السوبر أدمن
ادخل على admin.google.com بحساب market@sheikha.top
admin.google.com → تسجيل الدخول بـ market@sheikha.top
2
التحقق من ملكية الدومين sheikha.top
إضافة TXT record في DNS لإثبات ملكية الدومين
admin.google.com → Domains → Manage Domains → Add domain → sheikha.top → Verify → انسخ TXT record → أضفه في DNS الدومين → التحقق يستغرق ٢٤-٤٨ ساعة
3
إعداد MX Records — لتفعيل استقبال البريد
أضف هذه السجلات في DNS مزود الدومين (Vercel / Namecheap / GoDaddy):
Priority 1: ASPMX.L.GOOGLE.COM Priority 5: ALT1.ASPMX.L.GOOGLE.COM Priority 5: ALT2.ASPMX.L.GOOGLE.COM Priority 10: ALT3.ASPMX.L.GOOGLE.COM Priority 10: ALT4.ASPMX.L.GOOGLE.COM
4
إضافة SPF + DKIM + DMARC (الأمان)
حماية البريد من الانتحال والبريد المزيف
SPF (TXT): v=spf1 include:_spf.google.com ~all DKIM: admin.google.com → Gmail → Authenticate Email → Generate Key → أضف TXT DMARC (TXT): v=DMARC1; p=quarantine; rua=mailto:market@sheikha.top
5
مزامنة جهات الاتصال والتقويم مع الأجهزة
لمزامنة الجوال والحاسب مع Google Workspace:
iPhone/iPad: Settings → Mail → Add Account → Google → sign in with market@sheikha.top → فعّل: Mail + Contacts + Calendars + Notes Android: Settings → Accounts → Add Account → Google → market@sheikha.top → فعّل كل الخيارات Desktop (Outlook/Thunderbird): IMAP: imap.gmail.com (SSL, port 993) SMTP: smtp.gmail.com (SSL, port 465) → استخدم App Password من myaccount.google.com/apppasswords
6
مزامنة Google Drive مع الكمبيوتر
تثبيت Google Drive for Desktop لمزامنة ملفات شيخة محلياً + سحابياً
الرابط: dl.google.com/drive-file-stream/GoogleDriveSetup.exe → تثبيت → تسجيل الدخول بـ market@sheikha.top → اختر المجلدات المراد مزامنتها → تظهر كقرص G: في ويندوز أو مجلد في ماك
7
ربط Google Workspace بـ server.js (شيخة API)
Apps Script لإرسال بيانات شيخة مباشرة لـ Gmail وSheets
// Google Apps Script → script.google.com function syncSheikhaData() { const url = 'https://sheikha.top/api/metals/precious'; const res = UrlFetchApp.fetch(url); const data = JSON.parse(res.getContentText()); // كتابة في Sheets const sheet = SpreadsheetApp.getActiveSheet(); sheet.getRange('A1').setValue(data.message); // إرسال بريد يومي GmailApp.sendEmail( 'market@sheikha.top', 'أسعار المعادن اليومية — شيخة', JSON.stringify(data.data, null, 2) ); } // ضبط Trigger: يومياً الساعة 8 صباحاً
