Sheikha Core SDK

واجهة موحدة لعرض وحدات SDK الأساسية: السوق، الحوكمة، العقود، الإمداد، التحليلات، والمصادقة.

Core SDK
تشغيل وتوحيد الخدمات الأساسية.
Market SDK
قراءة بيانات السوق الحي والمؤشرات.
Governance SDK
قواعد الانضباط والتحقق والسجل.
Contract SDK
إدارة القوالب والحالات والموافقات.
Supply SDK
ربط الطلبات بالمخزون والتوريد.
Auth SDK
هوية وصلاحيات وتدقيق أثر الاستخدام.
