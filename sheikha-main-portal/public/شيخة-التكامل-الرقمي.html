  • تفعيل Google Sites لصفحات المعرفة الداخلية
  • ضبط DLP لمنع تسريب الوثائق الحساسة

🔐 تسجيل الدخول بـ Microsoft (Azure AD)
خطوات التفعيل
  • portal.azure.com → Azure Active Directory → App Registrations
  • New Registration → Name: Sheikha Market → Accounts in any tenant (common)
  • Redirect URI: https://sheikha.top/auth/microsoft/callback
  • Certificates & Secrets → New Client Secret (نسخه فوراً)
  • API Permissions → Microsoft Graph → User.Read (أساسي)
  • ضبط .env بـ CLIENT_ID و CLIENT_SECRET و TENANT_ID=common
MICROSOFT_CLIENT_ID=your_azure_app_client_id MICROSOFT_CLIENT_SECRET=your_azure_client_secret MICROSOFT_TENANT_ID=common MICROSOFT_REDIRECT_URI=https://sheikha.top/auth/microsoft/callback

🍎 Apple — تكامل iOS/macOS/watchOS
⚠️ ملاحظة مهمة: أي تطبيق iOS في App Store يدعم تسجيل دخول اجتماعي (Google/Microsoft) يـجب أن يدعم Sign in with Apple أيضاً — متطلب Apple إلزامي.
🔑
Sign in with Apple
الخطوات:
١. developer.apple.com → 99 USD/سنة
٢. Identifiers → Services IDs → com.sheikha.market
٣. تفعيل Sign In with Apple
٤. Domains: sheikha.top | Return URL: /auth/apple/callback
٥. Keys → إنشاء Private Key (p8) — حفظ مرة واحدة فقط!
٦. ضبط .env بالقيم أدناه
APPLE_CLIENT_ID=com.sheikha.market APPLE_TEAM_ID=YOUR_APPLE_TEAM_ID APPLE_KEY_ID=YOUR_APPLE_KEY_ID APPLE_REDIRECT_URI=https://sheikha.top/auth/apple/callback
🔔
APNs — إشعارات iOS
الخطوات:
١. developer.apple.com → Keys → New Key
٢. تفعيل Apple Push Notifications
٣. تحميل الـ .p8 file
٤. حفظ: Key ID + Team ID
٥. ضبط Firebase APNs:
console.firebase.google.com → Project Settings → Cloud Messaging → APNs Auth Key

🤖 Google Play (TWA) — خطوات النشر
  • اختبار Lighthouse: npx lighthouse https://sheikha.top --view (هدف ≥ 90)
  • تثبيت Bubblewrap: npm install -g @bubblewrap/cli
  • إنشاء TWA: bubblewrap init --manifest=https://sheikha.top/manifest.json
  • بناء APK: bubblewrap build → app-release-signed.apk
  • إضافة assetlinks.json: sheikha.top/.well-known/assetlinks.json
  • play.google.com/apps/publish → 25 USD → رفع APK → Internal Testing
  • مراجعة Google (1-7 أيام) → نشر للعموم
  • نفس APK → Huawei AppGallery + Samsung Galaxy Store
