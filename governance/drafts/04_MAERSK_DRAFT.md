# شيخة — مسودة تأهيل مورد خدمات لوجستية وسلاسل إمداد (ميرسك Maersk)
**حالة الوثيقة:** مسودة داخلية للمراجعة البشرية — **ليست شراكة رسمية قائمة ولا تضمن أمر شراء أو عقد شحن تلقائياً.**

## 1. البيانات الأساسية للمنشأة المتقدمة
- **الاسم التجاري:** سوق شيخة السيادية (Sooq Sheikha)
- **المالك والناظر:** سلمان أحمد بن سلمان الراجح
- **رقم السجل التجاري:** 2051263653
- **الرقم الموحد (700):** 7049031003
- **الموقع اللوجستي الاستراتيجي:** الخبر / قرب ميناء الملك عبدالعزيز بالدمام، المنطقة الشرقية، المملكة العربية السعودية
- **المنصات التقنية الحاضنة:** Sheikha Logistics Network (18155) & Sheikha Supply Gateway (18093)
- **درجة الأولوية التنظيمية:** المرحلة الثانية (86 / 100)
- **الرابط المرجعي للمشتريات:** https://www.maersk.com/procurement/how-to-reach-us

## 2. الخدمة المحددة المقترحة للتعاون اللوجستي
1. خدمات الفرز، التخزين، وإدارة ساحات المعادن والسكراب الصناعي المجهزة للشحن بالحاويات.
2. الربط الرقمي الموثق لقوائم التعبئة وبوليصات الشحن (Bill of Lading) عبر منصة شيخة اللوجستية (Port 18155) عند استكمال التراخيص.
3. تطبيق معايير الشفافية في أجور المناولة والعمليات (0.5% أجور إدارية شفافة بلا غرر).

## 3. قائمة التدقيق البشري الإلزامية قبل التواصل مع مشتريات ميرسك
- [ ] تحديد فئة الخدمة اللوجستية بدقة (نقل بري / ساحة تخزين / مناولة معادن) وفق تصنيفات ميرسك.
- [ ] مراجعة شروط التوريد العالمية (Maersk Supplier Code of Conduct) والسلامة البحرية والبيئية.
- [ ] التأكد من سريان تراخيص النقل أو التخزين البلدي والصناعي في المنطقة الشرقية.
- [ ] اعتماد وتوقيع المالك السيادي شخصياً قبل تقديم ملف التعريف عبر بوابة مشتريات ميرسك.
