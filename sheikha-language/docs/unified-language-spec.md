# لغة شيخة — المرجعية والمعمارية والمواصفة الموحدة

لغة شيخة لغة برمجية عربية ذات مرجعية قيم إسلامية يحددها صاحب المشروع بالكتاب والسنة وقاعدة «لا ضرر ولا ضرار». غايتها المعلنة عبادة الله والعمل النافع وإعمار الأرض بالصدق والعدل والأمانة والإتقان. تنفّذ البرمجيات ضوابط تقنية محددة وتُراجع نتائجها بالأدلة؛ مسائل الاستنباط والفتوى والتأهيل الشرعي ترجع إلى أهل العلم المؤهلين.

هذه مواصفة تقنية تابعة لمنصة شيخة الحالية، مرتبطة بالمرجع الجذري docs/canonical/registry/ROOT-SOURCE-OF-TRUTH.md وبالمترجم والسجلات القائمة. لا تمنح سلطة دينية أو قانونية أو حق نشر جديدًا. مثال لغة القيم والمنهج موجود في ../examples/language-charter-v1.shk.

## الأركان والقواعد

| الركن | مواصفته | ما يفحصه التنفيذ الحالي |
|---|---|---|
| المرجعية والغاية | الكتاب والسنة والنفع والعدل ومنع الضرر | اكتمال حقول مرجعية القيم وحدودها؛ لا شهادة امتثال شرعي |
| العربية | كلمات عربية وقواعد تركيب محددة وأسماء عربية ورسائل تشخيص | lexer وparser وعقد AST؛ لا تحليل شامل للإعراب والنحو والصرف في اللغة الطبيعية |
| الحساب والمنطق | دلالة معلنة وحدود قيم ونتائج متوقعة | منطق حرفي وحساب صحيح ثابت ومقارنات وشروط متداخلة |
| المنهج العلمي | سؤال ومصدر وفرضية وقياس وتجربة وتكرار وحدود ثقة | قوالب 11 منهجًا وموجز وصفي محدود؛ بقية التأهيل لكل مجال على حدة |
| الأدلة | فصل الادعاء والملاحظة والتحقق والتفويض | بصمات ملفات ومراجعات محفوظة واختبارات؛ البصمة ليست إثبات صحة الادعاء |
| الصلاحيات | أقل صلاحية ومنع التجاوز والمراجعة البشرية | بوابة SDP والأوامر المحددة وفحص النطاق الداخلي؛ لا صلاحيات إنتاج أو دفع أو تحريك أجهزة |
| التكامل | ربط الوحدات واللغات بعقود موثقة | مدخل .shk وبيانات semantic-manifest؛ لا ترجمة مكافئة لكل اللغات |

## جذور اللغة وبنيتها

```text
المصدر العربي .shk
  → التحليل المعجمي lexer
  → التحليل التركيبي parser وAST
  → فحص الأنواع والسياسات المعلنة
  → IR يحفظ الشروط المتداخلة
  → bytecode
  → VM محلي محكوم
  → تقارير وبصمات ومراجعة

جزء مؤهل للتجربة المحلية من bytecode
  → مولد C محدود
  → GCC أو Clang/CMake/Ninja على Linux x64
  → ELF يعتمد على libc المضيف
  → مقارنة الخرج المتوقع وحفظ الأدلة
```

المترجم الحالي مكتوب بـJavaScript ويعمل على Node.js. بناء المترجم بذاته بلغة شيخة هدف لاحق، وليس إنجازًا مثبتًا. النموذج الأصلي Bare-Metal مسار مستقل ذو أدلة إقلاع تاريخية وحدود معلنة، ولا ينتقل إليه هذا الهدف المضيف تلقائيًا.

## العربية والإعراب والنحو والصرف

النحو البرمجي يعرف تركيب `إجراء` و`كيان` و`إذا` و`وإلا` و`مرجعية` و`سياسة` و`منهج` والمسافات البادئة والأسماء والقيم. الإعراب والصرف والبلاغة وعلوم العربية الطبيعية مجالات تطوير لغوي تحتاج مصادر موثقة وخبراء واختبارات مدونات لغوية؛ تسجيل أسمائها في المانيفست لا ينفّذ محللًا لغويًا كاملًا. تحفظ رسائل الأخطاء موضع المصدر لتسهيل تصحيح البرامج.

## الدلالة وحدود الحساب الحالي

`true` و`false` و`صحيح` و`خطأ` قيم منطقية حرفية. تدعم الشروط العددية أعدادًا صحيحة عشرية ثابتة، و+ و- و* والأقواس والإشارة الأحادية، ثم == و!= و< و> و<= و>=. للضرب أولوية على الجمع والطرح. كل قيمة وسيطة ضمن ±1000000. طول الشرط 128 حرفًا وحد التعبير 64 رمزًا/عقدة وعمق 16؛ حد مولد C هو 4096 تعليمة وعمق 16.

تُرفض الكسور والقسمة والمتغيرات والتجاوزات والصياغة العددية غير الصالحة في هذا الجزء. تُبنى C من تحليل محدد دون eval أو إدخال نص الشرط مباشرة. للشروط النصية القديمة سلوك توافق وصفي داخل VM؛ لا يمثل لغة منطق عامة ولا يقبل في الهدف الأصلي المحدود. تقارن الاختبارات بالنتائج المتوقعة من المصدر، إلى جانب مقارنة VM والمترجمات المضيفة.

## العلم والبرهان

تتصل المواصفة بـcore/research/sheikha-research-brain-v1.cjs وبالفهرس الحالي للمنهجيات وبمصدر foundations/sheikha-methodologies-v1.shk. القوالب الأولية: الوصفي والتجريبي والإحصائي والاستقرائي والاستنباطي والمقارن والتاريخي والنوعي والمختلط والمحاكاة والمراجعة المنهجية. لا يساوي توفر قالب اكتمال تحليل أو تحقق علمي مستقل.

تحتاج كل دراسة سؤالًا محددًا ومصدرًا وصلاحية استخدام البيانات ووحدات قياس وحدودًا وأسبابًا بديلة ومراجعة مناسبة. يميز السجل بين نتيجة حسابية، وملاحظة تجريبية، وفرضية، وحكم شرعي، وتفويض تشغيلي. الثوابت الرياضية ضمن نموذجها، أما فرضيات العلوم التجريبية فتقبل الفحص والتصحيح. لا يُستدل على صحة عقد أو سلامة آلة ببصمة JSON وحدها.

## محفظة مجالات التوسع

الرياضيات والمنطق والحوسبة والفيزياء والمواد والصناعة والتجارة وسلاسل الإمداد والروبوتات والعلوم الإنسانية والعربية مجالات للتوسع بوحدات متخصصة. لكل وحدة مواصفة ومدخلات وأذونات واختبارات وجدوى وأدلة وحدود، ومراجع بشرية مؤهلة حيث يلزم. تغطية كل العلوم والتقنيات طموح للتطوير المستمر؛ لا تُسجل حالة جاهزية شاملة غير مثبتة.

## اللغات الأخرى

سجل specifications/language-spec-registry.json يصف عائلات ومداخل semantic-manifest. مدخل البيانات يحول بنية مصرحًا بها إلى AST/IR مشتركة؛ لا يثبت فهم دلالة المصدر الأصلي أو تشغيل كامل JavaScript أو Python أو C أو كل لغة مدرجة. يحتاج كل موصل دليل ترجمة واختبارات حفظ الدلالة ومراجعة تراخيص. تظل شيخة اللغة الداخلية المقترحة والتقنيات الخارجية أدوات بناء وتكامل مؤهلة ضمن نطاقها.

## الضوابط والتنظيم

الضوابط الحالية تقنية داخلية، ومنها فحص النوع والأوامر والمسارات والحجم والنطاق والتوثيق. لا نصنع من اسم القاعدة قانونًا صادرًا من دولة أو ترخيصًا من جهة اعتماد. العقود والمسائل الشرعية تحتاج أهل الاختصاص، والتشغيل الميداني يحتاج تأهيلًا لكل حالة. لا دمج Git أو نشر أو إنتاج أو دفع أو تغيير أسرار أو DNS أو تشغيل مادي ضمن هذه المواصفة.

## معيار استحقاق توسعة جديدة

تعريف واضح → مصدر مشروع → تصميم محدود → اختبار النتيجة المتوقعة وحالات الفشل → بناء وتجربة محلية مأذونة → أدلة محفوظة → مراجعة مستقلة مناسبة → تفويض منفصل عند الانتقال إلى التشغيل المطلوب. الشك أو غياب الأدلة يسجل UNKNOWN، والفشل يبقى ظاهرًا حتى إن نجح فحص لاحق.
