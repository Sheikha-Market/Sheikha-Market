# ترخيص التكامل مع منظومة شيخة — الإصدار 1

**صاحب المنظومة:** سلمان أحمد سلمان الراجح
**المنظومة:** منظومة شيخة — Sheikha

يسمح هذا القالب بإنشاء تكامل محدد ومقيد مع واجهات أو SDKs أو
أدوات أو خدمات شيخة وفق مبدأ أقل صلاحية.

التكامل لا ينقل الملكية، ولا يمنح حق إعادة الترخيص، ولا يجيز استخدام
الاسم أو الهوية أو البيانات خارج النطاق المتفق عليه.

يجب أن يحدد عقد التكامل:

1. الطرف المرخص له.
2. الأصول والواجهات المسموح بها.
3. الصلاحيات والبيانات والحدود.
4. النطاق المحلي أو الوطني أو الدولي أو العالمي.
5. مدة الإذن وآلية الإلغاء.
6. متطلبات الأمن والتدقيق والسجلات.
7. تراخيص الأطراف الخارجية الواجب حفظها.

هذا قالب تأسيسي يحتاج قبولًا موثقًا ومراجعة قانونية قبل استخدامه
كعقد ملزم مع الغير.
