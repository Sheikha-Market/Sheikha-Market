# Ownership Registry

هذا السجل يحدد ملكية كل عنصر تشغيلي في منظومة شيخة.

| العنصر         | المالك         | المسار الرسمي                        |
|---------------|---------------|--------------------------------------|
| Route         | Registry       | core/kernel/registry/                |
| Blueprint     | Canonical      | docs/canonical/                      |
| Engine        | Runtime        | core/kernel/runtime/                  |
| Dashboard     | Governance     | core/kernel/governance/              |
| AI Provider   | Provider Layer | core/providers/                      |
| Extension     | IDE Fabric     | sheikha-vscode-extension/            |

## تعليمات
- يمنع تكرار الملكية أو توزيعها خارج هذا السجل.
- أي تحديث يجب أن يُسجل هنا أولاً.
- هذا السجل هو مصدر الحقيقة النهائي للملكية.
