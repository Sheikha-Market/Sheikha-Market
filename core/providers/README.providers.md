# Provider Registry

كل مجلد هنا يمثل مزود ذكاء اصطناعي أو تشغيل قابل للتبديل.

- openai/: تكامل مع OpenAI
- ollama/: تشغيل محلي عبر Ollama
- gemini/: دعم Google Gemini
- claude/: دعم Anthropic Claude
- local/: نماذج محلية
- offline/: وضع عدم الاتصال

## الهدف
- التبديل التلقائي بين المزودات
- منع توقف النظام لأي سبب خارجي
- دعم التشغيل السيادي والمحلي
